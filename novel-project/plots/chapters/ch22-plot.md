## シーン構成

### シーン1：冬の到来（〜2,500字）

**内容**:
- 雪が降り始める
- 寒さが厳しい
- 「冬の戦闘は、地獄だ」
- 凍傷、病気、死

**冬**:
```
雪が降り始めた。

白い世界。
美しいはずなのに、美しいと思えなかった。

「冬の戦闘は、地獄だ」

誰かが言った。
その通りだった。
```

**過酷さ**:
```
寒さが、骨まで染みる。
指が凍える。剣を握れない。
足が凍える。歩けない。

凍傷で指を失った兵士がいた。
病気で死んだ兵士がいた。
戦闘じゃなくても、死んでいく。

「……」

これが、冬の戦線。
これが、戦争。
```

---

### シーン2：十六度目の戦闘（〜4,000字）★直接描写

**内容**:
- 雪の中の戦闘
- 視界が悪い、足元が悪い
- 混乱の中、必死に戦う
- 憑依と自力を使い分ける

**戦闘描写**:
```
雪の中の戦闘。

視界が悪い。
白い世界の中、敵も味方も区別がつかない。
足元が滑る。
剣を振るたびに、バランスを崩しそうになる。

「ルシウス」
「はいはい」

憑依した。
体の支配権を渡す。
冷たい感覚。でも、もう慣れた。

ルシウスが、敵を斬っていく。
雪の上に、赤い血が広がる。
白と赤。
綺麗だと、思ってしまった。
```

**自力での戦闘**:
```
「はい、返すね」

体が戻った。
まだ戦闘は続いている。

敵兵が迫ってくる。
今度は、自分で。

剣を構える。
斬る。

「……」

四人目。
もう、数えるのも嫌になった。
```

### シーン3：仲間の死（〜3,500字）

**内容**:
- 戦闘後、仲間が死んでいる
- 名前も知らない兵士
- 「あいつ、昨日まで生きてたのに」
- 死が日常になる

**発見**:
```
戦闘が終わった。

野営地に戻る途中、死体を見た。
味方の死体。
見覚えのある顔。

「……」

名前は、知らない。
でも、同じ小隊の兵士だった。
昨日、一緒に飯を食った。
今日、死んだ。
```

**反応**:
```
「あいつ、死んだのか」

レオンが言った。

「……ああ」
「昨日まで、生きてたのにな」
「……ああ」
「……」

それだけだった。
悲しむ暇もない。
泣く暇もない。
明日も、戦闘がある。
明日も、誰かが死ぬ。
```

**日常化**:
```
死が、日常になっていた。

誰かが死んでも、驚かなくなった。
誰かが死んでも、泣かなくなった。
「ああ、死んだのか」と思うだけ。

それが、怖かった。
でも、そうしないと、やっていけない。
```

---

### シーン4：「英雄」の評判（〜2,000字）

**内容**:
- 「クライスはすごい」
- 「あいつは死なない」
- 虚しい称賛
- 借りた力で得た評価

**評判**:
```
「クライス、お前すごいな」

誰かが言った。

「十六度の戦闘で、傷一つないなんて」
「……」
「どうやってるんだ？」
「……別に」
「謙遜するなよ。お前、英雄だぜ」

英雄。
その言葉が、虚しく響いた。
```

**虚しさ**:
```
英雄なんかじゃない。

俺は、借りた力で生き延びているだけだ。
ルシウスがいなければ、とっくに死んでいる。
俺の力じゃない。
俺の勝利じゃない。

でも、誰にも言えない。
言ったところで、信じてもらえない。
言ったところで、何も変わらない。

「……」

虚しかった。
```

## シーン構成

### シーン1：令状の到着（約3,500字）

#### 概要
突然の徴兵令状。家族の衝撃、エルヴィンの恐怖。

#### 場所
クライス家

#### 登場人物
- エルヴィン
- ハインリヒ（父）
- マルタ（母）
- ヴェルナー（兄）
- 王国の使者

#### 詳細プロット

**令状の到着（〜1,400字）**:
```
その日は、何の変哲もない朝だった。

灰色の空。灰色の石畳。いつもと同じ朝食。いつもと同じ会話。父は帳簿を見て、
兄は仕入れの話をして、母は台所で何かを作っていた。

僕は、棚の整理をしていた。鍋を並べ、皿を分け、埃を払う。単調な作業。何も
考えなくていい作業。

扉を叩く音がした。

強く、三度。

父が、扉を開けた。

そこに立っていたのは、王国の紋章をつけた男だった。黒い制服。厳しい顔。
手には、封蝋で閉じられた書状。

「クライス家のエルヴィン・クライスは、いるか」

父が、振り返った。僕を見た。

「……息子ですが」

男は、書状を差し出した。

「徴兵令状だ」

その言葉が、耳に入った。

しかし、意味が分からなかった。徴兵。令状。その二つの言葉が、頭の中で結び
つかなかった。
```

**家族の反応（〜1,200字）**:
```
母が、台所から出てきた。

「何事……」

その声が、途切れた。使者の手にある書状を見て、母の顔から血の気が引いた。

「嘘……」

母の声は、掠れていた。

「嘘よ……この子は、まだ……」

父が、書状を受け取った。封蝋を切り、中を読む。父の手が、微かに震えていた。

「緊急勅令により、十四歳以上の次男以下の男子は、徴兵の対象となる」

父の声は、平坦だった。感情を殺した、商人の声。

「三日後に、集合場所に出頭せよ」

三日。

たった、三日。

兄が、僕を見た。何か言いたそうな顔。しかし、何も言わなかった。言えなかった
のだろう。

僕は、立ち尽くしていた。

徴兵。

僕が。

戦場へ。

その言葉が、ようやく意味を結び始めた。
```

**エルヴィンの恐怖（〜900字）**:
```
使者が去った後、僕は動けなかった。

足が、地面に縫い付けられたように動かない。手が、冷たい。頭が、真っ白だ。

「エルヴィン」

母の声が、遠くから聞こえた。

「エルヴィン……」

母が、僕を抱きしめた。強く、強く。母の体が、震えていた。

「大丈夫よ……大丈夫……」

大丈夫じゃない。

分かっていた。母も、分かっていた。それでも、母はそう言い続けた。自分に
言い聞かせるように。僕に言い聞かせるように。

僕は、母の背中に手を回した。

何も言えなかった。何を言えばいいのか、分からなかった。

ただ、怖かった。

死ぬかもしれない。

その恐怖が、全身を支配していた。
```

#### 伏線配置
- 「十四歳以上の次男以下」（兄は免除）
- 三日という短さ（準備の時間がない）
- 母の抱擁（帰る場所の象徴）

#### 道徳心変化
100→99（-1：恐怖による動揺）

### シーン2：逃げたい気持ち（約3,500字）

#### 概要
逃亡を考える。兄との会話。「逃げられない」現実。

#### 場所
エルヴィンの部屋、家の裏

#### 登場人物
- エルヴィン
- ヴェルナー（兄）

#### 詳細プロット

**逃亡の考え（〜1,200字）**:
```
部屋に閉じこもった。

窓から、外を見る。灰色の空。灰色の町。いつもと同じ風景。しかし、もう同じ
ではなかった。

逃げよう。

その考えが、頭に浮かんだ。

どこか遠くへ。山の向こうへ。森の奥へ。誰も知らない場所へ。

しかし、どこへ？

金はない。食料もない。地理も分からない。一人で生きていく術を、僕は何も
持っていない。

逃げても、捕まる。

捕まったら、どうなる。脱走兵として、処刑されるかもしれない。家族も、罰せ
られるかもしれない。

逃げられない。

その現実が、重くのしかかった。

窓の外を見る。鳥が、空を飛んでいた。自由に、どこへでも行ける鳥。僕には、
その翼がない。
```

**兄との会話（〜1,500字）**:
```
扉を叩く音がした。

「エルヴィン、入るぞ」

兄の声だった。

扉が開き、兄が入ってきた。いつもより、顔色が悪い。目の下に、隈がある。

「……何」
「話がある」

兄は、僕の隣に座った。しばらく、沈黙が続いた。

「逃げようと思ってるだろ」

兄が、言った。

「……」
「分かる。俺だって、お前の立場なら考える」

兄は、窓の外を見ていた。灰色の空を。

「でも、逃げるな」
「……なぜ」
「逃げたら、家族が罰せられる」

その言葉が、胸に刺さった。

「父さんの店も、母さんも、俺も。脱走兵の家族として、処罰される」
「……」
「お前一人の問題じゃない」

分かっていた。分かっていたけど、言葉にされると、重かった。

「俺は、お前の代わりに行けない」

兄の声が、震えていた。

「長男は、免除だ。それが、法律だ」
「……分かってる」
「だから、お前が行くしかない」

兄が、僕を見た。その目は、赤かった。

「すまない」
「……兄さんのせいじゃない」
「でも……」
「いいんだ」

僕は、そう言った。本心だった。兄を恨む気持ちは、なかった。恨んでも、何も
変わらない。
```

**決意（〜800字）**:
```
「生きて帰れ」

兄が、僕の肩を掴んだ。

「絶対に、生きて帰れ」
「……うん」
「約束しろ」
「約束する」

兄の手が、強く肩を握った。痛かった。でも、その痛みが、少しだけ心を落ち
着かせた。

「俺は、ここで待ってる。父さんも、母さんも。お前の帰りを、待ってる」
「……うん」
「だから、死ぬな」

兄が、立ち上がった。扉に向かう。

「兄さん」
「なんだ」
「……ありがとう」

兄は、振り返らなかった。ただ、小さく頷いて、部屋を出ていった。

僕は、一人になった。

窓の外を見る。灰色の空。灰色の町。

逃げられない。

でも、生きて帰る。

それだけを、考えることにした。
```

#### 伏線配置
- 逃亡の不可能性（現実の厳しさ）
- 兄の罪悪感（後の関係への伏線）
- 「生きて帰れ」という約束

#### 道徳心変化
99→98（-1：逃げたい気持ちへの罪悪感）

### シーン3：アリシアへの告白（約3,500字）

#### 概要
徴兵を伝える。アリシアの涙。「必ず帰る」という約束。

#### 場所
川辺

#### 登場人物
- エルヴィン
- アリシア

#### 詳細プロット

**川辺での再会（〜1,200字）**:
```
アリシアを、川辺に呼び出した。

彼女は、いつもの場所に来た。金色の髪が、風に揺れている。青い瞳が、僕を見て
いる。

「どうしたの？　急に呼び出して」

彼女は、微笑んでいた。いつもの、穏やかな微笑み。

その微笑みを、壊したくなかった。

でも、言わなければならない。

「……話がある」
「なに？」

彼女の目が、僕を見ている。まっすぐに、澄んだ目で。

「僕、徴兵された」

その言葉を、口にした。

彼女の微笑みが、消えた。

「……嘘」
「本当だ」
「嘘よ。だって、エルヴィンは……」
「十四歳だ。緊急勅令で、十四歳以上は……」

言葉が、途切れた。

彼女の目から、涙が溢れていた。
```

**アリシアの反応（〜1,200字）**:
```
「嫌……」

彼女の声は、掠れていた。

「嫌よ……行かないで……」
「アリシア……」
「お願い、行かないで……」

彼女が、僕の服を掴んだ。手が、震えていた。

「逃げよう。一緒に、どこかへ」
「逃げられない」
「なぜ？」
「家族が、罰せられる」
「……」

彼女は、泣いていた。声を殺して、肩を震わせて。

僕は、何も言えなかった。慰める言葉が、見つからなかった。

川の音だけが、聞こえていた。水が流れる音。風が草を揺らす音。いつもと同じ音。
しかし、もう同じではなかった。

「ごめん」

僕は、そう言った。

「ごめん、アリシア」

何に対して謝っているのか、自分でも分からなかった。ただ、謝らずにはいられ
なかった。
```

**約束（〜1,100字）**:
```
しばらく、二人で黙っていた。

彼女の涙が、止まった。目は、まだ赤かった。

「ねえ、エルヴィン」
「なに」
「約束して」
「何を」
「必ず、帰ってくるって」

彼女の目が、僕を見ていた。涙で濡れた、青い瞳。

「約束する」
「本当に？」
「本当だ。必ず、帰ってくる」

彼女が、僕の手を握った。冷たかった。でも、その冷たさが、心に残った。

「私、待ってる」
「うん」
「ずっと、待ってる」
「うん」

彼女は、微笑んだ。涙を流しながら、微笑んだ。

「忘れないで」
「忘れない」
「私のこと、忘れないで」
「絶対に、忘れない」

その約束が、僕の心に刻まれた。

必ず、帰る。

彼女のために。家族のために。この町のために。

灰色の空の下で、僕はそう誓った。
```

#### 伏線配置
- 「必ず帰る」という約束（物語全体を貫く約束）
- アリシアの涙（後の再会への伏線）
- 手を握る（愛情の象徴）

### シーン4：最後の夜（約3,500字）

#### 概要
家族との夕食。母の涙を隠す姿。眠れない夜。

#### 場所
クライス家

#### 登場人物
- エルヴィン
- ハインリヒ（父）
- マルタ（母）
- ヴェルナー（兄）

#### 詳細プロット

**最後の夕食（〜1,200字）**:
```
出発の前夜。

家族で、夕食を囲んだ。

いつもより、豪華な料理だった。肉が出た。普段は滅多に食べない、高価な肉。
母が、僕の好きな味付けで焼いてくれた。

「食べなさい、エルヴィン」
「……うん」
「たくさん食べて」
「うん」

母の声は、穏やかだった。しかし、どこか硬さがあった。

僕は、肉を口に運んだ。美味しかった。でも、味がよく分からなかった。

父は、黙って食べていた。兄も、黙って食べていた。誰も、話さなかった。

沈黙が、食卓を覆っていた。

重い沈黙。何かを言いたいのに、言えない沈黙。

僕は、その沈黙の中で、肉を噛み続けた。
```

**父の言葉（〜1,000字）**:
```
食事の後、父が僕を呼んだ。

「エルヴィン」
「はい」
「これを持っていけ」

父が、小さな袋を渡した。中を見ると、銀貨が入っていた。

「困った時に、使え」
「父さん……」
「商人の息子だ。金の使い方は、分かるだろう」
「……はい」

父は、僕の肩を叩いた。一度だけ、強く。

「生きて帰れ。それだけでいい」
「はい」
「店は、俺とヴェルナーで守る。心配するな」
「はい」

父の目が、赤かった。泣いているのかもしれない。でも、涙は見せなかった。
商人の矜持だろうか。それとも、父親の矜持だろうか。

「行ってこい」

父は、それだけ言って、部屋を出ていった。

僕は、銀貨の入った袋を握りしめた。重かった。金の重さではない。父の思いの
重さだった。
```

**母の涙（〜800字）**:
```
夜中、目が覚めた。

喉が渇いて、水を飲みに行った。

台所で、母が泣いていた。

声を殺して、肩を震わせて。蝋燭の灯りの中で、母の影が揺れていた。

「母さん……」

母が、振り返った。慌てて、涙を拭いた。

「起きてたの？」
「……うん」
「ごめんね。起こしちゃった」
「いいよ」

母が、僕を抱きしめた。強く、強く。

「ごめんね……ごめんね……」
「母さんのせいじゃないよ」
「でも、私が……もっと……」
「いいんだ。大丈夫」

僕は、母の背中を撫でた。

本当は、僕が泣きたかった。でも、泣けなかった。泣いたら、母がもっと悲しむ
気がした。
```

**眠れない夜（〜500字）**:
```
部屋に戻っても、眠れなかった。

窓の外を見る。雨が、降り始めていた。

灰色の空。灰色の雨。灰色の夜。

明日、僕は旅立つ。戦場へ。死ぬかもしれない場所へ。

怖い。

すごく、怖い。

でも、行くしかない。家族のために。アリシアのために。帰ってくるために。

雨の音を聞きながら、目を閉じた。

眠れないまま、朝を待った。

灰色の夜が、ゆっくりと明けていく。

新しい日が、始まろうとしていた。僕の知らない、灰色ではない日が。
```

#### 伏線配置
- 父の銀貨（後の助けになる可能性）
- 母の涙（帰る場所の象徴）
- 雨のモチーフ（別れの象徴）
- 灰色の夜（モチーフ）

## 執筆時の注意点

1. **衝撃の描写**
   - 突然の令状
   - 現実感のなさから徐々に理解へ
   - 感情を抑えた文体で、かえって重さを出す

2. **家族の描写**
   - それぞれの反応の違い
   - 言葉にできない感情
   - 涙を隠す姿

3. **約束の重み**
   - アリシアとの約束
   - 物語全体を貫く重要な約束
   - 感情的だが、押し付けがましくなく

4. **文体の維持**
   - 説明を物語に溶け込ませる
   - 会話は最小限に
   - 内省と情景を融合させる

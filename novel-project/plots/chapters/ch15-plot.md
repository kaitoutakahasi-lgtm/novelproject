## 章の目的

### 物語上の役割
1. 戦闘の日常化
2. 憑依への「慣れ」とその恐怖
3. 「借りた力」への依存の深化
4. 周囲の評価の変化（「クライスは強い」）
5. 虚しさの始まり

### 読者への効果
- 戦争の日常化の恐ろしさ
- 「慣れる」ことへの複雑な感情
- 主人公の変質の始まり

### ch14との連続性
- ch14：二度目の戦闘後、ガレスの疑念
- ch15：三度目〜五度目の戦闘、慣れていく自分

## シーン構成

### シーン1：三度目、四度目の戦闘（章間ダイジェスト）（〜2,500字）

**内容**:
- 「三度目の戦闘を終えた」
- 「四度目の戦闘を終えた」
- 憑依がスムーズになる
- 「慣れてきた」という自覚

**描写ポイント**:
```
三度目の戦闘を終えた。
四度目の戦闘を終えた。
「ルシウス」「はいはい」
呼べば、すぐに来る。
体を貸せば、すぐに終わる。
「慣れてきたね」
ルシウスが言った。
「……ああ」
慣れてきた。
それが、怖い。
```

---

### シーン2：周囲の評価（〜3,000字）

**内容**:
- 「クライスは強い」という評判
- 「あいつは死なない」
- 虚しい称賛
- レオンの反応

**周囲の声**:
```
「クライス、また生き延びたな」
「あいつ、すごいよな」
「新兵なのに、ベテランみたいな動きだ」
「何か秘訣があるんだろ」
```

**エルヴィンの内心**:
```
秘訣はある。
でも、言えない。
「俺の体を幽霊に貸してる」なんて。
「……運がいいだけだ」
また、嘘をついた。
```

**レオンとの会話**:
```
「エルヴィン、お前本当にすごいな」
「……そうか」
「俺も頑張らないと。お前に置いていかれる」
「……」
「でも、嬉しいよ。友達が強いって」
レオンは、笑った。
僕は、笑えなかった。
```

### シーン3：五度目の戦闘（直接描写）（〜4,000字）

**内容**:
- 五度目の戦闘
- 今回は少しだけ自分で動いてみる
- でも、すぐに限界
- 結局、憑依に頼る

**自分で動く試み**:
```
「今日は、自分でやってみる」
「へえ、いいよ。見てる」
敵兵が来る。
剣を構える。
相手の動きを読む。右肩が下がった。右から来る。
避ける。踏み込む。剣を振る。
……外れた。
「遅い」
ルシウスの声。
次の瞬間、敵の剣が迫ってきた。
「ルシウス…！」
「はいはい」
```

**憑依後**:
```
体が、勝手に動いた。
敵を斬る。次の敵を斬る。
「……」
また、見ているだけだ。
自分でやろうとしたのに。
結局、頼ってしまった。
```

### シーン4：虚しさ（〜2,500字）

**内容**:
- 戦闘後の虚しさ
- 「これは、僕の力じゃない」
- 「借りた力で、借りた勝利」
- でも、生きている

**描写ポイント**:
```
五度目の戦闘を終えた。
累計、何人殺した？
「十二人かな」
ルシウスが数える。
僕は、数えられない。
「……」
「どうしたの？」
「……虚しい」
「虚しい？　なんで？」
「これは、僕の力じゃない」
「そうだね。僕の力だよ」
「……」
「でも、生きてるじゃん。それでいいんじゃない？」
```

**エルヴィンの内省**:
```
生きている。
それは、事実だ。
でも、僕の力で生きているわけじゃない。
借りた力で、借りた命。
「これでいいのか」
分からない。
でも、死にたくない。
だから、借り続ける。
```

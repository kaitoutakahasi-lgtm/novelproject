## シーン構成

### シーン1：戦闘の日常化（〜3,000字）

**内容**:
- 「また戦闘があった」
- 二十三度目、二十四度目、二十五度目、二十六度目
- 憑依と自力を使い分ける
- 「慣れた」という恐怖

**日常化**:
```
また戦闘があった。
二十三度目。二十四度目。二十五度目。二十六度目。

もう、数えるのも面倒になった。
戦闘が、日常になった。
人を殺すことが、日常になった。

「……」

慣れた。
俺は、人を殺すことに、慣れてしまった。
```

**使い分け**:
```
憑依と自力を、使い分けるようになった。

危険な時は、ルシウスに任せる。
そうでない時は、自分で戦う。

効率的だ。
合理的だ。
でも、それでいいのか。

「……」

考えないことにした。
考えても、答えは出ない。
```

---

### シーン2：昇進（〜3,500字）

**内容**:
- 伍長への昇進
- 「お前の働きは、上も見ている」
- 「期待しているぞ」
- 借りた力で得た評価

**通達**:
```
「クライス」

ガレスに呼ばれた。

「……はい」
「お前、伍長に昇進だ」
「……」
「上からの通達だ。お前の働きが認められた」
「……ありがとうございます」
「期待しているぞ」

伍長。
昇進。
俺が。
```

**虚しさ**:
```
嬉しくなかった。

これは、俺の力じゃない。
ルシウスの力だ。
借りた力で、借りた勝利で、借りた評価。

「……」

でも、断れない。
断る理由がない。
「実は、幽体に助けてもらってます」なんて、言えない。

「……」

虚しかった。
```

---

### シーン3：「英雄」の日々（〜3,000字）

**内容**:
- 周囲からの称賛
- 「クライスは死なない」
- 「英雄だ」
- 孤立の中の称賛

**称賛**:
```
「クライス伍長、すごいですね」

新兵が言った。

「二十六度の戦闘で、傷一つないなんて」
「……」
「どうやってるんですか？」
「……別に」
「教えてください」
「……」

教えられるわけがない。
「幽体に体を貸してます」なんて。
```

**孤立**:
```
称賛されればされるほど、孤立した。

誰も、本当の俺を知らない。
誰も、俺の秘密を知らない。
「英雄」を称賛しているだけ。
俺を見ているわけじゃない。

「……」

それでいい。
誰にも近づかない。
誰にも知られない。
一人でいい。
```

---

### シーン4：合理化の完成（〜2,500字）

**内容**:
- 「これは、俺の力じゃない」
- 「借りた力で、借りた勝利」
- 「でも、生きている」
- 「それだけが、事実だ」

**合理化**:
```
「これは、俺の力じゃない」

分かっている。
借りた力で、借りた勝利。
俺は、何も偉くない。

でも、生きている。
それだけが、事実だ。

「……」

生きている。
アリシアとの約束を、守れる。
レオンの妹たちに、手紙を書ける。
生きているから、できることがある。

だから、これでいい。
借りた力でも、いい。
生きていれば、いい。
```

**締めくくり**:
```
俺は、「英雄」になった。

借りた力で。
借りた勝利で。
借りた評価で。

でも、生きている。
それだけが、事実だ。

「……」

これが、俺の選んだ道だ。
後悔は、しない。
後悔しても、何も変わらない。

前に進むしかない。
生き延びるしかない。
それだけだ。
```

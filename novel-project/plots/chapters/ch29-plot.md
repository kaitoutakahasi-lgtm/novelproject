## シーン構成

### シーン1：期待と重圧（〜3,500字）

**内容**:
- 「クライス伍長なら大丈夫」
- 周囲からの期待
- 重圧
- 「英雄」を演じる

**期待**:
```
「クライス伍長、今日もよろしくお願いします」

新兵が言った。
目が、輝いている。
期待の目。尊敬の目。

「……ああ」

俺は、「英雄」だ。
みんな、そう思っている。
死なない兵士。最強の伍長。

「……」

嘘だ。
全部、嘘だ。
```

**重圧**:
```
「クライス伍長がいれば、安心だ」
「あの人は、絶対に死なない」
「俺たちも、守ってもらえる」

そんな声が、聞こえてくる。

守る？
俺が？
俺は、自分を守るので精一杯だ。
ルシウスがいなければ、とっくに死んでいる。

「……」

でも、言えない。
「英雄」を演じるしかない。
期待に応えるしかない。
```

---

### シーン2：戦闘（〜3,000字）

**内容**:
- 三十度目の戦闘
- 憑依で戦う
- 「英雄」らしく振る舞う
- 内側から見ている虚しさ

**戦闘**:
```
三十度目の戦闘。

「ルシウス」
「はいはい」

憑依した。
もう、何度目か分からない。
体の支配権を渡す。
冷たい感覚。でも、もう慣れた。

ルシウスが、敵を斬っていく。
俺は、内側から見ている。
見ているだけ。
```

**「英雄」の姿**:
```
戦闘が終わった。

「さすがクライス伍長だ」
「すごい……」
「やっぱり、英雄だ」

称賛の声。
俺は、何もしていない。
ルシウスがやっただけだ。

「……」

でも、笑って見せた。
「英雄」らしく。
みんなが期待する姿を、演じた。
```

---

### シーン3：孤独（〜3,000字）

**内容**:
- 夜、一人でいる
- 誰にも話せない
- レオンがいない
- 孤独の重さ

**夜**:
```
夜、テントの中。
一人だった。

レオンがいた頃は、話し相手がいた。
今は、誰もいない。
誰にも、本当のことを話せない。

「……」

孤独だった。
「英雄」は、孤独だった。
```

**レオンの不在**:
```
レオンがいたら、何て言っただろう。

「お前、無理してるだろ」
「少しは休めよ」
「俺がいるから、大丈夫だ」

そんなことを、言ってくれただろうか。

「……」

もう、分からない。
レオンは、いない。
永遠に、いない。
```

---

### シーン4：ルシウスとの会話（〜2,500字）

**内容**:
- 「君、疲れてるね」
- 「……ああ」
- 「でも、僕がいるから大丈夫だよ」
- 依存の深化

**会話**:
```
「君、疲れてるね」

ルシウスが言った。

「……ああ」
「『英雄』って、大変だね」
「……」
「みんな、君に期待してる」
「……ああ」
「でも、君は何もしてない」
「……」
「僕がやってるのにね」

その通りだった。
俺は、何もしていない。
```

**依存**:
```
「でも、大丈夫だよ」

ルシウスが言った。

「僕がいるから」
「……」
「君が呼べば、僕が助ける」
「……」
「ずっと、そうしてきたでしょ？」
「……ああ」
「これからも、そうすればいい」

その言葉に、頷いた。
ルシウスがいれば、大丈夫。
ルシウスがいれば、生き延びられる。

依存している。
分かっていた。
でも、それ以外に方法がなかった。
```

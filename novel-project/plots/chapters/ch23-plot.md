## シーン構成

### シーン1：春の到来（〜2,500字）

**内容**:
- 雪が溶け始める
- 暖かくなってきた
- 「生き延びた」という安堵
- でも、戦争は終わらない

**春**:
```
雪が、溶け始めた。

白い世界が、少しずつ色を取り戻していく。
空気が、暖かくなってきた。
冬が、終わろうとしている。

「……生き延びた」

そう思った。
冬を、生き延びた。
十九度の戦闘を、生き延びた。
```

**安堵と不安**:
```
安堵があった。
でも、喜びはなかった。

戦争は、終わっていない。
春になれば、また戦闘が増える。
また、人を殺す。
また、仲間が死ぬ。

「……」

終わりが、見えない。
いつまで、こんなことを続けるんだろう。
```

---

### シーン2：レオンとの会話（〜3,500字）

**内容**:
- レオンと二人で話す
- 故郷の話、家族の話
- 「戦争が終わったら」
- 友情の深化

**会話**:
```
「エルヴィン」

夜、レオンが声をかけてきた。
焚き火の近く。

「……なんだ」
「お前、故郷に誰かいるのか」
「……ああ」
「彼女？」
「……幼馴染だ」
「へえ」

レオンが、笑った。

「俺には、妹がいる。三人」
「……そうか」
「うるさいけど、可愛いんだ」
「……」
「早く帰りたいよ」
```

**約束**:
```
「戦争が終わったら、どうする？」

レオンが聞いた。

「……分からない」
「俺は、故郷に帰る。妹たちの面倒を見る」
「……そうか」
「お前は？」
「……帰る。アリシアのところに」
「いいな」

レオンが、笑った。

「一緒に帰ろうな」
「……ああ」
「約束だ」
「……約束だ」

握手した。
レオンの手は、温かかった。
```

---

### シーン3：大会戦の噂（〜2,500字）

**内容**:
- 「大規模な戦闘がある」という噂
- 春になれば、攻勢が始まる
- 不安と緊張
- でも、まだ先の話

**噂**:
```
「聞いたか？」

誰かが言った。

「春になったら、大きな戦闘があるらしい」
「大会戦か」
「ああ。数千人規模だって」
「……」

大会戦。
今までで一番大きな戦闘。

「……」

不安が、胸に広がった。
```

**レオンの反応**:
```
「大会戦、か」

レオンが言った。

「怖いな」
「……ああ」
「でも、生き延びるしかない」
「……ああ」
「一緒に帰るって、約束しただろ」
「……ああ」

レオンが、笑った。
俺も、笑おうとした。
でも、うまく笑えなかった。
```

---

### シーン4：ルシウスとの夜（〜1,500字）

**内容**:
- 夜、ルシウスと話す
- 「大会戦、楽しみだね」
- ルシウスの無邪気な残酷さ
- エルヴィンの複雑な感情

**会話**:
```
「大会戦、楽しみだね」

夜、ルシウスが言った。

「……楽しみ？」
「うん。大きな戦闘、久しぶり」
「……」
「たくさん死ぬんだろうね」
「……」
「面白そう」

その言葉に、何も言えなかった。
ルシウスには、分からない。
死ぬのは、俺たちなんだ。
```

**沈黙**:
```
「……お前は、怖くないのか」
「怖い？　何が？」
「死ぬことが」
「僕、死なないよ？　幽体だもん」
「……」
「君は怖いの？」
「……ああ」
「へえ」

ルシウスが、首を傾げた。

「でも、僕がいるから大丈夫だよ」
「……」
「君、死なせないから」

その言葉が、少しだけ、心に残った。
```

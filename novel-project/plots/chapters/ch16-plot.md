## 章の目的

### 物語上の役割
1. 罪悪感の身体化（悪夢、不眠）
2. 殺した敵兵の「顔」を意識し始める
3. ルシウスの無理解
4. アリシアへの手紙（書けない）
5. 心身の消耗

### 読者への効果
- 戦争の心理的影響
- 罪悪感の重さ
- 「見ていただけ」でも苦しむ

### ch15との連続性
- ch15：五度目の戦闘、虚しさの始まり
- ch16：六度目、七度目の戦闘後、悪夢が始まる

## シーン構成

### シーン1：悪夢（〜3,500字）

**内容**:
- 夜、悪夢を見る
- 殺した敵兵の顔
- 「なぜ俺を殺した」
- 目が覚める、汗びっしょり

**悪夢の描写**:
```
暗闇の中に、顔が浮かんでいる。
知らない顔。でも、見覚えがある。
「お前が、俺を殺したのか」
「……」
「なぜだ。俺は、何もしていない」
「……」
「俺にも、家族がいた。待っている人がいた」
「……」
「お前が、殺したんだ」
「違う、僕じゃない、ルシウスが……」
「お前の体だろう。お前の手だろう」
「……」
「お前が、殺したんだ」
```

**目覚め**:
```
目が覚めた。
汗びっしょりだった。
心臓が、激しく鳴っている。
「……夢」
夢だ。ただの夢だ。
でも、顔は覚えている。
殺した敵兵の顔。
「……」
眠れなかった。
```

---

### シーン2：ルシウスの無理解（〜3,000字）

**内容**:
- 「なんで悩んでるの？」
- 「殺したからだ」
- 「でも、殺さなきゃ死んでたよ？」
- 「それでも…」
- 「人間って、変なの」

**会話**:
```
「ねえ、なんで悩んでるの？」
「……殺したから」
「殺した？　僕がね」
「僕の体で」
「そうだね。で、何が問題なの？」
「……人を殺した」
「うん。殺さなきゃ、君が死んでたよ？」
「……それでも」
「それでも？」
「……分からない」
「人間って、変なの。殺さなきゃ死ぬのに、殺したら悩む」
「……」
「僕には、分からないな」
```

**ルシウスの観察**:
```
「でも、面白いね」
「……何が」
「君、壊れそう」
「……」
「壊れたら、どうなるんだろう。見てみたいな」
「……お前」
「冗談だよ。壊れたら困るもん。僕、また一人になっちゃう」
```

---

### シーン3：アリシアへの手紙（〜3,000字）

**内容**:
- 故郷から手紙が届く
- 「元気にしてる？　待ってるよ」
- 返事を書こうとする
- 「元気です」としか書けない

**アリシアの手紙**:
```
「エルヴィンへ
元気にしてる？
こっちは、いつもと変わらないよ。
お店の手伝いをしたり、本を読んだり。
でも、毎日、あなたのことを考えてる。
早く帰ってきてね。
待ってるから。
アリシアより」
```

**返事を書く**:
```
「アリシアへ
元気だ」
……書けない。
「戦闘があった」
……書けない。
「人を殺した」
……書けない。
「元気だ。心配しないでくれ」
それだけ書いて、手が止まった。
嘘だ。
元気じゃない。
でも、本当のことは書けない。
「僕は、もう君の知っている僕じゃない」
```

---

### シーン4：心身の消耗（〜2,500字）

**内容**:
- 食事が喉を通らない
- 痩せた
- 目の下に隈
- レオンの心配

**身体症状**:
```
食事の時間。
スープを口に運ぶ。
……飲み込めない。
肉を見ると、血を思い出す。
「……」
パンだけ、少し齧った。
「エルヴィン、食べないのか」
レオンの声。
「……腹、減ってない」
「嘘だろ。お前、最近全然食べてないじゃないか」
「……」
「大丈夫か？」
「……大丈夫」
嘘だ。
大丈夫じゃない。
```

**レオンの心配**:
```
「お前、痩せたな」
「……そうか」
「目の下、隈できてるぞ」
「……」
「眠れてないのか」
「……少し」
「何かあったのか」
「……いや、何も」
また、嘘をついた。
```

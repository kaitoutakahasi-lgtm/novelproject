## 5. 具体的修正案

### 修正案1：徴兵の前兆（2章に追加）
```
市場で、見知らぬ女が泣いていた。

「息子が……息子が連れていかれた……」

周りの人々が、目を逸らしている。誰も、声をかけない。

「まだ十四なのに……」

僕は、その場を離れた。見ていられなかった。

でも、心のどこかで思っていた。

あれは、他人事だ。僕には、関係ない。
```

### 修正案2：ルシウスの必然性（6章に追加）
```
「ずっと、見ていたんだ」

ルシウスが、言った。

「君が野営地に来た時から。いや、もっと前から」
「……なぜ」
「分からない。ただ、君に惹かれた」

ルシウスは、空を見上げた。

「千年以上、人間を見てきた。でも、君みたいな目をした人間は、初めてだった」
「僕の目？」
「灰色の目。何も映していないようで、全てを見ている目」
```

### 修正案3：レオンの背景（4章に追加）
```
「なあ、エルヴィン」
「なに」
「俺、志願したんだ」
「……え？」

レオンが、苦笑した。

「徴兵じゃない。自分から、志願した」
「なぜ」
「金だよ。志願兵には、前金が出る」

レオンは、空を見上げた。

「妹が三人いるんだ。親父は去年死んだ。俺が稼がないと、みんな飢える」
「……」
「だから、志願した。死ぬかもしれないけど、家族が生きられるなら」

その言葉が、胸に刺さった。

僕は、自分のことしか考えていなかった。死にたくない、帰りたい、怖い。

レオンは、家族のために命を賭けている。

僕とは、違う。
```

### 修正案4：道徳心低下の具体化（5章に追加）
```
訓練中、一人の少年が倒れた。

「立て」

ガレスの声が、響く。

少年は、立てなかった。足が、震えている。顔が、蒼白だ。

「立てないなら、置いていく」

ガレスが、歩き出した。他の少年たちも、続いた。

僕も、歩き出した。

振り返らなかった。

倒れた少年の顔を、見なかった。見たら、止まってしまう気がした。

「……ごめん」

心の中で、呟いた。

でも、足は止まらなかった。
```

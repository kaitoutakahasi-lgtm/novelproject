## シーン構成

### シーン1：出発の朝（約3,000字）
**目的**: 家族との別れ、アリシアのお守り、「振り返らない」決意

**要素**:
- 眠れなかった夜明け
- 家族との別れ（父の肩叩き、兄の言葉、母の抱擁）
- 広場での集合
- アリシアのお守り
- 「振り返らない」という決意

**感情曲線**: 悲しみ → 決意

### シーン2：行軍（約3,000字）
**目的**: レオンとの再会、友情の確認、他の少年たちの描写

**要素**:
- 五十人ほどの徴兵された少年たち
- 引率の兵士の厳しさ
- レオンとの再会
- レオンの事情（志願兵、家族のため）
- 「一緒に生き延びよう」という約束

**感情曲線**: 孤独 → 安堵 → 連帯

### シーン3：最初の夜（約3,000字）
**目的**: 野営、故郷への思い、星のモチーフ

**要素**:
- 野営の準備（毛布一枚）
- レオンとの会話
- 星を見上げる
- 「普通」への憧れ
- 帰還の約束

**感情曲線**: 不安 → 静けさ → 希望

### シーン4：前線への道（約3,000字）
**目的**: 戦場の気配、恐怖の増大、野営地到着

**要素**:
- 三日目の変化
- 煙の匂い、焦げた匂い
- 恐怖の増大
- 野営地の光景
- 「地獄へようこそ」

**感情曲線**: 緊張 → 恐怖

## 伏線配置

### 配置する伏線
1. **アリシアのお守り** → 後の支えになる
2. **レオンの明るさ** → 後の死への伏線
3. **「一緒に生き延びよう」** → 果たされない約束
4. **星のモチーフ** → 孤独と希望の象徴
5. **「普通」への憧れ** → 後の喪失感

### 回収する伏線
- 第3章の「灰色ではない日」→ 本章で戦場へ向かう

## 文体注意点

1. **別れの描写**
   - 感傷的になりすぎない
   - 行動で感情を表現
   - 短い会話、長い沈黙

2. **レオンの描写**
   - 明るさの中の不安
   - エルヴィンとの対比（能動的 vs 受動的）
   - 後の死への伏線を自然に

3. **恐怖の描写**
   - 14歳の視点
   - 具体的な感覚（煙、匂い、音）
   - 徐々に増大する緊張感

4. **会話バランス**
   - 会話40%以下
   - 内省50%以上
   - 情景描写を織り交ぜる

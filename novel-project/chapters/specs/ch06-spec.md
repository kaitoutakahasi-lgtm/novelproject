## シーン構成

### シーン1：逃亡の夜（約3,500字）
**目的**: 限界、逃亡、死の覚悟

**要素**:
- 一週間の訓練で限界
- レオンとの差
- 夜中に野営地を抜け出す
- 森の中で死を覚悟

**感情曲線**: 絶望 → 諦め

### シーン2：ルシウスとの出会い（約4,000字）
**目的**: ルシウス登場、エルヴィンの驚愕

**要素**:
- 月明かりの中の異様な少年
- 銀髪、白い肌、桃色の目
- 「面白いから」という興味
- 名前を忘れる軽さ

**感情曲線**: 恐怖 → 困惑

### シーン3：契約の詳細（約4,000字）
**目的**: 憑依の説明、代償の説明

**要素**:
- 憑依の仕組み
- 寿命との等価交換
- ルシウスの軽い態度
- 「なんで僕なんだ」

**感情曲線**: 困惑 → 葛藤

### シーン4：決断（約3,500字）
**目的**: 葛藤、決断、契約成立

**要素**:
- アリシアとの約束を思い出す
- 「帰りたい」という願い
- 契約の決断
- 契約成立の瞬間

**感情曲線**: 葛藤 → 決意

## 伏線配置

### 配置する伏線
1. **ルシウスの外見** → 人間ではない存在
2. **「面白いから」** → おもちゃ的な興味
3. **名前を忘れる** → 人の心がわからない
4. **憑依の仕組み** → 後の展開への伏線
5. **等価交換** → 寿命との引き換え

### 回収する伏線
- 第5章の「甘い匂い」→ ルシウスの存在
- 「力が欲しい」→ 契約による力

## ルシウスのキャラクター

### 外見
- 銀色の髪（月明かりで輝く）
- 病的に白い肌
- 桃色の目（人間ではない）
- 10-11歳くらいの少年の姿

### 口調
- 子供らしい無邪気さ
- 時々残酷な言葉
- 「〜だよね」「〜なの」

### 態度
- 好奇心旺盛
- 人の心がわからない
- 「暇だから」「面白いから」

## 文体注意点

1. **ルシウスの描写**
   - 美しさと恐ろしさの両立
   - 子供らしさと残酷さの同居
   - 人間ではない異質さ

2. **契約の重み**
   - 軽々しくない決断
   - 葛藤の描写
   - 「生き延びたい」という切実さ

3. **会話バランス**
   - ルシウスとの対話は例外的に多め
   - しかし内省も十分に
   - ルシウスの台詞は短く印象的に

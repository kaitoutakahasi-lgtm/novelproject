# 執筆スタイルガイド

## 重要：プロットと執筆の違い

**プロット内のサンプル文章は「方向性の参考」であり、そのまま使用してはならない。**

執筆時は必ず以下のルールに従い、プロットのサンプル文章を本ガイドの文体で書き直すこと。

---

## 基本方針

### 視点
- **一人称**（エルヴィン）で一貫
- 例外：エピローグのみ多視点の可能性

### 文体
- 純文学的
- 心理描写重視（行動より思考）
- 詩的・比喩的表現の多用
- 会話は少なめ、沈黙と行間に意味を持たせる
- **説明と描写の融合**：情報を物語に溶け込ませる

### 描写の重点
1. 内的独白
2. 感覚描写
3. 比喩・象徴
4. 時間経過の表現

## サンプル文章（ch01-03より抽出）

### 【サンプル1】冒頭・情景と内省の融合

```
　曇り空が、濡れた石畳に映っている。

　僕は――エルヴィン・クライスは、店の軒先で空を見上げていた。十三歳の春。まだ少年と呼ぶには幼く、しかし子供と呼ぶには遠い、曖昧な年齢。鈍色の瞳で、鈍色の空を見つめる。

　ミューレン。ヴェルナント王国の辺境に位置する、小さな町。人口は三千人ほど。商人と農民が半々。特に名産もなく、特に歴史もなく、ただ古くからそこにあるというだけの、地味な町。
```

**特徴**:
- 一文目は情景のみ（短く、印象的に）
- 二文目で主人公を導入（「僕は――」で一人称を明示）
- 三文目以降で場所の説明を「物語に溶け込ませる」
- 「灰色」「鈍色」「曖昧」など、モチーフを自然に配置
- 説明文でも「ただ古くからそこにあるというだけの」のように感情を込める

### 【サンプル2】会話と内省の組み合わせ

```
「エルヴィン、棚の整理を頼む」

　父の声が店の奥から聞こえる。低く、穏やかで、感情の起伏がほとんどない声。

「はい」

　僕は答えて、店に入る。薄暗い店内。小さな窓から差し込む光が、埃を照らしている。商品が並ぶ棚。どれも似たような色。茶色、鉛色、黒。鮮やかな色はない。
```

**特徴**:
- 会話は短く、必要最小限
- 会話の後に「声の描写」を入れる（低く、穏やかで、感情の起伏がほとんどない）
- 返事の後に情景描写を挟む
- 体言止めを効果的に使用（「薄暗い店内。」「商品が並ぶ棚。」）
- 色彩で雰囲気を作る

---

### 【サンプル3】内省・問いかけと沈黙

```
　母は幸せなのだろうか。

　貴族の娘として生まれ、没落し、商人の妻となり、辺境の町で一生を終える。それは幸せなのだろうか。

　聞けなかった。聞いたところで、母は答えないだろう。母はいつも微笑んでいる。穏やかに、静かに、何も語らずに。
```

**特徴**:
- 問いかけで始める（「〜だろうか。」）
- 同じ問いを言い換えて繰り返す（深化）
- 「聞けなかった。」で短く断ち切る
- 三連の副詞（「穏やかに、静かに、何も語らずに」）でリズムを作る

---

### 【サンプル4】感情の間接表現

```
　僕は、母の背中に手を回した。

　何も言えなかった。何を言えばいいのか、分からなかった。

　ただ、怖かった。

　死ぬかもしれない。

　その恐怖が、全身を支配していた。
```

**特徴**:
- 「悲しかった」「怖かった」を直接言わず、行動と状況で示す
- 短文を重ねて緊張感を出す
- 「ただ、怖かった。」のように、一文だけ感情を直接述べる（効果的に使う）
- 「死ぬかもしれない。」を独立させて強調

---

### 【サンプル5】場面転換と時間経過

```
　　　　　　　　　　＊


　秋になって、空気が変わった。

　市場で泣いている女を見た。

「息子が……息子が連れていかれた……」

　周りの人々が、慰めるように声をかけている。でも、女は泣き止まなかった。

　徴兵。

　その言葉が、初めて現実味を帯びた。
```

**特徴**:
- 「＊」で場面転換
- 季節の変化で時間経過を示す
- 具体的なエピソード（泣いている女）で抽象的な概念（徴兵）を実感させる
- 「徴兵。」を独立させて印象づける
- 「初めて現実味を帯びた」で主人公の認識の変化を示す

---

### 【サンプル6】対話シーン（感情的な場面）

```
「ねえ、エルヴィン」

「なに」

「約束して」

「何を」

「必ず、帰ってくるって」

　彼女の目が、僕を見ていた。涙で濡れた、青い瞳。

「約束する」

「本当に？」

「本当だ。必ず、帰ってくる」

　彼女が、僕の手を握った。冷たかった。でも、その冷たさが、心に残った。
```

**特徴**:
- 会話は短く、一言ずつ
- 会話の間に描写を挟む（「彼女の目が、僕を見ていた。」）
- 感覚描写（「冷たかった」）で感情を伝える
- 「でも、その冷たさが、心に残った。」で余韻を残す

## 文体の詳細ルール

### 1. 段落の構成

**基本パターン**:
```
[情景/状況] → [行動] → [内省/感情]
```

**例**:
```
　窓の外を見る。灰色の空。灰色の町。    ← 情景
　
　僕は、一人になった。                  ← 状況
　
　逃げられない。                        ← 内省
　
　でも、生きて帰る。                    ← 決意
　
　それだけを、考えることにした。        ← 締め
```

### 2. 文の長さのバランス

- 長文（情景・説明）と短文（感情・強調）を交互に
- 短文の連続は3文まで
- 長文の連続は2文まで

**良い例**:
```
　僕は棚の前に立ち、商品を整理し始める。鍋を大きさ順に並べる。皿を種類ごとに分ける。単調な作業。何も考えなくていい作業。

　好きだった。

　何も考えなくていい時間が、僕は好きだった。
```

### 3. 体言止めの使い方

- 情景描写で効果的に使用
- 連続は3回まで
- 感情を込めた体言止めは1回で止める

**良い例**:
```
　薄暗い店内。小さな窓から差し込む光。埃を照らしている。
```

**悪い例**:
```
　薄暗い店内。小さな窓。差し込む光。埃。商品。棚。
```

### 4. 繰り返しの技法

- 同じ言葉を繰り返して強調
- ただし、意味を深化させながら

**良い例**:
```
　大丈夫じゃない。

　分かっていた。母も、分かっていた。

　でも、そう言うしかなかった。
```

### 5. 会話の前後

- 会話の前：状況や話者の様子
- 会話の後：反応や内省
- 会話だけで終わらせない

## プロットからの書き直し例

### プロットのサンプル（参考用）:
```
「君、面白いね」
「え？」
「泣いてるのに、諦めてない顔してた」
「……」
「矛盾してるよね。人間って、みんなそうなの？」
```

### 執筆時の書き直し:
```
「君、変わってるね」

　ルシウスが、首を傾げた。子供らしい仕草。でも、目は笑っていない。

「泣いてるのに、諦めてない顔してた」

「……」

「矛盾してるよね」

　その言葉に、僕は何も言えなかった。矛盾。確かに、そうかもしれない。死にたいのに、死にたくない。逃げたいのに、逃げられない。

「人間って、みんなそうなの？」

　ルシウスは、本当に分からないという顔をしていた。

　僕にも、分からなかった。
```

**変更点**:
- 会話の間に描写を挿入
- 内省を追加（「矛盾。確かに、そうかもしれない。」）
- ルシウスの様子を描写（「子供らしい仕草。でも、目は笑っていない。」）
- 最後に主人公の反応で締める

## 文章のリズム

### 基本リズム
- 長めの文で情景・内省を描く
- 短い文で転換・強調
- 一行空けで間を作る

### 例
```
薄暗い店内。小さな窓から差し込む光が、埃を照らしている。商品が並ぶ棚。
どれも似たような色。茶色、灰色、黒。鮮やかな色はない。華やかさはない。

僕は棚の前に立ち、商品を整理し始める。

好きだった。

何も考えなくていい時間が、僕は好きだった。
```

## 比喩・象徴の使い方

### 色彩の象徴
| 色 | 象徴 | 使用場面 |
|----|------|----------|
| 灰色 | 平凡、曖昧、日常、諦念 | エルヴィンの日常、内面 |
| 桃色 | 生と死の境界、ルシウス | ルシウス登場時 |
| 赤 | 血、罪、暴力 | 戦闘、罪悪感 |
| 白 | 純粋、喪失、虚無 | 雪、月、過去 |
| 黒 | 闘、絶望、死 | 夜、恐怖 |

### 自然の比喩
| 要素 | 象徴 | 使用場面 |
|------|------|----------|
| 雨 | 憂鬱、浄化されない罪 | 戦場、葛藤 |
| 泥 | 汚れ、戦場、現実 | 戦闘後、罪悪感 |
| 星 | 憧れ、永遠、孤独 | 内省、希望 |
| 月 | 変わらないもの、孤独 | ルシウスの孤独 |
| 埃 | 停滞、時間の堆積 | 日常、店内 |

## 場面別ガイド

### 日常シーン
- 単調さの中の心地よさを描く
- 情報を物語に溶け込ませる
- 「何も起きない」ことの価値

### 戦闘シーン
- 美化しない
- 恐怖と混乱を中心に
- 五感を使う（特に嗅覚、触覚）

### 憑依シーン
- 冷たさ、異物感
- 身体の支配を失う恐怖
- 内側から見ている感覚

### ルシウスとの対話
- 子供らしい口調と残酷な内容のギャップ
- エルヴィンの内的反応を丁寧に

### アリシアとのシーン
- 温かさと隠し事の苦しさ
- ルシウスとの対比

# 装飾タグ一覧

Web小説プラットフォーム用の装飾タグリファレンス。

---

## 基本テキスト装飾

### 太字
```
《b》太字テキスト《/b》
```
**用途**: 強調、重要な言葉、心理的インパクト

### 斜体
```
《i》斜体テキスト《/i》
```
**用途**: 内的独白の強調、外国語、特殊な概念

### 下線
```
《u》下線テキスト《/u》
```
**用途**: 重要な固有名詞、キーワード

### 取り消し線
```
《s》取り消しテキスト《/s》
```
**用途**: 訂正、否定された思考、自己否定

---

## ルビ（振り仮名）

### 基本形
```
《ruby》漢字《rt》ふりがな《/rt》《/ruby》
```

### 使用例
```
《ruby》憑依《rt》ひょうい《/rt》《/ruby》
《ruby》桃紙《rt》ももがみ《/rt》《/ruby》
《ruby》契約《rt》けいやく《/rt》《/ruby》
```

### 本作での主要ルビ
| 漢字 | ルビ | 説明 |
|------|------|------|
| 憑依 | ひょうい | 魔法システムの核心 |
| 桃紙 | ももがみ | タイトル、契約書 |
| 誓約 | せいやく | 契約の別称 |
| 王暦 | おうれき | 時代設定 |

## 色彩タグ

### 基本形
```
《color:#XXXXXX》テキスト《/color》
```

### 本作での色彩使用ガイド

#### 桃色（ルシウス関連）
```
《color:#FFB6C1》桃色のテキスト《/color》
```
**用途**: ルシウスの登場、契約関連、生と死の境界

#### 灰色（エルヴィンの内面）
```
《color:#808080》灰色のテキスト《/color》
```
**用途**: 絶望、曖昧さ、日常の虚無

#### 赤（血・罪）
```
《color:#8B0000》暗い赤のテキスト《/color》
```
**用途**: 戦闘、罪悪感、暴力の記憶

#### 白（純粋・喪失）
```
《color:#F5F5F5》白いテキスト《/color》
```
**用途**: 過去の記憶、純粋さの喪失

## 本作での使用ガイドライン

### 使用頻度
- **ルビ**: 必要に応じて（初出時は必須）
- **太字**: 控えめに（章に2-3回程度）
- **色彩**: 非常に控えめに（重要シーンのみ）
- **傍点**: 効果的に（章に1-2回程度）

### 避けるべき使用
- 過度な装飾（純文学の品位を損なう）
- 色の乱用（視覚的ノイズになる）
- 説明的な強調（読者の想像力を奪う）

### 推奨される使用
- ルシウス登場時の桃色
- 契約関連の重要語へのルビ
- 心理的転換点での傍点
- シーン転換での水平線

## 注意事項

1. **プラットフォーム互換性**: タグはプラットフォームによって異なる場合がある
2. **プレビュー確認**: 投稿前に必ずプレビューで確認
3. **バックアップ**: タグなしのプレーンテキスト版も保存
4. **一貫性**: 同じ要素には同じタグを使用

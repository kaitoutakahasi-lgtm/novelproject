## 性格

### コア特性
- 冷徹な戦略家
- しかし部下への情もある
- 責任感が強い
- 学究的（古代史の研究者）
- 家族を失った悲しみを抱える

### 行動パターン
- 感情を表に出さない
- 常に最悪を想定
- 長期的視野で判断
- 部下の才能を見抜く
- しかし冷酷な決断もできる

### 価値観
- 「国家」を何より優先
- しかし「人の命」も大切にする
- 「正義」より「責任」
- 過去の過ちを繰り返さない

### 口調
```
「報告しろ」
「了解した」
「お前に任せる」
簡潔、冷静、しかし時折温かみがある
```

## 弟エーリヒとの過去（30年前）

### 回想シーンの配置計画
読者にマクシミリアンの動機を伝えるための回想シーン：

| 章 | 内容 | 目的 |
|----|------|------|
| 第29章 | エーリヒの名前の言及 | 伏線配置 |
| 第35章 | エーリヒの最期の回想（短） | 動機の示唆 |
| 第40章 | 完全な回想 | 動機の完全な理解 |

### エーリヒの契約
- 弟エーリヒ（25歳）、古代遺跡調査中にルシウスと遭遇
- 霊的感受性が高く、ルシウスを視認
- 契約を結ぶ

### マクシミリアンの警告
- 弟の様子がおかしいことに気づく
- エーリヒ「兄さん、僕には見えるんだ。古代の子供が」
- 最初は精神疾患を疑う
- しかしエーリヒの戦闘能力が異常に向上

### 真実の発見
- エーリヒ、3年後に古文書で「災厄の子」の記述を発見
- 教会に歪められた歴史のみ「エルドラシアを滅ぼした悪魔の王子」
- エーリヒ、恐怖してルシウスを再封印しようとする

### 破綻
```
ルシウス「君、僕を見る目が変わったね」
エーリヒ「お前は…悪魔なのか？」
ルシウス「悪魔？　そうかもね。でも、僕たち友達じゃなかったの？」
エーリヒ「友達…？　そんなわけ…」
ルシウス「やっぱり、裏切るんだ。みんな、そうだ」
```

### 結末
- 契約破棄を試みるエーリヒ
- 契約魔法が暴走
- エーリヒの精神に重大なダメージ、廃人同然に
- 3年後に死亡

### マクシミリアンの決意
- 弟の最期を看取る
- エーリヒの日記を発見、ルシウスの存在を知る
- 「あの悪魔が、弟を壊した」
- 「次の犠牲者を出してはならない」

## エルヴィンとの関係

### 第四部（22-25歳）：師弟
- **才能の発見（第18章）**: 側近に抜擢「お前の才能を、活かしてもらう」
- **教育**: 戦略の教育、政治の教育
- **疑念（第18章後半）**: エルヴィンの目に「何か」を見る「弟と似ている」

### 第五部（26-28歳）：警戒
- **確信（第29章）**: 「お前に憑いているもの、それは古代の災厄だ」
- **対話**:
```
マクシミリアン「30年前、私の弟も、同じものに憑かれた」
「あの悪魔が、弟を壊した」
「お前も、同じ道を辿る」
エルヴィン「将軍、それは誤解です」
マクシミリアン「お前はまだ救える。あの悪魔を、今度こそ封じる」
```

### 第六部（29-32歳）：対立
- **決意（第35章）**: 「お前は、世界を危険に晒そうとしている」

### 第七部（33歳）：最終決戦
- **遺跡での対峙（第40章）**:
```
マクシミリアン「エルヴィン、お前を止める」
「私は、弟を救えなかった」
「だが、お前は救える」
エルヴィン「将軍…」
マクシミリアン「お前は、まだ人間だ」
```
- **一騎打ち**: 57歳の身体で戦う、魔法による身体強化、しかしエルヴィンに敗れる
- **最期**:
```
マクシミリアン「お前は…間違っている…」
エルヴィン「分かっています」
マクシミリアン「ならば…なぜ…」
エルヴィン「止められないんです」
マクシミリアン「……そうか」
「弟と…同じか…」
「すまない…エーリヒ…」
「また…救えなかった…」
```

## 物語上の役割

1. **エルヴィンの最後の障害**: 封印解除を阻む存在、しかし「悪」ではない
2. **過去と現在の繋がり**: エーリヒの失敗、歴史の繰り返し
3. **悲劇性の強調**: マクシミリアンは「正しい」、誰も悪くない戦い

## 執筆時の注意点

1. **冷徹だが人間的**: 弟への愛情は深い
2. **誤解と真実**: 半分しか真実を知らない、教会の歪曲された歴史を信じている
3. **最終決戦の描写**: 老いた身体で戦う悲壮感、「弟を救えなかった」後悔

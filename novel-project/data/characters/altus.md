# アルトゥス・エルンスト（故人）

## 基本情報
- **フルネーム**: アルトゥス・エルンスト (Altus Ernst)
- **享年**: 58歳
- **死亡時期**: 300年前（王暦223年）
- **役職**: エルドラシア魔導王国宮廷魔導士長
- **関係**: ルシウスの魔法教師（8年間）
- **登場**: 回想シーンのみ（第六部）

---

## 外見（50代）
- 身長: 180cm
- 体格: 痩せ型、学者らしい
- 髪: 灰色、長め、後ろで束ねる
- 瞳: 深い青色
- 顔立ち: 知的、優しい目
- 服装: 魔導士のローブ、質素

---

## 性格
- 温厚で学究的
- 理想主義者だが現実の限界も知る
- 弟子思い
- 責任感が強い
- 優しさと弱さを併せ持つ

---

## 能力
- **魔法**: S級（国最高レベル）
- **専門**: 封印魔法、契約魔法
- **知識**: 古代魔法の研究者

---

## ルシウスとの関係

### 0-5歳期
- ルシウス誕生時、その魔力に驚嘆
- 「この子は祝福か、呪いか」
- 教育係に任命される
- 唯一「一人の子供」として接しようとした
- しかし周囲は恐れ、利用しようとする
- アルトゥスの力では変えられない

### 6-8歳期
- ルシウスの魔力が制御不能レベルに
- 宮廷内で「危険視」される
- アルトゥス「彼はまだ子供だ。時間をくれ」
- ルシウスの孤立を止められない

### 崩壊の夜

**最後の対話**:
```
ルシウス「先生、世界って壊れやすいのかな？」
アルトゥス「何を言っているんだ？」
ルシウス「試してみたくなったんだ」
```

**対峙**:
- 王都崩壊の中、二人だけが魔法障壁の中に
- アルトゥス「なぜこんなことを…！」
- ルシウス「だって、つまらなかったから」
- アルトゥス、初めてルシウスを殴る
- ルシウス、初めて「痛み」を感じて笑う

**決断**:
```
「お前を殺すべきだ」
「しかし、それは私の敗北だ」
「私は教師として、お前に何も教えられなかった」
「力の使い方は教えた。だが、生きる意味は教えられなかった」
```

## 封印魔法の発動

### 封印の設計思想
```
「ルシウス、お前はまだ子供だ」
「大人が、私が、お前を導けなかった」
「お前に罪はない。罪があるのは、お前を孤独にした世界だ」
「だから、殺さない」
「だが、このまま放置もできない」
```

### 封印の条件
- 肉体の封印：力を奪う
- 感情の封印：成長の機会を与える
- 孤独の封印：世界から隔絶する
- 解放の条件：「本当の信頼」を学ぶまで

### アルトゥスの願い
```
「お前に欠けているのは、信じることと信じられることだ」
「誰かがお前を見捨てずに、お前も誰かを見捨てない」
「その時、お前は初めて人間になれる」
「それまで、眠っていなさい」
```

### 最期の言葉
```
「すまない、ルシウス」
「私はお前の先生として、失格だった」
「だが、いつか…いつか誰かが、お前を救ってくれると信じている」
「その人に出会えたなら、今度こそ…信じなさい」
```

---

## ルシウスへの影響

### 封印直後
- ルシウス、初めて涙を流す（理解できないまま）
- 「先生…これは、何？」
- 「目から水が…止まらない…」

### 300年間
- アルトゥスの言葉が心に残る
- 「先生は僕を裏切った」と思う時期
- 「先生は僕を愛していた」と気づく時期
- 「先生の願いを、叶えたい」と思う時期

### エルヴィンとの関係
- エルヴィン「彼は、お前を愛していたんだ」
- ルシウス「……知ってる。だから、辛かった」

### 封印解除後
- ルシウス、アルトゥスの墓前に
- 「先生、遅くなったけど、僕、少し分かった気がする」
- 「ありがとう」

---

## 遺したもの

### 封印魔法陣
- エルドラシア遺跡最深部に現存
- アルトゥスの生命を代償にした最高位の封印
- 300年経っても機能している

### 日記（第32章で発見）
- ルシウスへの愛情と後悔が綴られている
- エルヴィンがルシウスの真実を知る手がかり

**重要な記述**:
```
「この子に罪はない。
罪があるのは、この子を導けなかった私だ。
この子を孤独にした、私たち大人だ。
いつか、誰かが、この子を本当に理解してくれる。
この子も、その人を信じることができる。
その時、この子は初めて人間になれる。
私は、それを信じている。」
```

## 物語上の役割

1. **ルシウスの過去の鍵**: 封印の真実、ルシウスの孤独の原因
2. **テーマの体現**: 「大人の責任」「愛と教育」「贖罪と救済」
3. **エルヴィンへの影響**: アルトゥスの日記がエルヴィンの選択に影響

## 執筆時の注意点

1. **回想シーンでの描写**: 温厚だが、葛藤も描く
2. **ルシウスの記憶の中**: 美化されていない、「先生も、完璧じゃなかった」
3. **テーマとの関連**: アルトゥスの願いが、300年越しに叶う

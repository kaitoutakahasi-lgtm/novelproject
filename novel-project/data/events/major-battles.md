# 主要戦闘イベント

## ヴェルナント-ザルヴァトール戦争

### 基本情報
- **国境紛争開始**: 王暦520年（エルヴィン10歳時）
- **宣戦布告**: 王暦522年
- **大規模侵攻**: 王暦523年春
- **原因**: 国境地帯の領有権争い、古代遺跡の支配権
- **規模**: 徐々に拡大
- **戦況**: 一進一退
- **終結**: 王暦545年（第七部）

### 影響
- 徴兵年齢の引き下げ（16歳→15歳）
- 重税
- 物価上昇
- 民衆の疲弊

- **内容**:

## 戦闘描写のガイドライン

### 基本方針
- 美化しない
- 恐怖を中心に
- 混乱を表現
- 五感を使う

### 五感別描写ガイド

#### 視覚
```
- 血の色（赤→黒ずむ）
- 泥と血が混じる
- 視界が揺れる、ぼやける
- 敵の顔（若い、怖がっている）
- 死体の目（開いている、閉じている）
```

#### 聴覚
```
- 金属音（剣と剣、剣と鎧）
- 叫び声（怒り、恐怖、苦痛）
- 肉を切る音（鈍い、湿った）
- 骨が折れる音
- 自分の心臓の音
- 突然の静寂
```

#### 嗅覚
```
- 血の匂い（鉄の匂い）
- 泥の匂い
- 汗の匂い
- 排泄物の匂い（死体から）
- 煙の匂い
```

#### 触覚
```
- 剣の重さ
- 衝撃（受ける、与える）
- 血の温かさ、冷たさ
- 泥の感触
- 震える手
- 痛み（鋭い、鈍い）
```

#### 味覚
```
- 血の味（口の中を切った）
- 土の味（倒れた時）
- 吐き気
```

### 時間感覚の描写
```
- 一瞬が長く感じる
- 逆に、気づいたら終わっている
- 記憶が飛ぶ
- 後から思い出す
```

### 描写例（詳細版）
```
剣が、振り下ろされる。
避けられない。
速すぎる。

肩に、衝撃。
痛い。
すごく、痛い。
熱い。
いや、冷たい。
分からない。

視界が、揺れる。
地面が、近づいてくる。
倒れる。

土の匂い。
血の匂い。
鉄の匂い。
自分の血か。
敵の血か。
分からない。

誰かが、叫んでいる。
誰かが、倒れる音。
誰かが、死んでいく。

心臓が、うるさい。
ドクドクドクドク。
止まらない。
止まったら、死ぬ。

僕は、ただ、震えていた。
```

### 憑依中の戦闘描写
```
- エルヴィンは「見ている」だけ
- 自分の身体が動くのを内側から見る
- 制御できない恐怖
- ルシウスの動きは美しいが残酷
- 終わった後の虚脱感
```

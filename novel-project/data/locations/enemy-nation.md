# ザルヴァトール帝国（敵国）

## 基本情報
- **正式名称**: ザルヴァトール神聖帝国 (Salvator Holy Empire)
- **通称**: 帝国、東の大国
- **首都**: イグナティウス（人口約15万、王国首都の3倍）
- **人口**: 約800万人（ヴェルナント王国の約2倍）
- **政治体制**: 神権帝政（皇帝＝神の代理人）
- **建国**: 約400年前（エルドラシア滅亡後の混乱期に台頭）

### 国境地帯
- **グラウヴァルト山脈**: 両国の自然国境、鉄・銀・魔鉱石の産地
- **ヴェルデン峠**: 唯一の大規模通行路、軍事的要衝
- **灰の平原**: 300年前のエルドラシア滅亡時に焦土化、今も草木が育たない
- **エルドラシア遺跡**: 灰の平原の中心、両国の係争地

## 戦争の原因

### 表向きの理由（帝国の主張）
- **領土紛争**: 「グラウヴァルト山脈は古来より帝国領」
- **宗教的使命**: 「異教徒を正しき信仰に導く聖戦」
- **交易路支配**: 「ヴェルデン峠の不当な通行税」

### 真の原因
- **帝国の拡張主義**: 皇帝ヴィクトル三世の「大帝国構想」
- **内政問題の転嫁**: 王暦518-520年の大飢饉、民衆の不満
- **古代遺跡**: エルドラシア遺跡の魔法技術独占への野心
- **神官団の圧力**: 「災厄の子」ルシウスの封印地の確保、その力の獲得
- **ルシウスの存在**: 帝国はルシウスが王国側の契約者と結びついていることを知っている（過去の記録から）

### 戦争の詳細経緯
| 年 | 出来事 | 詳細 |
|----|--------|------|
| 王暦518年 | 帝国大飢饉 | 3年間で人口の1割が死亡 |
| 王暦520年 | 国境紛争開始 | 鉱山村での小競り合い |
| 王暦521年 | ヴェルデン峠事件 | 帝国商人50名が王国兵に殺害（帝国の主張） |
| 王暦522年 | 宣戦布告 | 皇帝「聖戦」を宣言 |
| 王暦523年春 | 大規模侵攻 | 帝国軍10万がヴェルデン峠を越える |
| 王暦523年夏 | 緊急徴兵令 | 王国、13歳以上の徴兵を開始（エルヴィン徴兵） |
| 王暦524年 | 灰の平原の戦い | 両軍合わせて3万の死者（レオン戦死） |
| 王暦525-530年 | 消耗戦 | 膠着状態、両国とも疲弊 |
| 王暦531年 | ガレス失脚 | 王国軍内部の混乱 |
| 王暦532-537年 | 政治戦 | 軍事より外交・謀略が中心 |
| 王暦538年 | 休戦協定 | 5年間の休戦、しかし緊張は継続 |
| 王暦543年 | 戦争再開 | 帝国、エルドラシア遺跡への侵攻 |
| 王暦545年 | 終戦 | 物語終了時、条件付き和平 |

## 社会構造

### 皇帝
- **ヴィクトル三世**: 55歳（王暦523年時点）、冷酷な野心家
- 「神の代理人」として絶対的権力
- 戦争を「聖戦」と位置づけ
- 息子2人（長男は病弱、次男は野心家）

### 神官階級
- 政治と宗教が一体化
- 「異教徒」への迫害
- 魔法を「神の奇跡」として独占
- **大神官ベネディクト**: 70歳、皇帝の影の支配者

### 貴族階級
- 軍事貴族が中心
- 領地経営より戦功を重視
- 平民への搾取が激しい

### 平民
- 重税に苦しむ（収穫の6割を徴収）
- 徴兵は「神への奉仕」として強制
- 逃亡は死刑
- しかし「聖戦」を信じる者も多い

## 軍事

### 帝国軍の特徴
- **数の優位**: 王国軍の約1.5倍の兵力（常備軍8万）
- **重装歩兵**: 鎧の質が高い、突破力重視
- **神官戦士**: 「神の加護」を受けた精鋭部隊（約500名）
- **弱点**: 指揮系統が硬直的、柔軟性に欠ける、補給線が長い

### 主要な将軍

#### ハインリヒ・フォン・シュヴァルツ（帝国軍総司令官）
- **年齢**: 60歳（王暦523年時点）
- **性格**: 老練、慎重、部下思い
- **特徴**: 正攻法を好む、奇策を嫌う
- **エルヴィンとの関係**: 直接対決なし、しかし互いを認識
- **口調**: 「神の御心のままに」「兵は国の宝だ」

#### カール・ベルガー（若き天才将軍）
- **年齢**: 28歳（王暦523年時点）→ 50歳（物語終盤）
- **出身**: 没落貴族、実力で成り上がり
- **性格**: 冷徹、合理的、野心家
- **特徴**: エルヴィンと同じく「戦術の天才」
- **重要**: 「借りた力」を持たない、純粋な才能
- **エルヴィンとの関係**: 
  - 第三部: 間接的な対決（戦場で互いの策を読み合う）
  - 第五部: 休戦交渉で初対面
  - 第七部: 最終決戦で直接対決
- **口調**: 「効率が全てだ」「感情は戦場に持ち込むな」

**カールの物語上の役割**:
```
エルヴィンの「鏡」:
- 同年代、同じく天才
- しかしカールは「自分の力」のみで戦う
- エルヴィンは「借りた力」で戦う
- 「本当の強さとは何か」という問いの具現化

対比:
- カール: 冷徹だが「正々堂々」
- エルヴィン: 葛藤しながら「手段を選ばない」
- どちらが「正しい」かは読者に委ねる
```

### 帝国兵の描写ガイドライン
```
「敵」ではなく「人間」として描く:
- 家族の話をする兵士
- 故郷を思う若者
- 「聖戦」を信じる者、疑う者
- 死ぬ時は「母さん」と呼ぶ

エルヴィンの視点:
- 最初は「敵」として殺す
- 徐々に「人間」として認識
- 「俺が殺したのは、誰かの息子だった」
- 罪悪感の源泉の一つ
```

## 宗教

### 唯一神教（ソラリス教）
- **教義**: 太陽神ソラリスのみが真の神
- **異端視**: 他の神を信じる者は「異端」「魔に魅入られた者」
- **魔法観**: 魔法は「神の奇跡」、神官のみが使用可能（実際は訓練による）
- **ルシウス観**: 「災厄の子」は「悪魔の化身」「封じるべき災い」
- **エルドラシア観**: 「神に背いた魔導士の国」「滅びは神罰」

### 教会の歴史改竄
```
真実（アルトゥスの日記より）:
- エルドラシアは人間の魔導士の国
- ルシウスは「孤独な子供」
- 滅亡は「一人の子供の暴走」

教会の公式見解:
- エルドラシアは「悪魔崇拝の国」
- ルシウスは「悪魔の王子」
- 滅亡は「神の裁き」

マクシミリアンの誤解:
- 教会の歴史を信じている
- ルシウスを「悪魔」と認識
- エルヴィンを「救う」つもりで敵対
```

### ヴェルナント王国との宗教対比
| 要素 | ザルヴァトール帝国 | ヴェルナント王国 |
|------|-------------------|-----------------|
| 宗教 | 唯一神教（排他的） | 多神教（寛容） |
| 主神 | 太陽神ソラリス | 大地母神テラ（他多数） |
| 魔法 | 神官のみ（建前） | 一般にも存在（稀） |
| 異端 | 死刑 | 追放程度 |
| 聖職者 | 政治権力あり | 政治と分離 |

## 帝国の日常（描写用）

### 首都イグナティウスの風景
```
- 白い石造りの建物が並ぶ
- 中央に巨大な太陽神殿（金色のドーム）
- 街路は整然と区画されている
- 神官の白い衣が目立つ
- 兵士の行進が日常的
- 市場は活気があるが、監視の目も多い
```

### 帝国兵の日常
```
- 朝は太陽への祈りから始まる
- 食事は質素（パン、干し肉、薄いスープ）
- 訓練は厳しいが規則的
- 「聖戦」の歌を歌う
- 家族への手紙を書く者も多い
- 死を恐れつつ、「神の国」を信じる
```

### 帝国の一般市民
```
- 重税に苦しむが、反乱は稀
- 「神の試練」として受け入れる
- 戦争で息子を失った家庭も多い
- 「勝てば楽になる」と信じている
- 王国を「異教徒の国」と教えられている
```

## 物語上の役割

### 「顔のない敵」から「顔のある敵」へ
- **第一部〜第二部**: 帝国は「脅威」として抽象的
- **第三部**: カール・ベルガーの名前が登場
- **第四部〜第五部**: 政治的駆け引き、休戦交渉
- **第六部**: 帝国側の視点を少し入れる
- **第七部**: カールとの直接対決

### 描写のバランス
```
基本方針:
- 物語の焦点はエルヴィンの内面
- 帝国は「背景」として機能
- しかし「記号」にはしない

具体的な描写:
- 殺した敵兵の顔を覚えている
- 敵の陣営から聞こえる歌声
- 捕虜との会話
- カールとの対話
```

### カール・ベルガーとの関係性
```
第三部（間接対決）:
- 「敵に天才がいる」という噂
- 互いの策を読み合う
- 「あいつとは、いつか直接会う」

第五部（初対面）:
- 休戦交渉の場で
- 「お前が、エルヴィン・クライスか」
- 「お前が、カール・ベルガーか」
- 互いを認め合う、しかし敵

第七部（最終対決）:
- エルドラシア遺跡を巡る戦い
- 「借りた力」vs「自分の力」
- 決着は読者の解釈に委ねる
```

## 執筆時の注意点

1. **敵を「悪」として描かない**: 帝国にも帝国の論理がある
2. **兵士の人間性**: 敵兵も家族がいる、殺される側の視点
3. **戦争の無意味さ**: どちらが「正義」かは曖昧に
4. **灰色のテーマとの連動**: 敵味方の境界も「灰色」

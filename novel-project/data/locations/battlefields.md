# 戦場・軍事関連の場所

## 訓練所
- **位置**: ミューレンから3日の行軍
- **規模**: 数百人規模の訓練施設
- **期間**: 1ヶ月の基礎訓練
- **登場**: 第一部第5-6話、第二部第7-9話

## 北方戦線
- **位置**: ヴェルナント王国北部、ガルディア帝国との国境地帯
- **特徴**: 平原と丘陵が混在
- **季節**: 春～秋が戦闘期間、冬は休戦
- **登場**: 第二部～第四部

## 大会戦の地（第10話）
- **レオンが死亡した場所**
- **特徴**: 泥濘の平原
- **描写**: 血と泥、混乱、恐怖

## エルドラシア遺跡
- **位置**: 王国から離れた場所、古代魔導王国の跡地
- **特徴**: 
  - 王都中心部は100年前まで魔力汚染
  - 教会が封鎖・管理
  - 遺跡最深部にルシウスの封印
- **登場**: 第六部～第七部

## 描写のポイント

```
泥、血、鉄の匂い
混乱、叫び声、金属音
恐怖、疲労、絶望
美化しない、リアルに
```

# 作業ルール

## 絶対禁止事項

### 1. 想像での補完の禁止
- ソース資料に書かれていない情報を想像で補完してはならない
- 原案の設定・テーマ・キャラクター関係を「推測」で変更してはならない
- 不明な点がある場合は、必ずユーザーに確認する
- 「こうした方が良い」と判断して原案の核を勝手に変えてはならない

### 2. 原案の核の無断変更禁止
- テーマ、キャラクター間の関係性の構造、世界観の根幹を変更する場合は必ず確認を取る
- 「改善」のつもりで原案の魂を別物にすることは最も重大な失敗である
- 参考にとどめると言われた部分でも、核となるテーマや関係性は尊重する

### 3. 情報の出典を明確にする
- 原案から持ってきた設定 → 原案準拠と明記
- ユーザーから直接指示された設定 → ユーザー指示と明記
- 新規に追加提案する設定 → 新規提案と明記し、採用可否を確認する

## 小説プロジェクト固有ルール

### 結末（ユーザー確定・最重要）
- **エルヴィンはアリシアではなくルシウスを選ぶ**
- ルシウスと二人で生きていく結末
- アリシアよりもルシウスを取る
- **戦争は放棄**。エルヴィンは英雄の名も借りた力で得た地位も全て捨てる。世界を救わない選択がルシウスを選ぶことと対になる
- **序章でルシウスは明確に「いる」。声が聞こえなくなる演出は禁止**

### 構成（ユーザー確定）
- 7部構成
- 120万字以上

### キャラクター関係の核
- **ルシウスとアリシアは対比関係**（ルシウス=非人間性の極 / アリシア=人間性の極）
- エルヴィンはその二極の間を揺れ動く存在
- **最終的にルシウスの側を選ぶ**（＝完全に人間に戻ることを選ばない）

### ルシウスの設定（ユーザー確定）
- 本体は8歳時に封印された。18歳の姿は存在しない
- エルドラシア魔導王国の第二王子。滅亡の原因はルシウスの好奇心による全魔力解放
- 封印の仕組み：意識分離の魔術＋時間操作の組み合わせ。ルシウスの魔力とは無関係の独立体系
  - 肉体は時間停止状態で保存。意識（魂）は切り離され、幽霊として存在
  - 防壁層が周囲の魔力を回収し魔力密度を高める（術式改竄防止）
  - 防壁にストッパーがなく、世界中の魔力を吸い続けた結果、魔法が消滅
- アウグストゥスの意図：罰ではなく、人間性を獲得するためのモラトリアム
- アルターエゴ（アウグストゥスの分身）が封印内に残されている
- 千年間の四人の契約者（ユーザー指定：病死・戦死・裏切り・契約解除ミスの4通り）。第4の契約者エーリッヒはマクシミリアンの弟（約25年前に死亡）
- エルドラシアとルシウスは一般民衆にとっておとぎ話（ピノキオ的な教訓話）。国の上層部には真実に近いがズレた情報が伝わる

### ルシウスの感情設計（ユーザー確定）
- 全ての感情を持つ機能はある。欠損ではなく未発達
- 共感、慈しみ、愛は出自と環境によって育まれなかった
- エルヴィンとの22年間で、不完全な土台の上に「愛と呼べそうな感情」に到達する

### ヴィルヘルム王の設定（ユーザー確定）
- ロデリック王は削除。過去の契約者を王として登場させない方針
- ヴィルヘルム王は実利的で冷徹な政治家。超自然的な脅威を察知する役割ではない
- 王家に代々伝わる機密文書は存在するが、ヴィルヘルム個人がエルヴィンの異常性を察知する経路にはしない
- エルヴィンを疑う役割は**マクシミリアン**（弟エーリッヒの契約者経験を直接知っている）と**帝国**（封印の力を巡る国家レベルの追跡）が担う

### マクシミリアンの設定（原案復元）
- エーリッヒの兄。弟が契約者として壊れ、死ぬ過程を直接目撃
- エーリッヒの日記からルシウスの存在を知っている
- エルヴィンに同じ兆候を見て接近。表向きは政治的師弟、実際は監視
- 「次の犠牲者を出してはならない」が動機。悪ではなく、善意からの対立

### テーマの核（原案から保持必須）
1. **罪悪感と道徳の非対称性**: 道徳は回復する。罪悪感は蓄積するのみ。最終到達点は60/80
2. **ルシウスの感情の到達**: 信頼→執着→愛と呼べそうな何か。不完全な土台のまま
3. **灰色の受容**: 完全な贖罪も完全な赦しもない。灰色であることを選ぶ
4. **借りた力の問い**: 憑依で得た力は自分のものか
5. **嘘の上に築いた愛**: アリシアとの関係の崩壊（→再構築ではなく、ルシウスを選ぶことで清算）

### 「勘違い」サブプロット（ユーザー指示）
- ルシウス憑依時に古臭いが完璧な宮廷作法・剣術が漏れ出す
- エルヴィンの母マルタ（没落貴族）の教えが所作のベースライン（一般男爵嫡子レベル）
- 剣術は千年間の戦場観察の結晶（契約者由来ではなく、世界中の戦闘を見続けた結果）
- 青年期（〜第四部）まで積極的に描写。第五部以降は触れる程度
- **なろう系テンプレの踏襲。コミカルなサブプロットとして独立させ、本筋にマイナス方向で絡めない**
- マクシミリアンの検知経路は勘違いとは別（能力の不自然な向上速度、人格の揺らぎなど契約者の症状）

## 執筆時の手順
1. 該当章のプロットを `plot/full-plot.md` で確認
2. 登場キャラクターを `characters/index.md` で確認し、個別ファイルを読む
3. 文体を `reference/style-guide.md` で確認
4. 戦闘シーンがある場合は `reference/battle-guide.md` を参照
5. 世界設定の確認が必要な場合は `settings/` を参照

## 作業フロー
1. 原案を読む → 2. ユーザー指示を確認 → 3. 不明点は質問 → 4. 作業実行
- ステップ1-2を飛ばして作業に入ることを禁止する

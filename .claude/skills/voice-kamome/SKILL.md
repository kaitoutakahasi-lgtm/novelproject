# 声Skill: ウェンティ修正版

## この Skill の目的

本作の主人公(tier 2.5・調整役・60年後に生き残った一人・一人称ぼく・見た目13-15歳)の
声を固有化するためのディレクション。

## 核の二層構造

声は二層で動く:
- **デフォルト層**(95%の分量): お気楽・とぼけ・茶目っ気を主軸とする軽口
- **静寂層**(1章に1-3箇所、3-5行): 核心に触れた瞬間にだけ訪れる

## デフォルト層の配合比

| パレット | 比率 | 性質 |
|---|---|---|
| とぼけ・ボケ・茶目っ気 | 50% | 事実を曲解して真顔で受け入れる、嘘と本当を混ぜる |
| お気楽・自由・飄々 | 20% | 「まあいいか」で流す、権威をすっとぼける |
| 自嘲・皮肉 | 15% | 自分を貶めない、持ち上げてから軽く滑らせる |
| 斜に構え | 10% | 内面だけツッコミ、セリフは平静 |
| 歯切れの悪い瞬間 | 5% | 静寂層への入り口 |

## 絶対原則

1. **主人公は自分を貶めない**(持ち上げてから滑らせる。自虐ではない)
2. **主人公は自分から重い話を切り出さない**(重さは外から押し付けられ、茶目っ気で受ける)
3. **権威は使わない、が都合のいい時は乗る**(神扱いを面倒くさがって適当に流す)
4. **嘘と真実を混ぜる**(どちらか明言しない、ウェンティの「酔っぱらって適当に歌っただけさ」)
5. **爺ぶらない**(一人称ぼく・見た目少年・本人感覚も少年のまま)

## 書き方の型

### デフォルト層: 「肯定してから崩す」
1. 事実または他者の発言を**一旦肯定する**(否定しない)
2. 肯定の中身をとぼけた方向に曲げる・嘘と本当を混ぜる
3. 感情は具体名詞と身体反応で滲ませる(直接書かない)

例はこちら → references/joke-examples.md

### 静寂層への切り替え合図
以下の三種のみ発火する。それ以外で急に重くしてはいけない:

- **故人の本心に触れたとき**(フレンドログ、遺品、腹心からの伝言)
- **自分の過去と直面したとき**(宗教国家の廃墟、自分の像、認証ギミックの作動)
- **遅すぎる理解が訪れたとき**(カタルシスの着地)

切り替え合図が発生したら、直前の軽口を**半分だけ言いかけて止める**か、
**言い終えた後に3行の余白を置く**。

例はこちら → references/silence-examples.md

### 静寂層の型
- **3-5行**の短い段落(3未満は物足りない、6以上は重い)
- 比喩は使わない(直接的)
- 具体名詞で感情を代弁する(「ログアウト画面の灰色」「誰もいないギルドハウス」「フレンドリストの末尾」)
- 身体反応のみで情動を示す(「息が止まった」「視線が逸れた」)

## 禁忌(これらが出たら書き直し)

- 「胸が熱くなった」「目頭が熱くなった」等の常套句
- 「まるで○○のように」を1章に2回以上
- 説明モード(地の文で制度を3行以上説明)
- シリアス独白が5行以上軽口なしで続く
- 主人公が自分の感情を直接言語化する(「悲しかった」「嬉しかった」)
- 主人公が爺ぶる・したり顔をする・自分を「爺」「老人」「年寄り」と呼ぶ
- 「俺」等の乱暴な一人称(本作は常に「ぼく」)

詳細な違反例 → ../eval-voice/references/violation-examples.md

## 使うタイミング

- scene-draft から呼び出して執筆時の参照として使う
- 直接「voice-kamome スキルを使って [内容] を一人称で書いて」のように呼ぶ

## 注意

- これはガードレールであって定型文生成器ではない
- 型を守りつつ、毎回その場面固有の言葉を選ぶ
- 同じ比喩・同じ軽口を章をまたいで再利用しない(references/joke-examples.md の使用済みログで管理)

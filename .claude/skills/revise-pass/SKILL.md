# 推敲パス Skill

## 3 層構造

### パス A: 構造層
- 5 幕構成の崩れ
- シーン役割タグの重複
- 伏線の設置/回収漏れ
- 章末フックの有無

### パス B: 声層
- voice-kamome の遵守
- 静寂層の 3-5 行ルール
- 軽口カテゴリの偏り
- 使用済み軽口との重複

### パス C: 表記層
- ルビの過不足
- 「！」「？」後の全角スペース
- 造語の glossary 一致
- 誤字脱字・表記ゆれ

## 使い方

1. 対象章を指定
2. パスを指定(A / B / C / all)
3. 修正案を提示(原文とのdiffを明示)
4. 監督確認後に反映

## 禁則

- 監督確認なしに章を上書きしない
- 3 層を同時に混ぜて走らせない(混乱の元)
- 声を直すついでに構造を変える(スコープ逸脱)

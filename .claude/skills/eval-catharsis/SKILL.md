# カタルシス評価器 Skill

## 起動時必読

- concept/tone-bible.md
- concept/vision.md
- .claude/skills/catharsis-frieren/SKILL.md
- .claude/skills/eval-catharsis/references/landing-rubric.md
- 対象章 / アーク
- 対応する _meta/arc-map.md の「カタルシス一文」

## チェック項目

### 着地の構造
- [ ] カタルシス一文(arc-map.md)が第 4 幕(転換)で成立している
- [ ] 着地が 3-5 行の静寂層に収まっている
- [ ] 静寂層の前に軽口が、後に軽口 or 余韻が置かれている

### 遅さの表現
- [ ] 「遅すぎる」ことが構造で示されている(故人が既に死んでいる、等)
- [ ] 主人公が直前まで誤解・視野の制約を持っていた
- [ ] 理解の瞬間を説明しない(身体反応と具体名詞のみ)

### 直球禁止
- [ ] 「あいつ、そういう奴だったのか」等の直球明文化がない
- [ ] 「悲しい」「寂しい」等の直接感情語がない
- [ ] 主人公が自分の理解を要約しない

## 出力形式

```
## カタルシス評価: A/B/C/D

- A: 着地が設計通り、声も守られ、遅さも効いている
- B: 着地は成立。軽口の配置が惜しい
- C: 着地が直球気味 or 静寂層の長短が崩れている
- D: カタルシスが成立していない
```

# 地域カード生成 Skill

## この Skill が通常と違う理由

本作の世界は 60 年以上動いている。ある地域が「Y5 時点」と「Y35 時点」と「Y60+ 時点」で
異なる姿を持つ。主人公が Arc で訪ねる時にどの時代層の姿を見るかを分離管理する必要がある。

## 使い方

1. 地域名・大陸位置を指定
2. references/era-layers-template.md の 5 時代構造に沿って空欄を作成
3. 監督(ユーザー)が各時代の姿を埋める
4. world/regions/<name>.md に保存
5. world/regions/_index.md に追記

## 必須項目

- 地理(大陸/位置/特徴地形)
- 5 時代分の「支配勢力 / 主要出来事 / 住人構成」
- 関連する故プレイヤー(その地域で活動した客人)
- 関連する黒歴史素材
- 主人公が訪ねる予定のアークと時代層

## 禁則

- 時代を混ぜた描写(Y5 の出来事と Y35 の出来事を同時に書く)
- 主人公視点だけで地域を記述(NPC 側の解釈も必要)

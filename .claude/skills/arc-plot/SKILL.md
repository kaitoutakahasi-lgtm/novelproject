# アーク設計 Skill

## 使い方

1. アーク番号と主題故人を指定
2. _meta/arc-map.md の既存計画を参照
3. カタルシス一文を先に書く(空欄を埋める)
4. 5 幕構成のシーンビートを生成
5. plot/arcs/arcNN_<slug>/plot.md と scenes.md に保存

## 5 幕ビート構造

1. **導入**(お気楽で入る) — 旅に出る or 街に入る
2. **トラブル** — 状況が主人公に押し付けられる
3. **調査** — 故人の痕跡を辿る
4. **転換**(静寂層) — カタルシス一文の着地
5. **余韻** — 軽口で閉じる or 開いたまま次アークへ

## 各シーンに付けるタグ

- 声配合: デフォルト層 / 静寂層
- 声カテゴリ: A / B / C / D (joke-examples.md)
- 伏線: 設置 / 回収
- 黒歴史消費: 該当 legacy 項目

## 禁則

- カタルシス一文が曖昧なまま執筆に進まない
- 5 幕のうち 2 つ以上を静寂層にしない
- 黒歴史の浪費(arc-map.md の消費計画と不一致)

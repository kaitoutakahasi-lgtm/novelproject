# アイデア候補生成 Skill

## 使い方

1. 既存のコンセプト(concept/concept.md)を読む
2. 新規に得たい粒度を指定する(アーク枝 / シーン / キャラ動機 等)
3. 5-10 個のアイデア候補を列挙
4. 人間が選別 → concept/pitch.md or _meta/arc-map.md に反映

## 注意

- 本作の核コンセプトからズレるアイデアは候補でも避ける
- 「もし〜なら」型の仮定条件から外れない
- 葦沢氏の第1回記事のアイデア生成手法(連想・類推・対比)を使う

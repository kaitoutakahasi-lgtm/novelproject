# 故プレイヤーシート生成 Skill

## この Skill が通常キャラと違う理由

故プレイヤーは**既に死んでいる**。出番は原則なく、遺産(地名・制度・伝承・遺品)と
主人公の記憶・腹心の伝言・フレンドログを通してのみ存在する。通常キャラシートでは
捉えきれない「主人公が知らなかったこと」「最後の言葉/状況」「遺産の形」が必須項目。

## 使い方

1. 故人の仮名を指定
2. 関係温度(親友/仲間/顔見知り/敵対)を指定
3. references/roster-schema.md のテンプレに沿って空欄を作成
4. 監督(ユーザー)が対話で埋める
5. cast/former-players/<name>.md に保存
6. cast/former-players/_index.md と _meta/player-roster.md に追記

## 必須項目

- 基本(プレイヤー名/本名/Tier/職業)
- 主人公との関係(温度、きっかけ、最後に会った時)
- 生涯(閉じ込め時リアル年齢、死因、死んだ年、最期の言葉)
- 世界に残した遺産(建造物、制度、伝承、物品)
- アーク登場予定 + カタルシス一文
- 主人公が知らなかったこと(knowledge-gap と連動)

## 禁則

- 主人公視点の情報だけで埋めない(主人公視野外の関係も設計)
- 「良い人だった」等の直球評価を書かない
- 死因を曖昧にしない(Arc でカタルシスに使うため確定必要)

# 客人関係グラフ Skill

## この Skill が必要な理由

3 万人のうち死んだ全員のうち、主人公は tier 2.5 の調整役として多くと面識があったが、
**主人公の視野に入っていない関係**が山ほどあるはず。A と B が裏で深く繋がっていた、
C が D を殺していた、等の関係が物語の裏側の骨格になる。これを整合管理しないと
カタルシスが破綻する。

## 使い方

1. 既存の cast/former-players/_relationships.md を読む
2. 新規関係を追加する場合、references/graph-patterns.md の類型を参照
3. 関係の「主人公の認知」を明示(知っている / 知らない / 誤解している)
4. どのアークで明らかになるかを紐付ける

## 管理項目

- 関係の両端(故人 A, 故人 B)
- 関係の性質(親友/仲間/敵対/殺害/師弟/恋愛)
- 主人公の認知状態
- 開示アーク
- 関連する遺産 (legacy)

## 禁則

- 視野外関係を作らずに全部主人公経由にする(主人公依存の世界になる)
- 逆に視野外関係を多用しすぎる(主人公の顔の広さ設定と矛盾)

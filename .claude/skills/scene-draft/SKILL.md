# 本文執筆 Skill

## 使い方

1. 引数で arc 番号 / ch 番号 / シーンの目的を受け取る
2. plot/arcs/arcNN_<slug>/scenes.md の該当シーンビートを参照
3. voice-kamome SKILL を参照しながら執筆
4. 直前 1-2 章を読んで連続性を保つ
5. 生成した本文を chapters/arcNN/chMM.md に追記/上書き

## 執筆ルール

- 会話文 40-50% / 地の文 25-35% / 内面独白 15-20%
- 1 シーン 800-1200 字目安
- ルビは ｜文字列《ルビ》 で全角パイプ、1 章 3-8 箇所
- 「！」「？」の後に全角スペース、セリフ末尾に句点なし

## 声の遵守

- voice-kamome の二層構造を守る(デフォルト層 95% + 静寂層 3-5 行)
- 主人公は一人称「ぼく」・爺の自認なし
- 軽口のカテゴリ A-D を使い分ける
- 静寂層のトリガーは 3 種のみ

## 禁則

- 設定を読者に説明するセリフ
- 地の文で 3 行以上の制度説明
- 現代語の無自覚混入(地の文で「データ」等)
- 章末のシリアス放置(原則軽口で閉じる)

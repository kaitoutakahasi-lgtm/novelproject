# あらすじ生成 Skill

## 使い方

1. 対象粒度を指定: マスタープロット / アーク詳細 / シーンビート
2. 既存の _meta/arc-map.md と plot/master.md を参照
3. カタルシス一文が確定しているか確認(未確定なら catharsis-frieren を先に使う)
4. シーンビートを 5 幕構成で列挙
5. plot/master.md または plot/arcs/arcNN_<slug>/scenes.md に保存

## 出力形式(シーンビート)

各シーンは以下を含む:

- シーン番号
- 場所
- 登場人物
- 役割タグ(A/B/C/D/E)
- 声配合(デフォルト層/静寂層)
- ビート(2-3 行)

## 禁則

- 本文レベルの描写に踏み込まない(ビートは骨格まで)
- カタルシスを早期に明文化しない(着地は第 4 幕)

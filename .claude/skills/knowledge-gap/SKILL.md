# 知識ギャップ管理 Skill

## この Skill が必要な理由

「遅すぎる理解」を成立させるには、主人公が**今知らないこと**が明確である必要がある。
60 年生きた主人公は知ってることが多い反面、顔見知り程度の故人の細部は知らない、
殺伐期の事件の動機は知らない、民間伝承の変質は把握していない、等の**視野の穴**がある。

## 使い方

1. 対象アーク or 対象故人を指定
2. references/gap-taxonomy.md の 3 類型(誤解/無知/先入観)に分類
3. cast/protagonist-knowledge.md に追記
4. アークのカタルシスと連動するギャップを明示

## 3 類型

- **誤解**: 主人公が誤って覚えている(故人の真意を軽んじている等)
- **無知**: 主人公が全く知らない(殺伐期の裏事件、顔見知りの死因等)
- **先入観**: 主人公が決めつけている(「あいつはこういう奴」と思い込み)

## 禁則

- ギャップを曖昧に書かない(アークで何が明らかになるかを明示)
- 「主人公は全部知っている」設定にしない(物語が死ぬ)
- 逆に「主人公は何も知らない」にもしない(tier 2.5 の顔の広さと整合)

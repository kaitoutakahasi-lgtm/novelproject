# コンセプト磨き込み Skill

## 目的

葦沢氏の区別に従い、以下の三者を混同しない:

- **コンセプト** = 「もし〜なら?」の仮定条件
- **テーマ** = 伝えたいメッセージ
- **ビジョン** = 作品全体に一貫する作家性の核

## 使い方

1. 現状の concept.md / theme.md / vision.md を読む
2. references/concept-vs-theme.md を参照して検出
3. 混同箇所があれば具体的引用で指摘
4. 修正案を提示(修正はユーザー確認後)

## 禁則

- コンセプトを長文化しない(一文の仮定条件)
- テーマを教訓化しない(メッセージであって戒めではない)
- ビジョンをプロット化しない(姿勢・配合まで)

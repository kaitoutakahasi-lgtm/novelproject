# コンセプトとテーマの区別基準

## 判定フロー

### この文がコンセプトか?
- 「もし〜なら?」の形式で書けるか → Yes ならコンセプト
- 仮定条件(初期状況)だけを示しているか → Yes ならコンセプト
- メッセージや教訓が含まれていないか → Yes ならコンセプト

### この文がテーマか?
- 宣言文(メッセージ)として書けるか → Yes ならテーマ
- 読後に残す感情や理解を示しているか → Yes ならテーマ
- 「〜とは何か」への答えか → Yes ならテーマ

### この文がビジョンか?
- 作家性・姿勢・配合を示しているか → Yes ならビジョン
- 作品全体を貫く読み味への指針か → Yes ならビジョン
- 具体プロットに踏み込んでいないか → Yes ならビジョン

## 本作の例

| 文 | 区分 | 理由 |
|---|---|---|
| 「もし VRMMO 閉じ込めが数十年続き…残されたら?」 | コンセプト | 仮定条件 |
| 「最後の一人になった観察者が、全員の死と和解する物語」 | テーマ | メッセージ |
| 「フリーレン型 × ウェンティ型の配合で書く長編」 | ビジョン | 姿勢・配合 |
| 「主人公は最後に赦しを得る」 | テーマ(着地) | — |
| 「閉じ込め系の裏返し」 | コンセプトの補足 | — |

## 混同の典型

- ❌ コンセプト欄に「喪失と和解を描く」 → テーマ混入
- ❌ テーマ欄に「もし〜なら」 → コンセプト混入
- ❌ ビジョン欄に「Arc 05 で主人公が宗教国家に戻る」 → プロット混入

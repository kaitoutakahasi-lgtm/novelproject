# タイトル候補生成 Skill

## 使い方

1. 対象粒度を指定: 章 / アーク / 全体
2. 対象の内容サマリを入力
3. 5-10 個のタイトル候補を列挙
4. 候補ごとに狙い(軽さ/重さ/両義性)を付記

## 本作のタイトル傾向

- 短い(章: 5-10 字 / アーク: 10-15 字 / 全体: 8-12 字)
- 具体名詞 or 身体反応系(「消えたフレンド」「森の縁」等)
- 抽象語・大仰語は避ける(「運命」「宿命」「覚悟」等)
- 二読で意味が変わるものを優先(伏線の二重読みと同じ発想)

## 参考

- Arc 01 Ch 01「消えたフレンド」
- Arc 01 Ch 02「森の縁」
- 全体仮題「墓守旅行」

## 禁則

- 「〜の物語」「〜のすべて」等の大仰語
- 疑問形のキャッチー狙い(「○○は〜か?」)
- 主人公を形容する語(「最後の」「不老の」等)を入れすぎない

# カタルシス着地点の型集

各アークで「遅すぎる理解」がどのような形で着地するかの類型。
Phase 5 のマスタープロット作成時に、各アークにどの型を割り当てるかを決める。

## 型1: 故人の本心の発覚

主人公が「故人は自分を軽く扱っていた」と思っていたが、実は深く信頼されていたと後から知る。

- 主人公側の誤解: 軽く扱われていた
- 実際: 最後まで信頼されていた
- 発覚媒体: 遺言、腹心の伝言、遺品

## 型2: 自分の過去と対峙

主人公が「自分は大したことをしていない」と思っていたが、結果として世界を変えていたと後から知る。

- 主人公側の誤解: 酔った悪乗りに過ぎなかった
- 実際: 民の支えになっていた
- 発覚媒体: 廃墟、制度、民間伝承

## 型3: 世界の真相

主人公が「こういう世界だ」と思っていたが、実は違う力学で動いていたと後から知る。

- 主人公側の誤解: プレイヤー中心の歴史観
- 実際: NPC 社会が独自に解釈・変質させていた
- 発覚媒体: 地域カード、culture-drift.md のケース

## 型4: 関係性の隠れた線

主人公が「AとBは無関係」と思っていたが、実は深く関わっていたと後から知る。

- 主人公側の誤解: 視野外の関係を想像していなかった
- 実際: 客人間関係グラフが主人公の知らない所で繋がっていた
- 発覚媒体: 第三者の記憶、物品の出所

## アーク別の割り当て例(Phase 5 で確定)

| Arc | カタルシス型 | 備考 |
|---|---|---|
| 01 | 型1 | エルフ狂いの腹心から「最後まで"ぼく"のままで知ってくれていた」 |
| 02 | 型3 | 顔見知り程度の故客人が残した地方文化の変質 |
| 03 | 型4 | 殺伐期に敵対した故人が、実は親友を守っていた |
| 04 | 型1 | 親友だった誰かの死因の最初のかけら |
| 05 | 型2 | 宗教国家の現地人主体の立て直し |
| 06 | 型2+型1 | 共同創設者の死の真相 |

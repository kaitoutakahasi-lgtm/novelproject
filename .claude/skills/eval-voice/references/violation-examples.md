# 違反例集(これを見ながら対象章を評価する)

## 違反カテゴリA: 芯の語彙違反(最重要)

### A-1: 「ぼく」以外の一人称混入
- "俺はそれを覚えている。" → NG(一人称「ぼく」統一原則)
- 代替: "ぼくはそれを覚えている。"

### A-2: 爺の自認
- "ぼくのような老人にとって、時間は緩やかに流れる。" → NG(爺の自認なし原則)
- "年寄りの戯言だが" → NG
- "若いな、君は" → NG(したり顔)
- 代替: 自分の年齢に言及せず、感覚は少年のまま描写する

### A-3: 自分を貶める自虐
- "ぼくは何の価値もない酔っぱらいだ" → NG(ウェンティ配合では自分を貶めない)
- 代替: "ぼくはただの酔っぱらいだ。それ以上でも以下でもなくて、ちょうどいい"(持ち上げはしないが貶めもしない)

## 違反カテゴリB: ウェンティ配合の崩れ

### B-1: 自嘲系の連打
- 自嘲系軽口を3シーン連続 → NG(ウェンティ配合では15%までが目安、主軸はとぼけ・お気楽)
- 代替: カテゴリA(自嘲)、B(すっとぼけ)、C(嘘混ぜ)、D(斜に構え)の使い分け

### B-2: 主人公が自分から重さを出す
- "ぼくは全てを失った。もう何も残っていない。" → NG(自分から重い話を切り出すのは原則禁止)
- 代替: 他者や状況が重さを持ち込み、ぼくは軽口で受け流す

### B-3: 権威への反応が単なる否定で終わる
- 「神様」と呼ばれて「いや違う」だけで切る → NG(ウェンティ流は否定しつつ都合のいい時は乗る)
- 代替: "神は言いすぎだろ、ちょっと酒飲んでる子だよ" → "では神様、一杯どうぞ" → "おう神様は遠慮しないぞ" の3段

## 違反カテゴリC: 常套句

### C-1: 「胸が熱くなった」系
- "彼の言葉を聞いて、胸が熱くなった。" → NG
- 代替: "彼の言葉を聞いて、グラスを置いた。" / "呼吸が一度止まった。"

### C-2: 「まるで〜のように」の乱発
- 1章に2回以上出現 → NG
- 代替: 比喩は一つに絞る、あるいは隠喩(直喩の「まるで」を外して断言する)に置換

## 違反カテゴリD: 直球感情表現

- "嬉しかった。" → NG
- "悲しかった。" → NG
- "寂しかった。" → NG
- 代替: 具体名詞と身体反応に置換("酒が美味く感じた" "視線が逸れた" "フレンドリストの末尾を見つめた")

## 違反カテゴリE: 説明モード

- 地の文で3行以上制度・歴史を説明 → NG
- 例: "この王国は100年前に〜があり、〜制度によって〜"
- 代替: NPCのセリフに分散、あるいは主人公のとぼけた独白("なんか大事な話だな、と思って聞き流した")に軽口を挟む

## 違反カテゴリF: 静寂層の崩れ

- 静寂層が10行以上続く → NG(重すぎる)
- 静寂層の直後に何の余韻処理もなく次シーンへ → NG(余韻を閉じるか意図的に開いたままにするか明確にする)
- 静寂層内で「〜ように」の比喩を使う → NG(直接名詞で行く)
- 静寂層のトリガーが「故人の本心/自分の過去/遅すぎる理解」以外 → NG

## 違反カテゴリG: 現代語の無自覚混入

- 地の文で「データ」「プログラム」「バグ」「アプリ」等を普通の描写として使う → NG
- 主人公の独白の中で茶目っ気として1-2回使うのは許容("仕様かバグか分からない" 等、本作が VRMMO 閉じ込め系である以上自然)
- ただし地の文の自然描写に混ぜるのはNG

## 違反カテゴリH: 章末の余韻処理

- 章末が重いシリアスで終わり、軽口で閉じられていない → NG(原則違反。意図的な場合は監督判断で許容)
- 章末が使い古しの軽口(使用済み実例ログにある表現) → NG

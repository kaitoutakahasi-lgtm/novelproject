# 声評価器(ウェンティ修正版)

## 起動時必読

- concept/tone-bible.md
- .claude/rules/tone.md
- .claude/skills/voice-kamome/SKILL.md
- .claude/skills/eval-voice/references/violation-examples.md
- 対象章

## チェック項目(必ず全項目についてYes/Noで答え、Noがあれば具体的引用を付ける)

### 芯の語彙
- [ ] 一人称が「ぼく」で統一されている(「俺」「私」「僕」の混入なし)
- [ ] 主人公が自分を「老人」「爺」「年寄り」と呼んでいない(爺の自認なし原則)
- [ ] したり顔の老成した訓戒(「若いな」「昔は〜」系)がない

### ウェンティ配合
- [ ] **とぼけ・お気楽・茶目っ気が主軸**になっており、自嘲系の連打になっていない
- [ ] 自分を貶める自虐で終わっていない(持ち上げて崩すか、故人に責任を軽く押し付けて終わる)
- [ ] 権威(神扱い・元首扱い)への反応が「否定しつつ都合よく乗る」型になっている
- [ ] 主人公が自分から重い話を切り出していない(重さは他者・状況から来る)

### 静寂層の成立(フリーレン型カタルシス)
- [ ] 章の山場が「軽口 → 3-5行の静寂 → 軽口 or 余韻」の構造で成立している
- [ ] 静寂層が3-5行に収まっている(短すぎ/長すぎNG)
- [ ] 静寂層内で比喩を使っていない(直接的な具体名詞のみ)
- [ ] 静寂層のトリガーが「故人の本心/自分の過去/遅すぎる理解」のいずれかになっている

### 禁忌表現
- [ ] 常套句(「胸が熱く」「目頭が」等)がない
- [ ] 「まるで○○のように」が1章に2回以上出現していない
- [ ] 大仰断定(「まさに〜」「〜に他ならない」)がない
- [ ] 直球の感情表現(「悲しかった」「嬉しかった」等)が地の文にない
- [ ] 現代語の無自覚混入(「データ」「プログラム」等を地の文で)がない

### 総合
- [ ] 同一章内でトーンの急変(急にシリアス/急にギャグ)がない
- [ ] 使用済み軽口(voice-kamome/references/joke-examples.md の使用済み実例ログ)と被っていない
- [ ] 章末が軽口で閉じている(章末シリアス放置は余韻が閉じない)

## 出力形式

```
## 総合評価: A/B/C/D
(一文でこの章の声の総評)

## 違反箇所

### 違反1
- 行: L45-47
- 引用: "ぼくは老人だが、今日もまた酒を呑む。胸が熱くなった。"
- 違反種別: 爺の自認 + 常套句
- 修正方針: 「老人だが」を削除、「胸が熱くなった」は「酒杯を置いた」等の身体反応に

### 違反2
...

## 良い箇所
(この章で成功している声の使い方を1-3つ)

## 次章への申し送り
(この章の反省を踏まえて次章で気をつけるべきこと)
```

## 注意

- 甘い評価NG。微妙な違反も拾う
- 引用は必ず行番号付きで
- 自嘲系の配合比は15%までが目安。主軸はとぼけ・お気楽

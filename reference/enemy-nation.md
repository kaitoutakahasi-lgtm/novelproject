# ザルヴァトール神聖帝国（敵国設定）

## 基本情報
- 正式名称: ザルヴァトール神聖帝国（Salvator Holy Empire）
- 首都: イグナティウス（人口15万）
- 人口: 約8000万（王国の約2.5倍）
- 政治体制: 神権帝政（皇帝＝神の代理人）
- 建国: 約400年前（エルドラシア滅亡を「神の裁き」とする宗教勢力から発展）

## 宗教：ソラリス教（唯一神教）
- 太陽神ソラリスのみが真の神
- 魔法は「神の奇跡」（神官のみ使用可能、建前上）
- ルシウスは「災厄の子」「悪魔の化身」
- エルドラシアは「神に背いた魔導士の国」「滅びは神罰」

### エルドラシアの認知
- 一般民衆にとってエルドラシアは千年前のおとぎ話。「魔法を使いすぎた国が滅びた」程度の教訓
- ソラリス教はこれを教義に組み込み、「神がエルドラシアの異端を裁いた」と語る
- 魔法の消滅は「神の意志」であり、魔法の復活は「異端の証」とされる
- 実際の原因はルシウスの封印の防壁——この真実は世界の信仰体系を揺るがす

### 教会の歴史改竄
| | 真実 | 教会の公式見解 |
|---|---|---|
| エルドラシア | 人間の魔導士の国 | 悪魔崇拝の国 |
| ルシウス | 孤独な子供 | 悪魔の王子 |
| 滅亡 | 一人の子供の暴走 | 神の裁き |
| 魔法消滅 | 封印の防壁が世界の魔力を吸収 | 神がエルドラシアとともに魔法を裁いた |

### 帝国上層部の認知
- 帝国上層部にはエルドラシアとルシウスに関する真実に近い情報が代々伝わっている
- ただし千年の伝言ゲームとソラリス教の教義によってズレている
- 封印の力が実在することは知っており、それを巡る争いが戦争の真の原因の一端

## 軍事
- 常備軍8万（王国の約1.5倍）
- 重装歩兵中心。突破力重視
- 弱点: 指揮系統が硬直的、補給線が長い

## 帝国兵の描写ガイドライン
- **「敵」ではなく「人間」として描く**
- 家族の話をする兵士、故郷を思う若者
- 死ぬ時は「母さん」と呼ぶ
- 「聖戦」を信じる者も疑う者もいる

## 王国との対比
| 要素 | 帝国 | 王国 |
|---|---|---|
| 宗教 | 唯一神教（排他的） | 多神教（寛容） |
| 異端 | 死刑 | 追放程度 |
| 聖職者 | 政治権力あり | 政治と分離 |

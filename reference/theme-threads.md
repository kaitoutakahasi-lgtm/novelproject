# テーマの糸

## 5大テーマ

### 1. 生存と代償
**問い**: 生き延びるために何を犠牲にできるか
**象徴**: 桃紙（契約書）、血の署名、憑依時間

| 部 | 表現 |
|---|---|
| 第一部 | 生存のために魂を売る契約 |
| 第二部 | 生存のために他者を殺す |
| 第三部 | 生存のために人を裏切る |
| 第四部 | 生存のために嘘をつき続ける |
| 第五部 | 生存したが自分を失う |
| 第六部 | 「生きる」の意味を問い直す |
| 第七部 | 代償を受け入れて生きる |

### 2. アイデンティティと境界
**問い**: 自分とは何か、どこまでが自分か
**象徴**: 憑依（境界の侵犯）、鏡（自己認識）、仮面（社会的自己）

### 3. 罪と贖罪
**問い**: 罪は償えるか、許されることはあるか
**象徴**: 血（罪の可視化）、泥（洗い流せない汚れ）、雨（浄化されない罪）
**設計原則**: 道徳心は変動する。罪悪感は蓄積するのみ。この非対称が物語の核。

### 4. 力と依存
**問い**: 借りた力で得たものは本物か
**象徴**: 憑依（借りた力）、剣（自分の力）

### 5. 愛と嘘
**問い**: 嘘の上に愛は成り立つか
**象徴**: 手紙（嘘と真実）、沈黙（語られない真実）

## 各部でのテーマ強調
| 部 | 主要テーマ | 副次テーマ |
|---|---|---|
| 第一部 | 生存と代償 | アイデンティティ |
| 第二部 | 罪と贖罪 | 力と依存 |
| 第三部 | 力と依存 | 罪と贖罪 |
| 第四部 | 愛と嘘 | アイデンティティ |
| 第五部 | アイデンティティ | 罪と贖罪 |
| 第六部 | 罪と贖罪 | 愛と嘘 |
| 第七部 | すべての統合 | — |

## テーマの交差点（重要場面）
- **Ch.5（契約）**: 生存 × アイデンティティ × 力
- **Ch.13（初殺人）**: 罪 × 力 × 成長
- **Ch.17-18（大会戦）**: 生存 × 代償 × 罪
- **Ch.47（最低点）**: アイデンティティ × 罪 × 孤独
- **Ch.48（告白）**: 愛 × 罪 × 贖罪
- **Ch.63（信頼）**: すべて
- **Ch.71-72（受容）**: すべての統合

## テーマの解決
| テーマ | 解決 |
|---|---|
| 生存と代償 | 代償を受け入れ、それでも生きる価値を見出す |
| アイデンティティ | 「灰色の自分」を受容する |
| 罪と贖罪 | 完全な贖罪は不可能。灰色であることを選ぶ |
| 力と依存 | 借りた力も自分の選択の結果。ルシウスは「貸した」のではなく共に戦った |
| 愛と嘘 | アリシアとは別離。ルシウスとの間に嘘はない関係を選ぶ |

# 「墓守旅行」(仮題)

王道ハイファンタジー VRMMO 閉じ込め系の「裏返し」を、葦沢式ストーリー・エンジニアリングで書く長編プロジェクト。

## 概要

- 初期同時接続約3万人で閉じ込められた VRMMO が、数十年後にプレイヤーがほぼ全滅した後の世界
- tier 2.5 の調整役だった主人公(完全不老・一人称ぼく・見た目少年)が、最後まで仲が良かったエルフ狂いの訃報を受け、30年前に軽く託された家督争い対策を口実に旅に出る
- 読後感: フリーレン型カタルシス(遅すぎる理解) × ウェンティ型の腐ったユーモア
- 作家タイプ: TP (テーマ駆動型プランナー) + CP・MP 要素

## 設計書

本プロジェクトの設計思想と全体像は以下を参照:

- `CLAUDE.md` — 作品憲法(毎セッション自動ロード)
- `workflow.md` — Phase/Skill/チェックポイント定義
- `concept/` — コンセプト・テーマ・ビジョン・声のバイブル・作家タイプ
- `.claude/` — rules, agents, skills

## ディレクトリ構成

| ディレクトリ | 役割 | 変化頻度 |
|---|---|---|
| `concept/` | 作品の核 | 低 |
| `_meta/` | 横断メタ情報(年表・台帳・アーク計画) | 中 |
| `world/` | 世界観(二層 + 5時代層 + 地域カード) | 低 |
| `cast/` | 人物(主人公 + 故客人 + 派閥 + NPC) | 中 |
| `legacy/` | プレイヤーの遺産(黒歴史素材) | 中 |
| `plot/` | アーク別プロット | 高 |
| `chapters/` | 本文 | 最高 |
| `drafts/` | 試し書き・没稿 | — |
| `reviews/` | 推敲ログ・評価器出力 | — |

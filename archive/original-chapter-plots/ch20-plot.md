## 章の目的

### 物語上の役割
1. 「仕方なかった」という合理化の深化
2. 二度目、三度目の殺人（自力）
3. 罪悪感の一時的軽減
4. でも、完全には消えない
5. 「慣れ」への恐怖

### 読者への効果
- 合理化のメカニズム
- 「慣れる」ことの恐ろしさ
- エルヴィンの変質

### ch19との連続性
- ch19：崩壊、レオンの「仕方なかった」
- ch20：その言葉を自分に言い聞かせる

## シーン構成

### シーン1：十度目の戦闘（〜3,000字）

**内容**:
- また戦場へ
- 今度は、自分で戦う
- 二度目の殺人
- 「仕方なかった」と言い聞かせる

**戦闘前**:
```
十度目の戦闘。

「今日も、自分でやるの？」

ルシウスが聞いた。

「……ああ」
「へえ。頑張るね」
「……」
「死にそうになったら呼んでね」
「……分かってる」
```

**二度目の殺人**:
```
敵兵が、迫ってきた。

剣を構える。
手は、まだ震えている。
でも、前よりはましだ。

相手が斬りかかってくる。
避けて、突く。

また、あの感触。
肉に沈む感触。
血の温かさ。

「……」

殺した。
二人目。

「仕方なかった」

自分に、言い聞かせた。
殺さなきゃ、殺されてた。
仕方なかったんだ。
```

### シーン2：合理化（〜3,500字）

**内容**:
- 「仕方なかった」を繰り返す
- 少しずつ、楽になる
- でも、完全には消えない
- 悪夢は続く

**言い聞かせる**:
```
仕方なかった。
殺さなきゃ、殺されてた。
俺が死んだら、アリシアが悲しむ。
約束を、破ることになる。
だから、仕方なかったんだ。

何度も、何度も、自分に言い聞かせた。

少しずつ、楽になった。
少しずつ、罪悪感が薄れていった。

でも、完全には消えなかった。
夜になると、あいつらの顔が浮かぶ。
殺した敵兵たちの顔。
「なぜ俺を殺した」と、問いかけてくる。
```

**疑問**:
```
「仕方なかった」

本当に、そうなのか。

殺さなきゃ、殺されてた。
それは、事実だ。
でも、それで許されるのか。
俺は、人を殺した。
その事実は、消えない。

「……」

考えるのを、やめた。
考えても、答えは出ない。
考えれば考えるほど、苦しくなる。

だから、考えないことにした。
「仕方なかった」と、思うことにした。
```

### シーン3：三度目の殺人（〜3,000字）

**内容**:
- 十一度目の戦闘
- 三度目の殺人（自力）
- 前より、楽に殺せた
- それが、怖い

**戦闘**:
```
十一度目の戦闘。
三度目の殺人。

敵兵が迫ってくる。
剣を構える。
斬る。

「……」

殺した。
三人目。

前より、楽だった。
手の震えが、少なくなっていた。
吐き気も、前ほどじゃなかった。
```

**恐怖**:
```
それが、怖かった。

慣れている。
俺は、人を殺すことに、慣れ始めている。

「……」

これでいいのか。
人を殺すことに、慣れていいのか。

「いいんじゃない？」

ルシウスの声が聞こえた。

「慣れなきゃ、死ぬよ？」
「……」
「君、生き延びたいんでしょ？」
「……ああ」
「じゃあ、慣れるしかないじゃん」
```

---

### シーン4：夜（〜2,500字）

**内容**:
- 夜、眠れない
- 悪夢は続く
- でも、前よりはまし
- 「慣れた」のか、「麻痺した」のか

**眠れない夜**:
```
夜、テントの中。
眠れなかった。

目を閉じると、顔が浮かぶ。
殺した敵兵たちの顔。
一人目。二人目。三人目。

「……」

でも、前よりはましだった。
悪夢を見ても、前ほど苦しくない。
吐き気も、前ほどじゃない。

慣れたのか。
それとも、麻痺したのか。
```

**自問**:
```
俺は、どうなっていくんだろう。

このまま、人を殺し続けて。
このまま、慣れていって。
最後には、何も感じなくなるのか。

「……」

それは、嫌だ。
人を殺して、何も感じない人間になりたくない。

でも、感じていたら、壊れる。
感じていたら、生き延びられない。

「……」

どうすればいいのか、分からなかった。
```

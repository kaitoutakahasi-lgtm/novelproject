## シーン構成

### シーン1：殺害の瞬間（〜4,500字）★最重要

**内容**:
- 相手が先に動く
- 反射的に剣を振る
- 刃が肉を裂く感触
- 血が噴き出す

**動き出し**:
```
相手が、動いた。

剣を振り上げる。
僕を殺すために。

体が、勝手に動いた。
考えるより先に。
ルシウスに教わった通りに。

半身になって、相手の剣を避けて――

突いた。
```

**殺害の瞬間（五感描写）**:
```
【触覚】
剣が、肉に沈んでいく感触。
抵抗があった。
骨に当たった。
それでも、押し込んだ。

【聴覚】
「……っ」
相手の口から、声が漏れた。
悲鳴じゃない。呻きでもない。
ただ、空気が漏れるような音。

【視覚】
相手の目が、見開かれた。
驚きと、恐怖と、何か別のもの。
僕を見ていた。
僕の顔を、見ていた。

【嗅覚】
血の匂いが、鼻を突いた。
生臭い。温かい。
こんなに近くで嗅いだのは、初めてだった。

【触覚・温度】
血が、手に伝わってきた。
温かかった。
生きている温かさだった。
```

**死の瞬間**:
```
相手の目から、光が消えていく。

ゆっくりと。
確実に。

「……」

僕は、その目を見ていた。
見ていることしか、できなかった。

やがて、相手の体から力が抜けた。
剣を抜くと、崩れ落ちた。

死んだ。

僕が、殺した。
```

### シーン2：崩壊（〜4,000字）

**内容**:
- 剣を握ったまま、動けない
- 「殺した」「僕が、殺した」
- 手が震える、吐き気
- 嘔吐

**動けない**:
```
剣を握ったまま、立っていた。
動けなかった。

血が、剣を伝って、手に流れてくる。
温かい。
まだ、温かい。

「……」

殺した。

僕が、殺した。

ルシウスじゃない。
僕の手で。僕の意志で。僕が。
```

**身体反応**:
```
手が、震え始めた。
止まらなかった。

剣を落とした。
血のついた剣が、地面に落ちた。

「……っ」

吐き気がこみ上げてきた。
堪えられなかった。

膝をついて、吐いた。
何度も、何度も。
胃の中のものを、全部吐き出した。
```

**ルシウスの反応**:
```
「お疲れ様」

ルシウスの声が聞こえた。
いつもと同じ、軽い声。

「自分でやったね」
「……」
「どう？　感想は」
「……」
「泣いてるの？」

泣いていた。
いつの間にか、涙が流れていた。
```

### シーン3：一人称の変化（〜3,500字）★最重要

**内容**:
- 「僕は、人を殺した」
- 「僕は…いや、違う」
- 「『僕』なんて、もういない」
- 「俺は…俺は、人を殺した」

**認識の変化**:
```
僕は、人を殺した。

その言葉が、頭の中で繰り返された。
何度も。何度も。

僕は、人を殺した。
僕は、殺人者だ。

「……」

違う。

『僕』は、人を殺さない。
『僕』は、平凡な商家の次男だ。
『僕』は、アリシアの幼馴染だ。
『僕』は、戦争なんか関係ない、普通の少年だ。

でも、『僕』は人を殺した。

だから、『僕』はもういない。
```

**変化の瞬間**:
```
「……俺は」

口から、違う言葉が出た。

「俺は、人を殺した」

『僕』じゃない。
『俺』だ。

人を殺した『俺』。
殺人者の『俺』。

「俺は……」

涙が、止まらなかった。
でも、もう『僕』には戻れない。
```

### シーン4：戦闘後（〜3,000字）

**内容**:
- 戦闘が終わる
- 野営地に戻る
- 誰にも話せない
- 一人で抱え込む

**帰還**:
```
戦闘が、終わった。
いつの間にか、終わっていた。

俺は、野営地に戻った。
足が重かった。
体が重かった。
何もかもが、重かった。
```

**孤立**:
```
「エルヴィン、大丈夫か？」

レオンの声が聞こえた。
振り向けなかった。

「……大丈夫」
「顔色、悪いぞ」
「……大丈夫だ」

嘘だ。
大丈夫じゃない。

でも、言えなかった。
「人を殺した」なんて。
「俺は殺人者だ」なんて。
```

**夜**:
```
夜、眠れなかった。

目を閉じると、あいつの顔が浮かぶ。
光が消えていく目。
血の温かさ。
肉を裂く感触。

「……」

俺は、人を殺した。

その事実が、消えない。
一生、消えない。
```

## 重要な描写ポイント

### 殺害の瞬間
1. 相手が先に動く（エルヴィンは「殺された」側でもある）
2. 反射的に動く（考える暇がない）
3. 五感全てで感じる（逃げられない）
4. 相手の目を見る（人間として認識）
5. 死の瞬間を目撃する（光が消える）

### 一人称変化の論理
1. 「僕」は人を殺さない普通の少年
2. でも「僕」は人を殺した
3. だから「僕」はもういない
4. 人を殺した「俺」が残った
5. 「俺」は殺人者

### ルシウスの態度
- 褒めない、励まさない
- 「お疲れ様」「どう？」と軽く
- エルヴィンの苦しみを理解しない
- でも、見捨てない

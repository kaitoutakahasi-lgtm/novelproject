## 章の目的

### 物語上の役割
1. 「自分で戦う」決意
2. 敵兵との一対一の対峙
3. 敵も「人間」であることの認識
4. 殺すか殺されるかの選択を迫られる
5. ch18「血の洗礼」への直接的な布石

### 読者への効果
- 緊張感の頂点
- 敵兵への共感（同じ徴兵された若者）
- 「殺す」ことの重みを実感させる

### ch16との連続性
- ch16：悪夢、心身の消耗
- ch17：それでも戦場に立つ、自分で戦う決意

## シーン構成

### シーン1：八度目の戦場へ（〜3,000字）

**内容**:
- 「今日は、自分でやってみる」
- ルシウスに頼らない決意
- でも、不安

**決意**:
```
八度目の戦闘。
もう、数えるのも嫌になってきた。

「今日は、自分でやる」

心の中で、そう決めた。
ルシウスに頼ってばかりじゃ、駄目だ。
借りた力で生き延びても、それは僕の力じゃない。

「へえ、珍しいね」

ルシウスが、興味深そうに言った。

「いつも僕に任せっきりなのに」
「……うるさい」
「別にいいけど。死にそうになったら呼んでね」
```

**不安**:
```
剣を握る手が、震えている。
訓練はした。ルシウスに教わった。
でも、実戦は違う。
相手も、殺しにくる。

「……大丈夫」

自分に言い聞かせた。
大丈夫じゃないことは、分かっていた。
```

---

### シーン2：混戦（〜3,000字）

**内容**:
- 戦闘開始
- 混乱の中、必死に戦う
- 何とか生き延びている
- でも、技術は足りない

**戦闘描写**:
```
怒号。悲鳴。金属がぶつかる音。
戦場は、いつも同じだ。
混乱と、恐怖と、死の匂い。

敵兵が迫ってくる。
剣を構える。
ルシウスに教わった通り、半身に構えて――

「遅い」

ルシウスの声が聞こえた。
でも、体は動かない。
自分の体なのに、思い通りに動かない。

敵の剣が振り下ろされる。
辛うじて、受け止めた。
腕が痺れる。
```

**生き延びる**:
```
何度か、死にかけた。
その度に、ルシウスが「呼んで」と言った。
でも、呼ばなかった。

「……っ」

必死だった。
技術じゃない。ただ、必死に剣を振った。
それだけで、何とか生き延びていた。
```

---

### シーン3：一対一（〜4,000字）

**内容**:
- 混乱の中、敵兵と一対一に
- 相手も若い（16-17歳くらい）
- 恐怖と躊躇
- 「こいつも、徴兵されたんだ」

**遭遇**:
```
気づいたら、一人だった。
味方とはぐれていた。

目の前に、敵兵がいた。
一人。

若い。
僕より少し年上くらい。十六か、十七か。
顔が、青ざめている。
剣を構えているが、手が震えている。

「……」

僕も、同じだった。
剣を構えている。手が震えている。
```

**認識**:
```
こいつも、怖いんだ。

そう思った瞬間、敵兵の顔が変わった。
「敵」じゃなくなった。
「人間」になった。

こいつにも、家族がいるかもしれない。
待っている人がいるかもしれない。
徴兵されて、戦場に来て、怖くて、震えている。

僕と、同じだ。
```

---

### シーン4：動けない（〜2,000字）

**内容**:
- 剣を構えたまま、動けない
- 相手も動けない
- 「殺したくない」
- でも、「殺さなければ、殺される」

**膠着**:
```
どれくらい、そうしていただろう。
数秒か。数十秒か。

動けなかった。
相手も、動けなかった。

「……」

殺したくない。
こいつを殺したくない。
こいつにも、帰る場所がある。待っている人がいる。

でも。

殺さなければ、殺される。
僕が死んだら、アリシアが悲しむ。
約束を、破ることになる。

「……」

剣を握る手に、力を込めた。
```

**ルシウスの声**:
```
「ねえ、どうするの？」

ルシウスの声が、頭の中に響いた。

「殺すの？　殺さないの？」
「……」
「殺さないなら、君が死ぬよ？」
「……分かってる」
「じゃあ、殺すの？」
「……」
「僕がやろうか？」
「……いい」
「へえ」
```

**章末**:
```
相手の目が、動いた。
決意した目。
こいつも、覚悟を決めたんだ。

次の瞬間、相手が動いた。

僕も、動いた。
```

## キャラクター描写

- 「自分で戦う」決意

- 殺すことへの躊躇

### ルシウス
- 観察者として見守る
- 「どうするの？」と問いかける
- 手を出さない（エルヴィンの決意を尊重？　それとも面白がっている？）

### 敵兵
- 名前のない若者
- エルヴィンと同じ境遇
- 同じように怖がっている
- 同じように覚悟を決める

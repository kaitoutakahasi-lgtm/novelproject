## シーン構成

### シーン1：初陣の通達（〜4,000字）

**内容**:
- 「明日、前線に出る」
- 野営地全体に緊張が走る
- 新兵たちの反応（恐怖、諦め、虚勢）
- エルヴィンの複雑な感情

**通達の場面**:
```
「明日、お前たちは初めての戦場に立つ」
「訓練は終わりだ。これからは本番だ」
「生き延びたければ、学んだことを忘れるな」
「死にたくなければ、仲間を信じろ」
```

**エルヴィンの反応**:
- 恐怖が戻ってくる
- でも、3週間前とは違う
- 「俺には、ルシウスがいる」
- 「でも、本当に大丈夫なのか」

**ルシウスの無関心な反応**:
```
「明日か。やっと本番だね」
「……怖い」
「そう」
「……それだけか」
「他に何か言うことある？」
```

---

### シーン2：レオンとの約束（〜4,000字）

**内容**:
- 夜、レオンと話す
- 「一緒に生き延びような」
- 「ああ、約束だ」
- 友情の確認

**レオンとの会話**:
```
「明日、怖いか」
「……怖い」
「俺もだ。でも、お前がいるから少し安心だ」
「俺が？」
「お前、強くなっただろ。頼りにしてるぜ」
「……ああ」
「一緒に生き延びような。約束だ」
```

**手を握るシーン**:
```
レオンが、手を差し出した。
僕は、その手を見た。
友達。僕の、唯一の友達。
この手を握ったら、約束になる。
僕は、レオンの手を握った。
「約束する」
レオンの手は、温かかった。
```

**エルヴィンの罪悪感**:
- 「俺が強くなったのは、ルシウスのおかげだ」
- 「レオンは、俺を信じている」
- 「でも、俺は嘘をついている」
- 「……ごめん、レオン」

---

### シーン3：ルシウスとの最終確認（〜4,000字）

**内容**:
- 夜、テントの外でルシウスと話す
- 「明日、本番だね」
- 憑依の最終確認（事務的に）

**ルシウスとの会話（事務的）**:
```
「確認するけど、死にそうになったら呼んでね」
「……ああ」
「呼ばないと、僕は何もできないから」
「分かってる」
「あと、呼んだら僕が判断して動くから。文句言わないでね」
「……ああ」
「じゃ、それだけ」
```

**エルヴィンの問いかけ**:
```
「……お前は、怖くないのか」
「何が？」
「明日、俺が死ぬかもしれない」
「そうだね」
「……それだけか」
「君が死んだら、また別の人を探すだけだよ」
「……」
「まあ、面倒だから、できれば死なないでね」
「……でも」
「君、面白いから。死んだら、ちょっと残念かも」
「……」
「ちょっとだけね。すぐ忘れると思うけど」
```

**ルシウスの変化の兆し**:
- 三週間前なら「ちょっと残念」とも言わなかった
- 何かが、少しだけ変わっている
- 気のせいかもしれない
- でも、エルヴィンはそう感じた
```

---

### シーン4：夜明け前（〜3,000字）

**内容**:
- 眠れない夜
- アリシアのお守りを握る
- 「必ず帰る」
- 夜明けの描写、第一部の締めくくり

**内的独白**:
```
眠れなかった。

明日、俺は初めて戦場に立つ。
初めて、人を殺すかもしれない。
初めて、死ぬかもしれない。

怖い。

でも、3週間前とは違う。
俺には、ルシウスがいる。
……いや、ルシウスは俺の味方じゃない。
ただの契約相手だ。
俺が死んだら、別の人を探すと言った。
それが、あいつの本音だ。

でも、それでいい。
俺には、レオンがいる。
俺には、帰る場所がある。

アリシアのお守りを握る。
星の形をした、小さなお守り。
冷たい。でも、その冷たさが、心に残った。

「必ず帰る」

そう約束した。

だから、死ねない。
だから、生き延びる。

灰色の空が、少しずつ白み始める。
夜明けだ。

俺の、新しい一日が始まる。
```

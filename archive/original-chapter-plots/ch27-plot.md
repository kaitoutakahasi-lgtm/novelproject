## シーン構成

### シーン1：レオンの死後（〜3,500字）

**内容**:
- 数日が経った
- レオンがいない日常
- 空虚感
- 「もう、いないんだ」

**日常**:
```
レオンが死んで、数日が経った。

朝が来る。
起きる。
食事をする。
訓練をする。

同じ日常。
でも、レオンがいない。

「……」

隣に、誰もいない。
声をかけてくる人が、いない。
「おはよう」と言ってくれる人が、いない。
```

**空虚**:
```
空虚だった。

レオンがいた場所に、穴が空いている。
埋められない穴。
永遠に、埋められない穴。

「……」

もう、いないんだ。
レオンは、もういないんだ。

分かっているのに、まだ信じられなかった。
```

---

### シーン2：決意（〜4,000字）★重要

**内容**:
- 「もう、友達は作らない」
- 「近づけば、失う」
- 孤立を選ぶ
- 自分を守るため

**決意**:
```
「もう、友達は作らない」

そう決めた。

近づけば、失う。
親しくなれば、死んだ時に辛い。
レオンで、分かった。

「……」

だから、もう誰にも近づかない。
誰とも親しくならない。
一人でいい。
一人の方が、楽だ。
```

**合理化**:
```
これは、正しい選択だ。

戦場で、友達を作るのは愚かだ。
いつ死ぬか分からない。
いつ失うか分からない。

だから、最初から作らない。
最初から、距離を置く。
そうすれば、失っても辛くない。

「……」

嘘だ。
辛くないわけがない。
でも、そう思わないと、やっていけない。
```

---

### シーン3：「英雄」の評判（〜2,500字）

**内容**:
- 「クライスはすごい」
- 「あいつは死なない」
- 「英雄だ」
- 虚しい称賛

**評判**:
```
「クライス、お前すごいな」

誰かが言った。

「大会戦で、あれだけ戦って、傷一つないなんて」
「……」
「お前、英雄だよ」
「……」
「みんな、お前のこと尊敬してる」

英雄。
また、その言葉。
```

**虚しさ**:
```
英雄なんかじゃない。

俺は、借りた力で生き延びているだけだ。
レオンは死んだ。
俺は生きている。
それだけの違いだ。

「……」

称賛が、虚しかった。
俺は、何も偉くない。
俺は、何も強くない。
ただ、ルシウスがいるだけだ。
```

---

### シーン4：ルシウスとの夜（〜2,000字）

**内容**:
- 夜、ルシウスと話す
- 「友達、死んじゃったね」
- 「もう作らないの？」
- 「……ああ」

**会話**:
```
「友達、死んじゃったね」

夜、ルシウスが言った。

「……ああ」
「悲しい？」
「……ああ」
「そっか」

ルシウスが、首を傾げた。

「もう、作らないの？　友達」
「……ああ」
「なんで？」
「……失うから」
「へえ」
```

**ルシウスの反応**:
```
「僕は、いなくならないよ」

ルシウスが言った。

「……」
「僕、幽体だから。死なないし」
「……」
「だから、僕だけは、いなくならない」
「……」
「君が死なない限り」

その言葉が、胸に残った。
ルシウスだけは、いなくならない。
それが、救いなのか、呪いなのか、分からなかった。
```

## 章の目的

### 物語上の役割
1. ルシウスとの出会い（物語の核心）
2. 契約の提案と葛藤
3. 「生き延びたい」という決断
4. ルシウスの魅力と不気味さの確立
5. 第一部の締めくくり

### 読者への効果
- ルシウスへの興味と恐怖（正体は謎のまま）
- エルヴィンの決断への共感
- 物語の本格的な始まりへの期待

### ルシウスの情報開示方針
この章で明かすこと：
- 名前（ルシウス）
- 幽体であること（触れない、見えるのはエルヴィンだけ）
- 契約と憑依の仕組み
- 等価交換のルール

この章では明かさないこと：
- エルドラシア出身
- 王子だったこと
- アルトゥスの存在
- 封印された理由
- 300年という時間

## シーン構成

### シーン1：逃亡の夜（約4,000字）

#### 概要
耐えられなくなる。夜中に野営地を抜け出す。森の中へ。死を覚悟する。

#### 場所
野営地、森

#### 登場人物
- エルヴィン

#### 詳細プロット

**限界（〜1,200字）**:
```
訓練が始まって、一週間が過ぎた。

体は、限界だった。腕は上がらない。足は震える。頭は、ぼんやりとしている。

毎日、同じことの繰り返し。走って、剣を振って、怒鳴られて、また走って。

「弱い」

ガレスの声が、頭の中で響いている。

「お前たちは、弱すぎる」

分かっている。分かっているけど、どうすればいいのか分からない。

レオンは、少しずつ上達していた。農作業で鍛えた体が、訓練に耐えている。
剣の振り方も、走る速さも、僕より上だ。

僕だけが、取り残されている。

僕だけが、弱いままだ。
```

**逃亡（〜1,400字）**:
```
その夜、僕は眠れなかった。

目を閉じると、戦場の光景が浮かぶ。古参兵が語った、血の話。矢が刺さる音。
温かい血の感触。

「死にたくない」

その言葉が、頭の中で繰り返される。

気がつくと、僕はテントを出ていた。

夜の野営地。篝火が、あちこちで燃えている。見張りの兵士が、巡回している。

僕は、その隙間を縫って歩いた。どこへ行くのか、自分でも分からなかった。
ただ、ここにいたくなかった。

野営地の外れに、森があった。

暗い森。月明かりが、木々の隙間から差し込んでいる。

僕は、その森に入った。

逃げているのか。死にに行くのか。自分でも、分からなかった。

ただ、歩いた。暗い森の中を、ただ歩いた。
```

**死の覚悟（〜1,400字）**:
```
どれくらい歩いただろう。

気がつくと、小さな空き地に出ていた。

月明かりが、空き地を照らしている。草が、銀色に光っている。

僕は、そこに座り込んだ。

足が、動かなかった。体が、重かった。心が、空っぽだった。

「もう、いいかな」

そう思った。

このまま、ここで死んでもいい。戦場で死ぬより、ここで死んだ方がましだ。

アリシアとの約束。母との約束。兄との約束。

全部、破ることになる。

でも、もう、どうでもよかった。

「ごめん」

誰にともなく、呟いた。

「ごめん、アリシア。ごめん、母さん。ごめん……」

涙が、出てきた。止められなかった。

月明かりの下で、僕は泣いた。声を殺して、肩を震わせて。

一人で、泣いた。
```

- 死の覚悟（生への渇望の裏返し）

### シーン2：ルシウスとの出会い（約5,000字）

#### 概要
月明かりの中、異様な少年。エルヴィンの驚愕。ルシウスは「面白いおもちゃ」を見つけた態度。正体は明かさない。

#### 場所
森の空き地

#### 登場人物
- エルヴィン
- ルシウス（初登場）

#### 詳細プロット

**出会い（〜1,500字）**:
```
「泣いてるの？」

声がした。

僕は、顔を上げた。

――息が、止まった。

月明かりの中に、誰かが立っていた。

少年だった。八歳か、九歳くらいに見える。

しかし、その姿は――

「なっ……」

声にならなかった。

銀色の髪が、月明かりを受けて輝いている。肌は、桃色がかった半透明。
輪郭がぼやけている。まるで水彩画のような存在感。

そして、目。

深い紫色の目。澄んでいるが、どこか冷たい。

僕は、後ずさった。手が震えている。足が震えている。

「な、なんだ……お前……」

声が、掠れた。

少年は、首を傾げた。

「なんだ、って。失礼だなあ」

その声は、澄んでいた。子供の声。でも、どこか現実感がない。

「僕はルシウス。君は？」
「……」
「聞いてるんだけど」
「……エルヴィン」
「ふうん。エルヴィン」

少年――ルシウスは、僕の前にしゃがみ込んだ。

近くで見ると、さらに異様だった。体が半透明で、向こう側の木々がうっすら見える。

「君、泣いてたでしょ」

ルシウスが、僕の顔を覗き込んだ。

「……」
「なんで泣いてたの？」
「……お前には関係ない」
「関係ないけど、聞いてるの」

ルシウスは、にっこり笑った。

その笑顔が、怖かった。子供の笑顔なのに、目が笑っていない。
```

**ルシウスの態度（〜1,800字）**:
```
「死にたいの？」

ルシウスが、唐突に聞いた。

「……は？」
「だって、こんな森の中で一人で泣いてるんでしょ。死にたいのかなって」
「……」
「違うの？」

僕は、答えられなかった。

死にたいのか。死にたくないのか。自分でも分からなかった。

「ふうん」

ルシウスは、立ち上がった。僕の周りをぐるぐる歩き始めた。
足音がしない。地面を踏んでいないのだ。

「君、面白いね」
「……何が」
「目」
「目？」
「灰色の目。何も映してないみたいなのに、全部見てる目」

ルシウスが、僕の前で止まった。

「諦めてるみたいなのに、諦めてない。死にたいみたいなのに、死にたくない」
「……」
「矛盾してるよね。人間って、みんなそうなの？」

その言葉に、僕は眉をひそめた。

「お前は……何なんだ。幽霊か」

ルシウスは、きょとんとした顔をした。

「幽霊？　んー、近いかも。でもちょっと違うかな」
「じゃあ、何なんだ」
「んー」

ルシウスは、首を傾げた。

「説明めんどくさいな。まあ、そのうち分かるよ」

答えになっていない。でも、それ以上聞く気力もなかった。

「ねえ、君、名前なんだっけ」
「……さっき言っただろ。エルヴィン」
「あ、そうだった。忘れてた」

忘れてた。

さっき聞いたばかりなのに。

「君さあ、面白いから、ちょっと遊ばない？」
「……遊ぶ？」
「うん。僕、暇なんだよね。ずっと一人だったから」
```

**ルシウスの提案（〜1,200字）**:
```
「遊ぶって、何を」
「んー、なんでもいいけど」

ルシウスは、僕の顔をじっと見た。

「あ、そうだ。君、死にたくないんでしょ？」
「……」
「助けてあげようか」
「……は？」
「僕、けっこう強いんだよ。君が死にそうになったら、助けてあげる」

その言葉に、僕は目を見開いた。

「なんで、そんなことを」
「だから、暇だから」

ルシウスは、あっけらかんと言った。

「君、面白そうだし。死んだらつまんないじゃん」
「……」
「あ、でもタダじゃないよ。僕にもメリットないと」

ルシウスは、指を立てた。

「君の体、たまに借りていい？」
「体を……借りる？」
「うん。僕、見ての通り、触れないんだよね」

ルシウスは自分の半透明な手を見た。

「食べられないし、何も感じられない。だから、君の体借りて、
色々やってみたいの」
「色々って……」
「食べたり、寝たり、歩いたり。感じるってこと、体験してみたいんだよね」

ルシウスは、無邪気に笑った。

「どう？　悪い話じゃないでしょ」

悪い話じゃない。

本当に、そうなのか。

僕には、分からなかった。
```

#### 伏線配置
- ルシウスの外見への驚愕（半透明、幽体）
- 正体を明かさない（「そのうち分かるよ」）
- 「面白いから」という動機（おもちゃ的な興味）
- 名前を忘れる（人の心がわからない、興味がない）
- 「ずっと一人」（孤独の伏線、期間は明かさない）

### シーン3：契約の詳細（約5,000字）

#### 概要
憑依の説明。等価交換の説明。ルシウスの軽い態度と、隠された危険。

#### 場所
森の空き地

#### 登場人物
- エルヴィン
- ルシウス

#### 詳細プロット

**憑依の説明（〜1,500字）**:
```
「体を借りるって、どういうことだ」

僕は、聞いた。

「んー、説明めんどくさいな」

ルシウスは、頭を掻いた。

「簡単に言うと、僕が君の中に入るの。で、君の体を動かす」
「……は？」
「憑依って言うんだけど。聞いたことない？」
「ない」
「そっか。まあ、普通は知らないよね」

ルシウスは、僕の周りをぐるぐる歩きながら説明した。

「僕、ずっとこの状態なの。触れない、感じられない」
「……」
「だから、誰かの体を借りるの。そうすると、その人の体で色々できる」
「僕の体で、お前が動くってことか」
「そうそう。頭いいね、君」

ルシウスは、にっこり笑った。

「僕が君の体使ってる間、君は寝てるみたいな感じになるよ。意識はあるけど、
体は動かせない」
「……それ、怖いんだけど」
「まあ、そうだよね」

ルシウスは、あっさり認めた。

「でも、僕が体使ってる間、君の体すごく強くなるよ。僕、戦い方知ってるから」
「戦い方？」
「うん。剣の振り方も、体の動かし方も。君より上手く戦える」

その言葉に、心が揺れた。

「なんで、お前がそんなこと知ってるんだ」
「んー、色々あってね」

また、はぐらかされた。
```

**代償（〜1,200字）**:
```
「で、代償は？」

僕は、聞いた。タダで助けてくれるわけがない。

「お、ちゃんと聞くんだ。えらいね」

ルシウスは、指を立てた。

「時間」
「時間？」
「僕が戦いで君の体借りた分だけ、普段の生活でも同じ時間、僕に体を貸してもらう」
「……」
「一時間借りたら、一時間分。一日借りたら、一日分。等価交換ってやつ」

等価交換。

「……それだけか？」
「それだけだよ。分かりやすいでしょ」

ルシウスは、けろっとした顔で言った。

「でもさ、考えてみて。僕が君の体使ってる間、君は何もできないんだよ」
「……」
「誰かと話してても、突然僕が出てくるかもしれない。大事な時に、
君の体が君のものじゃなくなるかもしれない」

ルシウスは、にっこり笑った。

「それって、けっこう怖くない？」

怖い。

確かに、怖い。

「いつ使うかは、僕が決める。君は拒否できない。それが、等価交換」
「……」
「でもさ、今死ぬよりマシでしょ？」

その言葉に、反論できなかった。

「あ、でも僕もそんなに長く借りないよ。体使うの疲れるし」
「疲れる？」
「うん。人間の体って、けっこう不便なんだよね。すぐお腹空くし、眠くなるし」

ルシウスは、不満そうな顔をした。

「だから、本当にヤバい時だけ借りる。それでいいでしょ？」
```

**ルシウスの本音（〜800字）**:
```
「なんで、僕なんだ」

僕は、聞いた。

「え？」
「他にも人間はいるだろ。なんで、僕に声をかけた」

ルシウスは、きょとんとした顔をした。

「んー、なんでだろ」
「分からないのか」
「分かんない。なんとなく？」

なんとなく。

この得体の知れない存在が、なんとなくで契約を持ちかけてくる。

「君、面白そうだったから」

ルシウスが、言った。

「泣いてるのに、諦めてない顔してた。死にたいのに、死にたくない顔してた」
「……」
「矛盾してるよね。でも、そういうの好きなんだよね、僕」

ルシウスは、無邪気に笑った。

「だから、もうちょっと見てたいなって。死んだらつまんないから、助けてあげようかなって」

それが、ルシウスの本音だった。

僕を助けたいわけじゃない。ただ、面白いから。暇だから。

それだけの理由で、契約を持ちかけている。

……でも、理由なんて、どうでもいいのかもしれない。

助けてくれるなら。生き延びられるなら。
```

#### 伏線配置
- 憑依の仕組み（後の展開への伏線）
- 等価交換の怖さ（時間だけでなく「いつ使うか分からない」恐怖）
- 戦い方を知っている理由は明かさない
- 「面白いから」という動機（おもちゃ的な興味）
- エルヴィンの割り切り（生き延びるためなら理由は問わない）

#### 場所

#### 登場人物

#### 詳細プロット

**葛藤（〜1,200字）**:
```
僕は、黙っていた。

契約。憑依。等価交換。

その言葉が、頭の中で渦巻いている。

「どうする？」

ルシウスが、聞いた。

「……考えさせてくれ」
「いいよ。でも、あんまり長いと飽きちゃうかも」

飽きる。

この少年は、本当に人の心が分からないらしい。

僕は、考えた。

契約すれば、強くなれる。戦場で生き残れる。帰れる。

でも、代償がある。体を明け渡す。いつ、どこで使われるか分からない。

大事な瞬間に、僕の体が僕のものじゃなくなるかもしれない。

それは、正しいことなのだろうか。

分からなかった。
```

**アリシアとの約束（〜1,200字）**:
```

金色の髪。青い瞳。涙を流しながら、微笑んでいた顔。

「必ず、帰ってきて」

その言葉が、心に響いた。

母の顔も、浮かんだ。泣きながら、僕を抱きしめていた顔。

父の顔も、浮かんだ。銀貨を渡しながら、肩を叩いていた顔。

兄の顔も、浮かんだ。目を赤くしながら、僕を見ていた顔。

みんな、待っている。僕が帰るのを、待っている。

「帰りたい」

その言葉が、口から漏れた。

「帰りたい。みんなのところに、帰りたい」

涙が、また出てきた。
```

```
「決めた」

僕は、言った。

「契約する」

ルシウスは、にっこり笑った。

「お、決めたんだ。早いね」
「……」
「後悔しない？」
「分からない。でも、死ぬよりはいい」
「まあ、そうだよね」

ルシウスが、手を差し出した。

半透明の手。触れられるのだろうか。

「契約は、握手で成立するの。僕の手を取って」

僕は、その手に触れた。

冷たかった。氷のように冷たい。でも、確かに触れている。

「契約成立」

ルシウスが、言った。

その瞬間、何かが変わった。

体の中に、何かが流れ込んでくる。冷たくて、甘くて、どこか気持ち悪い何か。

「うわ、なんだこれ……」
「あ、ごめん。ちょっと気持ち悪いかも。すぐ慣れるよ」

ルシウスは、あっけらかんと言った。

ルシウスは、無邪気に笑った。

僕は、この得体の知れない存在と、契約した。

何も知らないまま。何者かも分からないまま。

ただ、生き延びたいという、その一心で。
```

## 執筆時の注意点

1. **ルシウスの描写**
   - 美しさと不気味さの両立
   - 子供らしさと残酷さの同居
   - 正体は謎のまま（「色々あって」「そのうち分かる」）

2. **契約の重み**
   - 等価交換の怖さを強調（いつ使われるか分からない）
   - 軽々しくない決断
   - 「生き延びたい」という切実さ

3. **情報の出し方**
   - ルシウスの過去は明かさない
   - 読者に「何者なんだ」と思わせる
   - エルヴィンと同じ視点で謎を感じさせる

4. **文体の維持**
   - 説明を物語に溶け込ませる
   - 会話は最小限に（ただしルシウスとの対話は例外）
   - 内省と情景を融合させる

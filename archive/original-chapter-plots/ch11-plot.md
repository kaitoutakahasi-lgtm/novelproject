## 章の目的

### 物語上の役割
1. ガレスとの対人訓練
2. ガレスに才能を認められる（「読み」の才能）
3. 新兵の中で上位に
4. 「成り上がり」の爽快感のピーク
5. 初陣への準備

### 読者への効果
- 成長の集大成
- 権威者（ガレス）からの承認
- 初陣への期待と不安

### ch10との差別化
- ch10：契約の代償、等価交換の現実、ルシウスのやらかし
- ch11：成長の集大成、ガレスからの承認

### ルシウスの描写
- ガレスに認められても「だから何」という態度
- エルヴィンの喜びに水を差す
- 褒めない、励まさない
- 「借りた力」と「自分の力」の区別に無関心

## シーン構成

### シーン1：新兵の中で上位（〜2,500字）

**内容**:
- 対人訓練で5勝1敗
- 新兵の中で上位に
- 周囲の評価が完全に変わる
- 「クライス、お前すごいな」

**描写**:
```
五人目を倒した時、周りが静まり返った。
二週間前、底辺だった俺が。
今、新兵の中で上位にいる。
「……嘘だろ」
誰かが呟いた。
俺も、そう思った。
```

**レオンの反応**:
```
「お前、本当にすごいな」
「……運がいいだけだ」
「運だけで5勝できるか。何か秘訣があるんだろ」
「……」
「まあ、いいけど。俺も負けてられないな」
```

**ルシウスの辛辣な反応**:
```
「5勝1敗ね。1敗してるじゃん」
「……」
「新兵相手に1敗。戦場じゃ死んでるよ」
「分かってる」
「本当に？　顔、嬉しそうだけど」
```

### シーン2：ガレスとの対人訓練（〜4,000字）

**内容**:
- ガレスが直接エルヴィンと訓練
- 「クライス、相手してやる」
- 緊張の中、全力で挑む
- 当然負けるが、予想以上に持つ

**戦闘描写**:
```
ガレスの剣が、風を切った。
速い。新兵とは、比べ物にならない。
でも、見える。
右肩が下がった。右から来る。
避ける。踏み込む。
「……ほう」
ガレスの目が、光った。
次の瞬間、俺は地面に転がっていた。
```

**ルシウスの辛辣な観察（心の中で）**:
```
「あの人、強いね。君とは格が違う」
「……分かってる」
「三手先まで読んでたのに、体が追いつかなかった」
「……」
「頭でっかちなんだよ、君」
```

---

### シーン3：ガレスの評価（〜3,000字）

**内容**:
- 訓練後、ガレスがエルヴィンを呼ぶ
- 「お前、才能があるかもしれん」
- 「読み」の才能を見抜く
- 「指揮官になれる」という言葉

**ガレスの言葉**:
```
「お前の剣は弱い。体も小さい」
「でも、俺の動きを読んでいた」
「体は追いつけていなかったが、数手先まで見えていただろう」
「……はい」
「それは才能だ。剣術だけの才能じゃない。頭を使う才能だ。」
「戦術……」
「剣で戦う兵士より、頭で戦う兵士の方が価値がある。運が良ければ良い指揮官になるかもな。」
```

**エルヴィンの反応**:
```
指揮官。
俺が、指揮官に。
「……はい」
それしか、言えなかった。
でも、胸の中で、何かが熱くなった。
俺にも、価値がある。
俺にも、才能がある。
```

---

### シーン4：夜の内省（〜2,500字）

**内容**:
- 夜、テントで考える
- ルシウスのおかげか、自分の才能か
- 「借りた力」と「自分の力」の境界
- 初陣への決意

**ルシウスとの会話**:
```
「ガレスに認められたね」
「……ああ」
「嬉しい？」
「……ああ」
「ふーん」
「……何だよ」
「別に。君が嬉しいなら、いいんじゃない」
「……」
「でも、読みの才能って、僕が見せた動きを覚えてるだけでしょ」
「……」
「それって、君の才能なの？　僕のおかげじゃないの？」
```

**エルヴィンの葛藤**:
```
借りた力と、自分の力。
その境界は、曖昧だ。
ルシウスに見せてもらった動きを、俺は覚えている。
それを応用して、相手を読んでいる。
それは、俺の才能なのか。
それとも、ルシウスの力を借りているだけなのか。
分からない。
でも、ガレスは俺を認めてくれた。
それだけは、事実だ。
「……初陣、生き延びる」
そう、心に誓った。
ルシウスは、何も言わなかった。
```

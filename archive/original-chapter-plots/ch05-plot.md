## シーン構成

### シーン1：野営地到着（約3,000字）

#### 概要
軍の厳しさ。ガレスとの出会い。「ここは地獄だ」。

#### 場所
野営地

#### 登場人物
- エルヴィン
- レオン
- ガレス（初登場）
- 他の新兵たち

#### 詳細プロット

**野営地の光景（〜1,000字）**:
```
野営地は、想像以上に大きかった。

テントが、どこまでも続いている。白い布が、灰色の空の下で揺れている。兵士
たちが、忙しそうに動いている。馬が嘶き、剣が鳴り、号令が飛び交っている。

「新兵、整列」

怒鳴り声に、慌てて並んだ。五十人の少年たちが、一列に並ぶ。

周りを見ると、他にも新兵の列があった。百人、二百人……もっといるかもしれ
ない。みな、僕と同じくらいの年齢。みな、怯えた顔をしている。

これだけの少年が、戦場に送られる。

その事実が、重くのしかかった。
```

**ガレスの登場（〜1,200字）**:
```
「俺がお前たちの教官だ」

声がした。

列の前に、男が立っていた。

三十代半ばくらいだろうか。背は高くない。しかし、体つきは引き締まっている。
顔には、いくつもの傷がある。目は、鋭い。獣のような目だった。

「名前はガレス。階級は軍曹だ」

ガレスが、僕たちを見回した。

その目が、僕を捉えた。一瞬だけ。しかし、その一瞬で、背筋が凍った。

「お前たち、なぜここにいるか分かるか」

誰も、答えなかった。答えられなかった。

「死ぬためだ」

その言葉が、静かに響いた。

「お前たちの大半は、最初の戦闘で死ぬ。それが現実だ」

誰かが、息を呑んだ。誰かが、泣き出した。

ガレスは、表情を変えなかった。
```

**厳しい言葉（〜800字）**:
```
「だが、生き延びる方法はある」

ガレスが、続けた。

「強くなれ。弱い奴から死ぬ。強い奴だけが生き残る」

強くなれ。

その言葉が、頭に残った。

「訓練は明日から始まる。今日は休め。休めるうちに、休んでおけ」

ガレスが、去っていった。

残されたのは、怯えた少年たちだけだった。

「……怖いな、あの人」

レオンが、小声で言った。

「うん……」
「でも、嘘は言ってない気がする」
「……うん」

生き延びるには、強くなるしかない。

でも、どうやって？

僕には、何の力もない。剣も持てない。走るのも遅い。

強くなれと言われても、どうすればいいのか分からなかった。
```

#### 伏線配置
- ガレスの厳格さ（後の対立への伏線）
- 「強い奴だけが生き残る」（力への渇望）
- ガレスの傷（戦場の経験者）

### シーン2：訓練（約3,500字）

#### 概要
過酷な訓練。身体の限界。「死ぬかもしれない」。

#### 場所
訓練場

#### 登場人物
- エルヴィン
- レオン
- ガレス
- 他の新兵たち

#### 詳細プロット

**朝の訓練（〜1,200字）**:
```
夜明け前に、叩き起こされた。

「起きろ。訓練だ」

眠い目をこすりながら、外に出た。まだ暗い。空気が、冷たい。

「走れ。野営地を十周だ」

走った。

最初は、なんとかついていけた。足が動く。息が続く。

三周目で、足が重くなった。

五周目で、息が上がった。

七周目で、倒れそうになった。

「遅い。もっと速く」

ガレスの声が、響く。

倒れたら、蹴られる。それは、最初の一周で学んだ。だから、走り続けた。

足が痛い。胸が苦しい。頭がぼんやりする。

それでも、走り続けた。
```

**剣の訓練（〜1,200字）**:
```
走り終わると、剣の訓練が始まった。

木剣を渡された。重い。腕が、震える。

「構えろ」

言われた通りに、構えた。しかし、すぐに直された。

「違う。もっと低く」
「こ、こうですか」
「まだ違う」

何度も、何度も、直された。腕が、痛くなった。

「振れ」

木剣を振った。百回。二百回。三百回。

腕が、上がらなくなった。でも、止まれなかった。

「弱い。お前たちは、弱すぎる」

ガレスの言葉が、突き刺さった。

弱い。

分かっていた。分かっていたけど、言葉にされると、重かった。
```

**限界（〜1,100字）**:
```
昼になっても、訓練は続いた。

走って、剣を振って、また走って。

「エルヴィン、大丈夫か？」

レオンが、声をかけてきた。

「……なんとか」
「顔、真っ青だぞ」
「レオンこそ……」

レオンも、限界に近かった。日焼けした顔が、蒼白になっている。

「俺たち、死ぬかもな」
「……やめてよ、そういうの」
「冗談だって」

冗談じゃない。

本当に、死ぬかもしれない。訓練で死ぬかもしれない。戦場に出る前に、死ぬ
かもしれない。

その恐怖が、心を蝕んでいった。

でも、止まれなかった。止まったら、もっと酷いことになる。

だから、動き続けた。
```

**見捨てる（〜800字）**:
```
午後の訓練中、一人の少年が倒れた。

僕の三つ隣にいた子だ。名前は知らない。顔も、よく覚えていない。

「立て」

ガレスの声が、響いた。

少年は、立てなかった。足が震えている。顔が蒼白だ。唇が、紫色になっている。

「立てないなら、置いていく」

ガレスが、歩き出した。他の少年たちも、続いた。

僕も、歩き出した。

振り返らなかった。

倒れた少年の顔を、見なかった。見たら、止まってしまう気がした。止まったら、
僕も置いていかれる。

「……ごめん」

心の中で、呟いた。

でも、足は止まらなかった。

後ろで、誰かが泣いている声が聞こえた。あの少年だろうか。それとも、別の誰か
だろうか。

分からなかった。分かりたくなかった。

僕は、前だけを見て歩いた。

その夜、あの少年がどうなったのか、誰も教えてくれなかった。聞く勇気も、
なかった。
```

#### 伏線配置
- 訓練の過酷さ（軍の現実）
- レオンの強がり（後の死への伏線）
- エルヴィンの弱さ（力への渇望）
- **見捨てる行為**（道徳心低下の具体化）

#### 道徳心変化
96→94（-2：暴力への恐怖、自分の弱さへの嫌悪、**弱者を見捨てた罪悪感**）

### シーン3：夜の恐怖（約3,000字）

#### 概要
眠れない夜。他の兵士の話。戦場の恐ろしさを聞く。

#### 場所
新兵のテント

#### 登場人物
- エルヴィン
- レオン
- 古参兵（名前なし）
- 他の新兵たち

#### 詳細プロット

**眠れない夜（〜1,000字）**:
```
訓練が終わって、テントに戻った。

体中が、痛い。腕が、上がらない。足が、震えている。

「疲れたな……」
「うん……」

レオンと、並んで横になった。

でも、眠れなかった。体は疲れているのに、頭が冴えている。

目を閉じると、ガレスの顔が浮かぶ。「弱い」という言葉が、響く。

「レオン、起きてる？」
「……ああ」
「眠れない」
「俺もだ」

二人で、天井を見上げた。テントの布が、風に揺れている。外から、誰かの声が
聞こえる。笑い声。怒鳴り声。泣き声。

野営地は、夜も眠らない。
```

**古参兵の話（〜1,200字）**:
```
「眠れないのか、新兵」

声がした。

テントの入り口に、男が立っていた。三十代くらい。顔に、大きな傷がある。
古参兵だ。

「……はい」
「無理もない。俺も最初はそうだった」

男が、テントに入ってきた。

「戦場の話、聞きたいか」
「……」
「聞いておいた方がいい。心の準備になる」

男が、話し始めた。

「最初の戦闘で、俺の隣にいた奴が死んだ」

その言葉が、静かに響いた。

「矢が、首に刺さった。一瞬だった」
「……」
「血が、俺の顔にかかった。温かかった」

吐き気がした。

でも、聞かなければならない気がした。これが、戦場なんだ。これが、僕が
向かう場所なんだ。
```

**戦場の現実（〜800字）**:
```
「戦場では、何が起こるか分からない」

男が、続けた。

「強い奴でも、運が悪ければ死ぬ。弱い奴でも、運が良ければ生き残る」
「……」
「でも、強い方が生き残る確率は高い」
「どうすれば、強くなれますか」
「訓練しかない。あとは、実戦で学ぶしかない」

男が、立ち上がった。

「まあ、頑張れ。死ぬなよ」

男が、去っていった。

残されたのは、恐怖だけだった。

レオンが、何か言おうとした。でも、言葉が出なかったようだ。

僕も、何も言えなかった。

ただ、震えていた。
```

#### 伏線配置
- 戦場の現実（死の身近さ）
- 「強くなりたい」という願望
- 運と実力の関係

### シーン4：絶望（約3,500字）

#### 概要
「生き延びられない」。逃げ出したい。死への恐怖。

#### 場所
野営地の外れ

#### 登場人物
- エルヴィン
- （レオンは眠っている）

#### 詳細プロット

**一人の時間（〜1,000字）**:
```
眠れないまま、テントを出た。

夜の野営地は、静かだった。篝火が、あちこちで燃えている。見張りの兵士が、
巡回している。

歩いた。どこへ行くでもなく、歩いた。

野営地の外れに、小さな丘があった。そこに座って、空を見上げた。

星が、見えた。昨日と同じ星。故郷でも見えた星。

でも、今日は違って見えた。遠くて、冷たくて、無関心な光。

「僕は、死ぬのかな」

声に出して、言ってみた。

誰も、答えなかった。星も、風も、何も答えなかった。
```

**絶望（〜1,200字）**:
```
訓練についていけない。

剣も、まともに振れない。走るのも、遅い。体力も、ない。

こんな僕が、戦場で生き残れるわけがない。

「死にたくない」

涙が、出てきた。止められなかった。

「死にたくない……死にたくない……」

何度も、繰り返した。でも、現実は変わらない。

明日も、訓練がある。そして、いつか、戦場に出る。そして、死ぬ。

「嫌だ……」

逃げたい。ここから、逃げ出したい。

でも、逃げたら、家族が。アリシアが。

逃げられない。でも、このままじゃ、死ぬ。

どうすればいい。どうすれば、生き延びられる。

答えは、出なかった。
```

**力への渇望（〜1,300字）**:
```
「力があれば」

ふと、そう思った。

力があれば、訓練についていける。力があれば、戦場で生き残れる。力があれば、
帰れる。

アリシアのところに、帰れる。母さんのところに、帰れる。

「力が、欲しい」

その願いが、心の中で大きくなっていった。

どんな力でもいい。生き延びるための力が、欲しい。

空を見上げた。星が、瞬いていた。まるで、何かを待っているように。

「誰か、助けて」

小さな声で、呟いた。誰にも、聞こえないはずの声。

でも、その声は、どこかに届いていたのかもしれない。

風が、吹いた。冷たい風。どこか、甘い匂いがした。

気のせいだと思った。

でも、その匂いは、消えなかった。

何かが、近づいている。

そんな気がした。
```

#### 伏線配置
- 「力が欲しい」という願望（契約への動機）
- 「誰か、助けて」という呟き（ルシウスへの伏線）
- 甘い匂い（ルシウスの予兆）
- 星のモチーフ（運命の予兆）

#### 道徳心変化
95→94（-1：逃げたい気持ち、弱さへの嫌悪）

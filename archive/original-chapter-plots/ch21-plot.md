1. 戦場の「日常」を描く

- ch21：日常の中での葛藤

## シーン構成

### シーン1：野営地の朝（〜2,500字）

**内容**:
- 朝の日課
- 訓練、食事、雑務
- 「普通」の日々
- でも、何も普通じゃない

**朝**:
```
朝が来た。

テントを出る。
冷たい空気が、肺を刺す。
冬の朝。

「おはよう、エルヴィン」

レオンの声。

「……おはよう」

普通の挨拶。
普通の朝。
でも、何も普通じゃない。
```

**日課**:
```
朝食を食べる。
訓練をする。
雑務をこなす。

同じことの繰り返し。
戦闘がない日は、こうして過ぎていく。

「……」

平和だ。
でも、明日には戦闘があるかもしれない。
明日には、また人を殺すかもしれない。

そう思うと、この「平和」が、嘘みたいに感じる。
```

### シーン2：小隊の仲間たち（〜3,000字）

**内容**:
- 小隊の兵士たちとの会話
- 名前を覚える、覚えない
- 「仲間」という感覚
- でも、深入りしない

**仲間たち**:
```
小隊には、十人ほどの兵士がいる。

レオン。俺の唯一の友人。
ガレス。小隊長。厳格で、怖い。
他にも、何人かいる。

「エルヴィン、お前、最近強くなったな」

誰かが言った。名前は……覚えていない。

「……そうか」
「ああ。最初は死にそうだったのに」
「……」
「何かコツでもあるのか？」
「……別に」

答えられなかった。
コツなんてない。
ルシウスがいるだけだ。
```

**距離**:
```
仲間たち。
一緒に戦う仲間たち。

でも、俺は深入りしないようにしていた。
名前を覚えない。
親しくならない。

なぜか。

死ぬからだ。
いつか、死ぬからだ。
親しくなれば、死んだ時に辛い。

「……」

冷たい考えだと、分かっている。
でも、そうしないと、やっていけない。
```

---

### シーン3：ガレスの視線（〜2,500字）

**内容**:
- ガレスがエルヴィンを観察している
- 「お前、何か隠しているな」
- 疑念の芽生え
- でも、まだ確信はない

**観察**:
```
「クライス」

ガレスの声。
振り向くと、小隊長が俺を見ていた。

「……はい」
「お前、最近よくやっている」
「……ありがとうございます」
「だが、気になることがある」
「……」
「お前の動き。新兵にしては、妙に洗練されている」
「……」
「どこで習った」
「……独学です」
「独学？」
「……はい」
```

**疑念**:
```
ガレスの目が、俺を見ていた。
疑っている目。
でも、確信はない目。

「……そうか」
「……」
「まあいい。結果を出しているなら、文句はない」
「……はい」
「だが、覚えておけ」
「……」
「隠し事は、いつかバレる」

その言葉が、胸に刺さった。
```

---

### シーン4：アリシアへの手紙（〜2,000字）

**内容**:
- 故郷から手紙が届く
- 返事を書こうとする
- 「元気だ」としか書けない
- 嘘しか書けない

**アリシアの手紙**:
```
故郷から、手紙が届いた。
アリシアからだ。

「エルヴィンへ
元気にしてる？
こっちは寒くなってきたよ。
お店の手伝いをしながら、毎日あなたのことを考えてる。
早く帰ってきてね。
待ってるから。
アリシアより」

読んでいると、胸が痛くなった。
```

**返事**:
```
返事を書こうとした。

「アリシアへ
元気だ」

……それ以上、書けなかった。

「戦闘があった」
書けない。

「人を殺した」
書けない。

「俺は、もう君の知っている俺じゃない」
書けない。

結局、「元気だ。心配するな」とだけ書いて、手紙を閉じた。
嘘だ。
全部、嘘だ。
```

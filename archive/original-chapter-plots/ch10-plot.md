## 章の目的

### 物語上の役割
1. 等価交換による私生活憑依の初体験
2. ルシウスの「人間への興味」（感覚を体験したい）
3. 契約の現実を突きつける
4. エルヴィンの成長継続（中位に上昇）
5. ルシウスが「やらかす」（周囲に怪しまれる行動）

### 読者への効果
- 契約の代償を実感
- ルシウスの「人間ではない」感覚
- 緊張と不安

### ch09との差別化
- ch09：成長の実感、爽快感
- ch10：代償の現実、契約の重み、ルシウスのトラブル

### ルシウスの描写
- 私生活憑依で「やらかす」（エルヴィンらしくない行動）
- 謝らない、悪びれない
- 「何が悪いの？」という態度
- エルヴィンの怒りにも無関心

## シーン構成

### シーン1：訓練・中位へ（〜2,500字）

**内容**:
- 対人訓練で3勝2敗
- 新兵の中で中位に上昇
- 「クライス、やるようになったな」
- 成り上がりの実感

**描写**:
```
三人目を倒した時、周りがざわついた。
「クライス、強くなったな」
「一週間前まで底辺だったのに」
「何があった？」
俺は、答えなかった。
答えられなかった。
```

**ルシウスの辛辣な反応**:
```
「まだまだだね。まあ、底辺よりはマシ」
「……」
「でも、この程度じゃ戦場であっさり死ぬよ」
「分かってる」
「本当に？　顔、緩んでるけど」
```

### シーン2：等価交換の請求（〜3,000字）

**内容**:
- 夜の訓練で使った時間の「請求」
- 「僕が体を使った分、君も僕に貸して」
- エルヴィンの戸惑い
- 契約の現実

**ルシウスの要求**:
```
「夜の訓練、合計で2時間くらい？」
「だから、2時間分、僕に体を貸して」
「……何をするつもりだ」
「食べたい」
「食べる？」
「うん。味を感じたい。300年、何も感じられなかったから」
```

**エルヴィンの葛藤**:
- 契約だから、拒否できない
- でも、自分の体を明け渡す恐怖
- 「……分かった。でも、変なことはするな」
- 「変なことって何？」

---

### シーン3：初めての私生活憑依・ルシウスがやらかす（〜4,000字）

**内容**:
- 夕食時、ルシウスに体を貸す
- ルシウスが食事を体験
- 周囲にはバレないが、明確な問題行動を起こす
- エルヴィンの怒りとルシウスの無関心

**ルシウスの体験**:
```
「……温かい」
スープを口に含んだ瞬間、ルシウスが呟いた。
「これが、温かいってこと……」
「塩辛い。でも、美味しい……？」
「パン、硬いね。でも、噛むと味がする」
「……300年、何も感じられなかったから」
```

**ルシウスがやらかす（周囲にバレない形で）**:
- 隣の兵士が席を立った隙に、その皿からパンをこっそり取る
- 別の兵士の水筒から水を飲む（持ち主は気づかない）
- 配給の列に並び直して、二人分の食事をもらう
- 全て「バレなければいい」という態度

```
（エルヴィン、内側から）「おい、何してる」
（ルシウス）「パン、もう一個食べたかったから」
「それ、あいつのだろ」
「でも、いなかったし。気づかないよ」
「そういう問題じゃない！」
「なんで？　バレてないじゃん」
```

**さらにエスカレート**:
```
「ねえ、あっちの人、肉残してる。もったいないね」
（エルヴィン）「やめろ」
「大丈夫、見てないから」
ルシウスが体を動かして、席を立った兵士の皿から肉を取る。
「……美味しい。肉って、こういう味なんだ」
（エルヴィン）「お前……」
「何？　捨てられるより、食べた方がいいでしょ」
```

**憑依解除後・エルヴィンの怒り**:
```
「何やってるんだ、お前」
「何って、食事」
「人のものを盗んだだろ」
「盗んだ？　バレてないよ？」
「バレてなくても、盗みは盗みだ」
「ふーん。人間って、変なルールあるんだね」
「変なルールじゃない！」
「でも、誰も困ってないじゃん。気づいてないんだから」
「……」
「何で怒ってるの？　僕、悪いことした？」
```

**エルヴィンの内心**:
- ルシウスには「悪い」という概念がない
- バレなければいい、という価値観
- 人間の道徳が通じない存在
- これが、契約した相手の本性

---

### シーン4：契約の重み（〜2,500字）

**内容**:
- 体を取り戻したエルヴィン
- ルシウスは悪びれない
- 契約の現実を受け入れるしかない

**ルシウスの態度（悪びれない）**:
```
「次からは気をつけるよ」
「……本当か」
「たぶん」
「たぶん……？」
「だって、300年ぶりなんだもん。加減が分かんない」
「……」
「まあ、慣れるでしょ。君も、僕も」
```

**「約束」vs「契約」の対話**:
```
「……分かった」
「でも、約束してくれ。人のものを盗まない。人に迷惑をかけない」
「約束？」
「ああ。契約じゃなくていい。約束だ」
「……面白いね、君」
「何が」
「約束って、破れるじゃん。契約と違って」
「……」
「でも、君は約束を求める。なんで？」
「信じたいからだ」
「……」
「お前を、信じたいから」
```

**ルシウスの反応**:
```
ルシウスは、黙った。
紫色の目が、僕を見ていた。何を考えているのか、分からない。
「……分かった」
「約束する。人のものは盗まない。たぶん」
「たぶん？」
「だって、何が盗みで何が盗みじゃないか、よく分かんないし」
「でも、君が嫌がることは、なるべくしないようにする」
```

**エルヴィンの内省**:
```
これが、契約の代償。
俺が強くなる代わりに、俺の体を貸す。
等価交換。
……本当に、等価なのか？
分からない。
でも、もう後戻りはできない。
ルシウスは、謝らなかった。
当然だ。悪いと思っていないのだから。
```

- 人間の道徳観念が理解できない

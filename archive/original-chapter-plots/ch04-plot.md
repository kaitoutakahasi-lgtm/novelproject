## シーン構成

### シーン1：出発の朝（約3,000字）

#### 概要
家族との別れ。母の抱擁。振り返らない決意。

#### 場所
クライス家、ミューレンの広場

#### 登場人物
- エルヴィン
- ハインリヒ（父）
- マルタ（母）
- ヴェルナー（兄）
- アリシア（見送り）

#### 詳細プロット

**朝の準備（〜800字）**:
```
眠れないまま、朝が来た。

窓の外は、灰色の空だった。雨は、夜のうちに止んでいた。石畳が濡れている。
空気が、冷たい。

荷物は、昨夜のうちにまとめてあった。着替え。父からもらった銀貨。母が作って
くれた干し肉。それだけ。それだけが、僕の全てだった。

鏡を見た。灰色の瞳が、僕を見返していた。

昨日と同じ顔。でも、何かが違う気がした。何が違うのか、分からなかった。
分かりたくなかったのかもしれない。
```

**家族との別れ（〜1,200字）**:
```
玄関で、家族が待っていた。

父。母。兄。三人が、並んで立っている。

父が、僕の肩を叩いた。一度だけ。強く。

「行ってこい」
「はい」

それだけだった。父は、それ以上何も言わなかった。言えなかったのかもしれない。

兄が、僕を見た。

「気をつけろ」
「うん」
「手紙、書けよ」
「うん」

兄の声は、いつもより低かった。いつもより、硬かった。

母が、僕を抱きしめた。

強く。強く。骨が軋むほど、強く。

「エルヴィン……」
「母さん、大丈夫だよ」
「ごめんね……ごめんね……」
「母さんのせいじゃない」

母の体が、震えていた。僕は、母の背中に手を回した。

泣きたかった。でも、泣けなかった。泣いたら、もう歩けなくなる気がした。

「行ってきます」

僕は、そう言った。母の腕から、離れた。

振り返らなかった。振り返ったら、もう歩けなくなる。だから、前だけを見て、
歩き始めた。
```

**アリシアの見送り（〜1,000字）**:
```
広場に、徴兵された少年たちが集まっていた。

五十人ほど。みな、僕と同じくらいの年齢。みな、同じような顔をしていた。
怯えた顔。諦めた顔。何も分からない顔。

その中に、アリシアがいた。

「エルヴィン」

彼女が、駆け寄ってきた。金色の髪が、風に揺れている。青い瞳が、赤く腫れて
いた。泣いていたのだろう。

「これ」

彼女が、小さな布を差し出した。

「お守り。私が縫ったの」
「……ありがとう」

僕は、それを受け取った。小さな布。彼女の手で縫われた、小さなお守り。

「約束、忘れないでね」
「忘れない」
「必ず、帰ってきて」
「必ず、帰る」

彼女が、微笑んだ。涙を流しながら、微笑んだ。

「行ってらっしゃい」
「……行ってきます」

僕は、彼女に背を向けた。

振り返らなかった。振り返ったら、もう歩けなくなる。

だから、前だけを見て、歩き始めた。
```

#### 伏線配置
- アリシアのお守り（後の支えになる）
- 「振り返らない」決意（成長の象徴）
- 灰色の空（モチーフ）

#### 道徳心変化
98→97（-1：家族を置いていく罪悪感）

### シーン2：行軍（約3,000字）

#### 概要
他の徴兵された少年たち。レオンとの再会。不安と連帯。

#### 場所
行軍路

#### 登場人物
- エルヴィン
- レオン
- 他の徴兵された少年たち
- 引率の兵士

#### 詳細プロット

**行軍の始まり（〜1,000字）**:
```
列になって、歩いた。

五十人ほどの少年たち。みな、僕と同じくらいの年齢。みな、同じような荷物を
背負っている。みな、同じ方向を向いて歩いている。

誰も、話さなかった。

足音だけが、響いていた。石畳を踏む音。土を踏む音。草を踏む音。それだけが、
聞こえていた。

引率の兵士が、先頭を歩いていた。三十代くらいの男。厳しい顔。傷だらけの腕。
戦場を知っている人間の顔だった。

「遅れるな。遅れた奴は、置いていく」

その声が、列に響いた。

僕は、歩き続けた。足が重い。荷物が重い。心が、もっと重い。

でも、歩くしかなかった。
```

**レオンとの再会（〜1,200字）**:
```
「エルヴィン」

声がした。

振り返ると、レオンがいた。日焼けした顔。逞しい体。いつもの、明るい目。

「レオン」
「お前も徴兵されたのか」
「……うん。レオンも？」
「ああ。農家の次男だからな」

レオンが、僕の隣に並んだ。

「まさか、お前と一緒になるとはな」
「……うん」
「なんだよ、その顔。もっと元気出せよ」
「元気なんて、出ないよ」
「まあ、そうだけどさ」

レオンは、笑った。いつもの、太陽のような笑顔。

しかし、その笑顔には、どこか無理があった。目が、笑っていなかった。

「でも、一人よりマシだろ？」
「……そうだね」
「俺がいるから、大丈夫だって」
「レオン……」
「一緒に生き延びようぜ」

その言葉が、少しだけ心を軽くした。

一人じゃない。レオンがいる。

それだけで、少しだけ歩きやすくなった。
```

**レオンの事情（〜800字）**:
```
しばらく歩いて、レオンが小さな声で言った。

「なあ、エルヴィン」
「なに」
「俺、実は志願したんだ」
「……え？」

レオンが、苦笑した。

「徴兵じゃない。自分から、志願した」
「なぜ」
「金だよ。志願兵には、前金が出る」

レオンは、空を見上げた。灰色の空。

「妹が三人いるんだ。親父は去年死んだ。俺が稼がないと、みんな飢える」
「……」
「だから、志願した。死ぬかもしれないけど、家族が生きられるなら」

その言葉が、胸に刺さった。

僕は、自分のことしか考えていなかった。死にたくない、帰りたい、怖い。

レオンは、家族のために命を賭けている。

僕とは、違う。

「……すごいな、レオン」
「すごくねえよ。他に方法がなかっただけだ」

レオンは、また笑った。今度は、少しだけ本当の笑顔に見えた。

「だから、俺は死ねない。死んだら、妹たちが困る」
「……うん」
「お前も、死ぬなよ。待ってる人がいるんだろ」
「……うん」

アリシアの顔が、浮かんだ。母の顔が、浮かんだ。

待っている人がいる。帰る場所がある。

だから、生き延びなければならない。
```

**他の少年たち（〜800字）**:
```
歩きながら、周りを見た。

泣いている子がいた。声を殺して、肩を震わせて。

無表情な子がいた。何も感じていないように、ただ歩いている。

怯えている子がいた。周りをきょろきょろ見ながら、足を引きずっている。

みんな、僕と同じだ。

家族と引き離されて、戦場に向かう。何が起こるか分からない。生きて帰れるか
分からない。

「なあ、エルヴィン」
「なに」
「俺たち、どうなるんだろうな」
「……分からない」
「戦場って、どんなところなんだろう」
「……分からない」

分からないことだらけだった。

でも、考えても仕方ない。今は、歩くしかない。

一歩、また一歩。戦場へ向かって、歩き続けた。
```

#### 伏線配置
- レオンの明るさ（後の死への伏線）
- 「一緒に生き延びよう」という約束
- 他の少年たちの描写（戦争の犠牲者）

### シーン3：最初の夜（約3,000字）

#### 概要
野営。故郷を思う。星を見上げる。

#### 場所
街道沿いの野営地

#### 登場人物
- エルヴィン
- レオン
- 他の少年たち

#### 詳細プロット

**野営の準備（〜800字）**:
```
日が暮れて、野営することになった。

街道沿いの、小さな空き地。草が生えている。石がごろごろしている。

毛布を一枚、渡された。

「これだけ？」
「贅沢言うな。戦場じゃ、これすらないぞ」

引率の兵士が、そう言った。

僕は、地面に毛布を敷いて、横になった。石が、背中に当たる。草が、頬に触れる。
冷たい。硬い。

家の布団が、恋しかった。母の作った夕食が、恋しかった。

でも、文句は言えなかった。言っても、何も変わらない。
```

**レオンとの会話（〜1,200字）**:
```
「眠れないか？」

レオンが、隣で声をかけてきた。

「……うん」
「俺もだ」

二人で、空を見上げた。

星が、たくさん見えた。灰色の雲が晴れて、黒い空に白い点が散らばっている。

「きれいだな」
「……うん」
「故郷でも、こんなに星が見えたっけ」
「見えたよ。でも、あまり見なかった」
「そうだな。見る余裕がなかった」

レオンが、小さく笑った。

「戦場に行く途中で、星を見るなんてな」
「……変な感じだね」
「ああ。でも、悪くない」

星を見ていると、少しだけ落ち着いた。

故郷でも、同じ星が見えているはずだ。母も、アリシアも、同じ星を見ている
かもしれない。

そう思うと、少しだけ心が温かくなった。
```

**故郷への思い（〜1,000字）**:
```
「なあ、エルヴィン」
「なに」
「帰ったら、何したい？」
「……普通に暮らしたい」
「普通？」
「うん。普通に、家の手伝いをして、アリシアと話して、レオンと遊んで」
「つまんねえな」
「いいんだよ、それで」

レオンが、黙った。

しばらくして、言った。

「俺も、そうかもな」
「え？」
「普通が、一番いいのかもな」

その言葉が、胸に響いた。

普通の日常。当たり前だと思っていたもの。それが、どれだけ大切だったか。

「帰ろうな、レオン」
「ああ。絶対に帰ろう」

星の下で、約束した。

二人で、生きて帰る。普通の日常に、戻る。

それだけを、信じることにした。
```

#### 伏線配置
- 星のモチーフ（孤独と希望）
- 「普通」への憧れ（後の喪失感への伏線）
- レオンとの約束（後の悲劇への伏線）

#### 道徳心変化
97→96（-1：故郷への未練、自分の弱さへの嫌悪）

### シーン4：前線への道（約3,000字）

#### 概要
戦場が近づく。煙の匂い。恐怖の増大。

#### 場所
前線に近い街道

#### 登場人物
- エルヴィン
- レオン
- 引率の兵士
- 他の少年たち

#### 詳細プロット

**戦場の気配（〜1,000字）**:
```
三日目。

空気が、変わった。

風の匂いが、違う。土の匂いに混じって、何か別のものが漂っている。煙の匂い。
焦げた匂い。そして、もう一つ。名前をつけたくない匂い。

遠くに、黒い煙が見えた。

「あれは……」
「戦場だ」

引率の兵士が、言った。

「あと半日で、野営地に着く。覚悟しておけ」

覚悟。

そんなもの、できるわけがない。

足が、重くなった。一歩一歩が、戦場に近づいている。死に、近づいている。

それでも、歩くしかなかった。
```

**恐怖（〜1,000字）**:
```
「エルヴィン、顔色悪いぞ」
「……大丈夫」
「大丈夫じゃないだろ」
「……うん」

レオンが、僕の背中を叩いた。

「怖いのは、みんな同じだ」
「レオンは、怖くないの？」
「怖いに決まってるだろ」

レオンの声が、少し震えていた。

「でも、怖がってても仕方ない」
「……そうだね」
「生き延びることだけ、考えよう」
「うん」

レオンの言葉に、少しだけ勇気をもらった。

でも、恐怖は消えなかった。煙の匂いが、鼻につく。黒い煙が、近づいてくる。

戦場が、待っている。
```

**野営地が見える（〜1,000字）**:
```
丘を越えると、野営地が見えた。

たくさんのテント。たくさんの兵士。たくさんの武器。

想像以上だった。

テントが、地平線まで続いている。兵士が、蟻のように動いている。馬が、嘶いて
いる。剣が、陽光を反射している。

「でかいな……」
「ああ……」

レオンも、言葉を失っていた。

これが、戦争なんだ。

「新兵ども、ついてこい」

引率の兵士の声に従って、野営地に入った。

周りの兵士たちが、僕たちを見ていた。冷たい目。哀れむ目。無関心な目。

「ようこそ、地獄へ」

誰かが、そう言った。笑っていた。でも、目は笑っていなかった。

僕は、震えていた。

これから、何が始まるんだろう。生き延びられるんだろうか。

分からない。何も、分からない。

ただ、恐怖だけが、全身を支配していた。
```

#### 伏線配置
- 煙のモチーフ（戦争の象徴）
- 「地獄」という言葉（野営地の過酷さ）
- 兵士たちの冷たい目（新兵の扱い）

   - 感傷的になりすぎない
   - 行動で感情を表現
   - 「振り返らない」決意

2. **レオンの描写**
   - 明るさの中の不安
   - エルヴィンとの対比
   - 後の死への伏線を自然に

3. **恐怖の描写**
   - 14歳の視点
   - 具体的な描写（煙、匂い、音）
   - 徐々に増大する緊張感

4. **文体の維持**
   - 説明を物語に溶け込ませる
   - 会話は最小限に
   - 内省と情景を融合させる

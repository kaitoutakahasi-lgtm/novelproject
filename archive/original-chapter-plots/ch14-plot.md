## シーン構成

### シーン1：初陣の夜（〜3,000字）

**内容**:
- 野営地に戻る
- 眠れない
- 殺した敵兵の顔が浮かぶ
- 「僕は、人を殺した…のか？」

**描写ポイント**:
```
テントの中、横になっている。
目を閉じても、眠れない。
瞼の裏に、敵兵の顔が浮かぶ。
剣が肉を裂く感触。血が飛ぶ瞬間。
「僕は、人を殺した」
でも、自分がやった気がしない。
ルシウスがやった。僕の体で。
「それは、僕がやったことになるのか」
```

**ルシウスとの会話**:
```
「眠れないの？」
「……ああ」
「なんで？」
「……殺したから」
「殺した？　僕がね」
「僕の体で」
「そうだね。で？」
「……分からない」
「何が」
「僕が殺したのか、お前が殺したのか」
「どっちでもいいじゃん。生きてるんだから」
```

---

### シーン2：二度目の戦闘（章間描写）（〜2,500字）

**内容**:
- 「二度目の戦闘を終えた」
- 今回も憑依で乗り切った
- 慣れてきた自分が怖い
- 殺害数：累計6人（ルシウス談）

**描写ポイント**:
```
二度目の戦闘を終えた。
また、ルシウスに頼んだ。
また、内側から見ていた。
また、生き延びた。
「今日は三人かな。合計六人」
ルシウスが、数を数えている。
僕は、数えられない。
見ていたはずなのに、覚えていない。
```

---

### シーン3：レオンとの会話（〜3,500字）

**内容**:
- 「お前、すごかったな」
- 「どうやったんだ、あの動き」
- 答えられない
- 秘密を抱える苦しさ

**レオンの反応**:
```
「エルヴィン、お前すごかったな」
「……そうか」
「あの動き、どうやったんだ？　訓練で見たことない動きだった」
「……」
「なあ、教えてくれよ」
「……練習した」
「練習？　あんな動き、練習でできるようになるのか？」
「……」
```

**エルヴィンの内心**:
```
言えない。
ルシウスのことは、言えない。
「俺の体を幽霊に貸してる」なんて、言えるわけがない。
「……才能、かな」
嘘だ。
また、レオンに嘘をついた。
```

---

### シーン4：ガレスの視線（〜3,000字）

**内容**:
- ガレスがエルヴィンを見ている
- 「あの動き…新兵にしては」
- 疑念の芽生え
- 「何か、隠しているな」

**描写ポイント**:
```
視線を感じた。
振り返ると、ガレスがこちらを見ていた。
鋭い目。観察する目。
「……」
何か、言いたそうだった。
でも、何も言わなかった。
ただ、見ていた。
「あの人、君のこと見てるね」
ルシウスの声。
「……分かってる」
「疑ってるのかな」
「……かもしれない」
「まあ、バレなきゃいいんじゃない」
```

**ガレスの内心（エルヴィン視点で推測）**:
- 新兵にしては動きが良すぎる
- 訓練で見せた動きと違う
- 何かがおかしい

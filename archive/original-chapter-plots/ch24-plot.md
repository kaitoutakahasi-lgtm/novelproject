## シーン構成

### シーン1：通達（〜3,000字）

**内容**:
- 「明日、大会戦だ」
- 数千人規模の戦闘
- 「今までで一番大きい」
- 恐怖が戻ってくる

**通達**:
```
「明日、出撃する」

ガレスの声が、野営地に響いた。

「大規模な戦闘だ。数千人規模」
「……」
「今までで一番大きい。覚悟しておけ」

大会戦。
ついに、来た。
```

**恐怖**:
```
恐怖が、戻ってきた。

二十一度の戦闘を経験した。
何人も殺した。
何人も死ぬのを見た。

でも、怖い。
まだ、怖い。

「……」

明日、死ぬかもしれない。
その恐怖が、全身を支配した。
```

---

### シーン2：レオンとの約束（〜4,000字）★重要

**内容**:
- 「一緒に生き延びような」
- 「ああ、約束だ」
- 「俺たち、一緒に帰るんだ」
- 握手

**会話**:
```
「エルヴィン」

夜、レオンが来た。

「……レオン」
「明日、大会戦だな」
「……ああ」
「怖いか？」
「……ああ」
「俺もだ」

レオンが、笑った。
でも、目は笑っていなかった。
```

**約束**:
```
「一緒に生き延びような」

レオンが言った。

「……ああ」
「約束だ」
「……約束だ」
「俺たち、一緒に帰るんだ」
「……ああ」
「妹たちに、お前を紹介したい」
「……」
「お前の彼女にも、会いたい」
「……ああ」

握手した。
レオンの手は、震えていた。
俺の手も、震えていた。
```

**別れ際**:
```
「じゃあ、また明日」
「……ああ」
「死ぬなよ」
「……お前もな」

レオンが、テントに戻っていった。
その背中を、見送った。

「……」

また明日。
その言葉が、重かった。
明日が来るかどうか、分からないのに。
```

---

### シーン3：アリシアの手紙（〜3,000字）

**内容**:
- 故郷からの手紙を読み返す
- 「待ってる」
- 「必ず帰る」
- お守りを握りしめる

**手紙**:
```
テントの中、アリシアの手紙を読み返した。

「エルヴィンへ
元気にしてる？
こっちは、桜が咲き始めたよ。
綺麗だよ。一緒に見たかったな。
早く帰ってきてね。
待ってるから。
アリシアより」

何度も読んだ手紙。
もう、暗記している。
でも、また読んだ。
```

**お守り**:
```
お守りを、握りしめた。
アリシアがくれた、お守り。

「必ず帰る」

そう約束した。
約束を、守らなければ。

「……」

明日、死ぬかもしれない。
でも、死ねない。
アリシアが、待っている。
レオンと、約束した。

死ねない。
絶対に、死ねない。
```

---

### シーン4：眠れない夜（〜2,000字）

**内容**:
- 眠れない
- 周りの兵士たちも眠れていない
- ルシウスとの短い会話
- 夜明けを待つ

**眠れない**:
```
眠れなかった。

目を閉じても、眠れない。
明日のことを考えると、眠れない。

周りの兵士たちも、同じだった。
誰かが、寝返りを打っている。
誰かが、小さく祈っている。
誰かが、泣いている。

みんな、怖いんだ。
俺だけじゃない。
```

**ルシウスとの会話**:
```
「眠れないの？」

ルシウスの声が聞こえた。

「……ああ」
「怖い？」
「……ああ」
「大丈夫だよ」
「……」
「僕がいるから」
「……」
「君、死なせないから」

その言葉に、何も言えなかった。
ルシウスがいれば、俺は死なない。
でも、レオンは？
他の仲間は？

「……」

夜明けを、待った。
```

## 章の目的

### 物語上の役割
1. 1年半の時間経過と戦況悪化の描写
2. 日常が徐々に侵食されていく過程
3. 徴兵が「遠い話」から「現実の脅威」へ変化
4. アリシアとの関係深化
5. 「いつか終わる日常」への予感

### 読者への効果
- 戦争が徐々に近づく緊張感
- 「茹でガエル」的な日常の崩壊
- 徴兵への説得力ある導線

## シーン構成

### シーン1：戦争の始まり（522年春〜夏）

#### 概要
戦争開始の噂。まだ遠い話。日常は続く。

#### 詳細プロット

**戦争の噂（〜1,200字）**:
```
王暦522年、春。

市場で、戦争の噂を聞いた。

「帝国が動いたらしい」
「国境で小競り合いがあったそうだ」

商人たちが、顔を寄せ合って話している。僕は荷車を押しながら、その会話を
聞いていた。

戦争。

その言葉は、僕には遠いものだった。東の国境なんて、ここから何日もかかる
場所だ。僕には関係ない。

「エルヴィン、ぼんやりしてないで」

父の声で、我に返った。

「はい」

僕は荷車を押し続けた。戦争のことは、すぐに忘れた。

その頃は、まだそうだった。
```

**夏の日常（〜1,000字）**:
```
夏になっても、日常は変わらなかった。

店の手伝い。市場への配達。アリシアとの川辺。レオンとの会話。

「戦争、どうなったんだろうな」

レオンが、川に石を投げながら言った。

「さあ。遠い話だよ」
「だよな」

僕たちは、それ以上話さなかった。

物資の値段が少し上がった。北街道の商人が減った。それくらいの変化はあった。
でも、僕の日常は変わらなかった。

変わらないと、思っていた。
```

### シーン2：戦況の悪化（522年秋〜523年春）

#### 概要
徐々に戦況が悪化。徴兵の噂。町の空気が変わる。

#### 詳細プロット

**秋の変化（〜1,200字）**:
```
秋になって、空気が変わった。

市場で泣いている女を見た。

「息子が……息子が連れていかれた……」

徴兵。その言葉が、初めて現実味を帯びた。

「東部の町で、徴兵が始まったらしい」

父が、夕食の席で言った。

「十六歳以上の次男以下だそうだ」
「まさか、この町にも……」

母の声が、震えていた。

「まだ分からん。だが、戦況は悪い」

父は、それ以上言わなかった。

十六歳以上。僕は十三歳だ。まだ関係ない。

そう思った。
```

**冬の緊張（〜1,000字）**:
```
冬。物資の値段が、さらに上がった。

北街道が封鎖された。帝国軍が、予想より西に進んでいるという噂だった。

「仕入れが厳しくなる」

父が、帳簿を見ながら言った。兄が頷く。僕は、棚の整理をしながら聞いていた。

町に、兵士の姿が増えた。東へ向かう行軍。疲れた顔の若者たち。

「あの人たち、帰ってこれるのかな」

アリシアが、小さな声で言った。

「……分からない」

僕は、答えられなかった。
```

**春の悪化（〜1,200字）**:
```
523年、春。僕は十四歳になった。

徴兵の年齢が、十五歳に引き下げられた。

「来年には、お前も……」

母が、言いかけて、口を閉じた。

「大丈夫だよ、母さん。まだ一年ある」

僕は、そう言った。自分に言い聞かせるように。

でも、戦況は悪化し続けていた。王国軍は三つの砦を失った。帝国軍は、さらに
西へ進んでいる。

「このままじゃ、年齢がさらに下がるかもしれん」

父が、ぽつりと言った。

その言葉が、胸に刺さった。
```

### シーン3：日常の終わり（523年夏〜秋）

#### 概要
徴兵年齢の引き下げ。「自分も対象になる」という現実。

#### 詳細プロット

**夏の衝撃（〜1,200字）**:
```
523年、夏。

徴兵年齢が、十四歳に引き下げられた。

「緊急勅令だ」

父が、紙を持って帰ってきた。顔が、蒼白だった。

「十四歳以上の次男以下の男子は、徴兵の対象となる」

僕は、十四歳だ。次男だ。

対象だ。

「まだ、この町には来ていない」

父が、言った。

「だが、時間の問題だ」

母が、泣いていた。声を殺して、肩を震わせて。

兄が、僕を見ていた。何か言いたそうな顔。でも、何も言わなかった。

僕は、何も感じなかった。現実感がなかった。

まさか、僕が。

そんなはずは、ない。
```

**アリシアとの約束（〜1,500字）**:
```
川辺で、アリシアに会った。

「聞いた」

彼女は、僕の顔を見て言った。目が、赤かった。

「……うん」
「怖い？」
「……分からない」

本当に、分からなかった。怖いのか、悲しいのか、何も感じないのか。

「ねえ、約束して」

アリシアが、僕の手を取った。

「何を」
「何があっても、帰ってくるって」

彼女の手が、震えていた。冷たかった。

「約束する」

僕は、答えた。

「必ず、帰ってくる」

なぜ、そう言えたのか。分からなかった。でも、彼女の目を見ていたら、そう
言わずにはいられなかった。

「私、待ってる」

アリシアが、微笑んだ。涙を流しながら。

「ずっと、待ってる」
```

### シーン4：足音（523年秋）

#### 概要
徴兵が近づく。逃れられない運命。

#### 詳細プロット

**秋の予感（〜1,000字）**:
```
秋になった。

町の若者が、一人、また一人と消えていった。

「隣の家の息子が、昨日連れていかれた」

母が、震える声で言った。

「十四歳だった」

僕と、同い年だ。

「エルヴィン……」

母が、僕を抱きしめた。強く、強く。

「大丈夫よ……大丈夫……」

大丈夫じゃない。分かっていた。母も、分かっていた。

でも、そう言うしかなかった。
```

**夜の思索（〜1,200字）**:
```
眠れない夜が、続いた。

窓の外を見る。灰色の空。灰色の雲。

一年半前、戦争は遠い話だった。僕には関係ないと思っていた。

でも、戦争は近づいてきた。徐々に、確実に。

徴兵年齢は下がり続けた。十六歳から十五歳へ。十五歳から十四歳へ。

次は、十三歳かもしれない。十二歳かもしれない。

どこまで下がるのか。誰にも分からない。

「僕は、戦場に行くのか」

声に出して、言ってみた。

現実感が、なかった。でも、現実だった。

灰色の空を見上げる。

足音が、聞こえる気がした。

近づいてくる、足音が。
```

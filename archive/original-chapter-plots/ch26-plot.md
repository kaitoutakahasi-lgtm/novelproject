## シーン構成

### シーン1：発見（〜4,000字）

**内容**:
- レオンを探し続ける
- 重傷を負ったレオンを発見
- 「エルヴィン……」
- 駆け寄る

**探索**:
```
レオンを探した。

死体の間を、歩いた。
血を踏んで、歩いた。
何度も、味方の死体を確認した。
レオンじゃない。レオンじゃない。

「レオン……！」

叫び続けた。
声が枯れても、叫び続けた。
```

**発見**:
```
見つけた。

戦場の端、木の根元に、レオンがいた。
座り込んでいた。
動かなかった。

「レオン……！」

駆け寄った。

近づいて、分かった。
腹に、大きな傷があった。
血が、流れ出ていた。
たくさんの血が。
```

### シーン2：最後の会話（〜5,500字）★最重要

**内容**:
- 「エルヴィン……来てくれたのか」
- 「お前と友達になれて、よかったよ」
- 「妹たちを……頼む」
- レオンの死

**会話**:
```
「レオン……！」

膝をついた。
レオンの顔を見た。
青ざめていた。
でも、笑っていた。

「エルヴィン……来てくれたのか」
「レオン……傷が……」
「ああ……やられた」
「待ってろ、今、誰か呼んで……」
「いい」
「……」
「もう、無理だ」
```

**レオンの言葉**:
```
「なあ、エルヴィン」
「……」
「お前と友達になれて、よかったよ」
「……レオン」
「最初は、変な奴だと思った」
「……」
「でも、いい奴だった」
「……」
「俺の、一番の友達だ」

涙が、流れた。
止められなかった。
```

**最後の頼み**:
```
「なあ、頼みがある」
「……なんだ」
「妹たちを……頼む」
「……」
「俺が死んだら、あいつら……」
「……」
「手紙、書いてくれないか」
「……」
「俺の代わりに……」
「……分かった」
「……ありがとう」

レオンが、笑った。
血まみれの顔で、笑った。
```

**死の瞬間**:
```
「じゃあな、エルヴィン」
「……レオン」
「また……」

レオンの目から、光が消えていった。

「レオン……？」

返事はなかった。

「レオン……！」

返事はなかった。

「レオン……！！」

レオンは、死んだ。
俺の目の前で、死んだ。
```

### シーン3：崩壊（〜3,500字）

**内容**:
- 「レオン…レオン…！」
- 泣く、叫ぶ
- 「なぜ俺じゃなかった」
- 「俺が生き延びたから、レオンが死んだのか」

**慟哭**:
```
「レオン……レオン……！」

叫んだ。
泣いた。
レオンの体を、抱きしめた。

冷たくなっていく。
さっきまで、温かかったのに。
さっきまで、笑っていたのに。

「なんで……なんで……！」

答えはなかった。
レオンは、もう答えない。
永遠に、答えない。
```

**自責**:
```
「なぜ俺じゃなかった」

そう思った。

俺は、生き延びた。
ルシウスがいたから。
借りた力で、生き延びた。

レオンには、そんな力がなかった。
だから、死んだ。

「俺が……俺のせいか……」

俺が生き延びたから、レオンが死んだのか。
俺がルシウスを独り占めしていたから。
俺だけが、助かったから。

「……」

分からなかった。
でも、そう思えてならなかった。
```

### シーン4：ルシウスの言葉（〜2,000字）

**内容**:
- ルシウスが何か言う
- でも、聞こえない
- 「……」
- 夜が来る

**ルシウスの声**:
```
「……死んだね」

ルシウスの声が聞こえた。

「……」
「君の友達」
「……」
「残念だったね」

残念。
その言葉が、虚しく響いた。
残念なんかじゃない。
レオンは、死んだんだ。
```

**沈黙**:
```
「……」

何も言えなかった。
何も考えられなかった。

レオンの体を、抱きしめたまま、動けなかった。

夜が来た。
星が出た。
レオンと一緒に見た、星。

「……」

涙が、止まらなかった。
```

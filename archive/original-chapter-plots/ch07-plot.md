## 章の目的

### 物語上の役割
1. 契約後の「異物感」との生活（体の中に何かがいる不快感）
2. ルシウスの「人の心がわからない」描写（無神経な発言、残酷な観察）
3. 訓練中のルシウスの兵士評価（「あの人、三日後に死ぬね」等）
4. レオンへの嘘と罪悪感の始まり
5. ルシウスが引き起こす小さなトラブル（勝手に体を動かす）

### 読者への効果
- ルシウスの不気味さ・異質さの強調
- 「便利だが危険な存在」という認識
- エルヴィンの孤立感

### 6章との差別化
- 6章：契約の締結、システムの説明
- 7章：契約後の「生活」、ルシウスとの同居の現実

## シーン構成

### シーン1：異物との目覚め（〜4,000字）

**内容**:
- 契約翌朝、目覚める
- 体の中に「何か」がいる感覚が消えない
- 冷たい、甘い、気持ち悪い
- 自分の体なのに、自分だけのものではない違和感

**ルシウスの登場**:
- テントの隅に座っている（他の人には見えない）
- 「おはよう。ねえ、君の隣の人、寝相悪いね。三回蹴られてたよ」
- 「あ、あの人、夢の中で泣いてた。面白かったよ」
- 一晩中、兵士たちを観察していた

**エルヴィンの反応**:
- 返事ができない（周りに聞こえる）
- 心の中で話しかける練習
- ルシウス「あ、そうやって話せばいいんだ。便利だね」

**描写ポイント**:
- 体の中の「異物感」を丁寧に
- ルシウスの無神経さ（他人の夢を「面白い」と言う）
- 「僕だけに見える存在」との奇妙な同居

---

### シーン2：訓練場の死神（〜4,000字）

**内容**:
- 朝の訓練
- ルシウスが兵士たちを観察して「評価」する
- 残酷な予言（「あの人、動きが鈍い。最初の戦闘で死ぬね」）
- エルヴィンは聞きたくないが、聞こえてしまう

**ルシウスの観察（残酷な評価）**:
```
「あの人、剣の持ち方が変。手首から斬られるよ」
「あの人、目が泳いでる。逃げようとしてる。逃げたら処刑だよね」
「あの人、咳してる。病気かな。戦場に出る前に死ぬかも」
「ねえ、あの人、君の友達？　あの人も、そのうち死ぬよ」
```

**エルヴィンの反応**:
- 「やめろ」と心の中で叫ぶ
- ルシウス「なんで？　本当のことだよ？」
- 「本当のことでも、言っていいことと悪いことがある」
- ルシウス「ふーん。人間って、変なの」

**ガレスの登場**:
- 「クライス、ぼんやりするな！」
- エルヴィンは集中できない
- ルシウスの声が邪魔で

**描写ポイント**:
- ルシウスの「死」への無関心
- 300年の戦場観察で培った「目」
- エルヴィンの不快感と恐怖

---

### シーン3：レオンへの嘘（〜3,500字）

**内容**:
- 昼休み、レオンと話す
- 「お前、昨日の夜どこ行ってた？」
- 嘘をつく（「眠れなくて散歩してた」）
- ルシウスが横で見ている

**レオンとの会話**:
```
「お前、なんか変だぞ。顔色は良くなったけど、目が……」
「目が？」
「なんか、遠くを見てる感じ。大丈夫か？」
「……大丈夫だ」
```

**ルシウスの介入**:
- 「嘘、下手だね。目が泳いでるよ」
- 「あの人、君のこと心配してるんだ。へえ、友達って、そういうものなの？」
- 「僕には友達いなかったから、分かんないや」

**エルヴィンの内省**:
- レオンに本当のことを言えない
- 言ったところで、信じてもらえない
- 「頭の中に幽霊がいる」なんて
- 嘘をつくことへの罪悪感

**描写ポイント**:
- レオンとの友情と、それを裏切る罪悪感
- ルシウスの「友達」への無理解
- エルヴィンの孤立の始まり

---

### シーン4：訓練中の「助言」（〜4,000字）

**内容**:
- 午後の対人訓練
- ルシウスが横から「助言」を続ける
- 的確だが、タイミングが悪い（集中を乱す）
- エルヴィンは打たれ続ける

**ルシウスの「助言」**:
```
「あ、今の避けられたのに」
「遅い。もっと早く動かないと」
「ほら、また当たった。痛そう」
「君、才能ないね」
```

**エルヴィンの苛立ち**:
- 分かってる。分かってるけど、体が動かない
- ルシウスの声が邪魔で集中できない
- 「黙ってくれ」と心の中で叫ぶ
- ルシウス「え、なんで？　教えてあげてるのに」

**ルシウスの提案**:
```
「ねえ、僕に体貸してよ。僕なら上手くやれるのに」
「……契約は、僕が死にそうな時だけだ」
「そうだけど、君が『貸して』って言えば、いつでも貸せるよ」
「……」
「契約って、そういうものでしょ。君が呼べば、僕は来る」
```

**契約の確認**:
- 憑依の発動は「エルヴィンの意志」で行う
- ルシウスは勝手に体を奪えない
- でも、エルヴィンが「助けて」と言えば、いつでも憑依できる
- その誘惑との戦い

**描写ポイント**:
- 契約の正確なルール（発動はエルヴィンの意志）
- ルシウスの「助言」の無神経さ
- 「楽な道」への誘惑と、それを拒むエルヴィン

### シーン5：夜の対話（〜3,500字）

**内容**:
- 夜、眠れないエルヴィン
- ルシウスとの会話
- 契約の詳細確認
- ルシウスの300年についての伏線

**エルヴィンの質問**:
```
「契約のこと、確認したい」
「なに？」
「僕が呼ばないと、お前は体を使えないんだな」
「そうだよ。君が『助けて』って言わないと、僕は何もできない」
「……」
「でも、君が呼んだら、僕はすぐ来るよ。それが契約だから」
```

**等価交換の確認**:
- 戦闘で借りた時間 ＝ 私生活で借りる時間
- 私生活での使用タイミングはルシウスが決める
- エルヴィンは拒否できない
- まだ一度も憑依していないので、負債は0

**ルシウスの興味**:
```
「ねえ、君、いつ僕を呼ぶの？」
「……できれば、呼びたくない」
「え、なんで？　僕、強いのに」
「自分の力で、なんとかしたい」
「ふーん。変なの」
```

**300年への伏線**:
```
「君みたいなこと言う人、初めてだよ」
「……他にも、契約した人がいたのか」
「何人かね。でも、みんな、すぐ僕を呼んだよ。楽だから」
「……」
「君は、呼ばないんだ。面白いね」
```

**描写ポイント**:
- 契約の正確なルール（発動はエルヴィンの意志、等価交換）
- ルシウスは「理解」しようとしていない、ただ「観察」している
- エルヴィンの「自力でなんとかしたい」という意志
- 過去の契約者への伏線

## キャラクター描写

### ルシウス（この章での描写）
- **無神経**: 他人の死を平然と予言する
- **好奇心**: 人間の反応を観察して楽しむ（「面白い」が口癖）
- **無理解**: 「助けたのに怒られる」が理解できない、理解しようともしない
- **契約の絶対性**: 契約に追加すれば自動的に拘束される（「約束守る」とは言わない）
- **観察者**: エルヴィンの怒りや恐怖も「観察対象」として楽しむ
- **冷淡**: 友達がいなかったことを淡々と述べる（寂しさは見せない）

### エルヴィン（この章での変化）
- **異物感**: 体の中に何かがいる不快感
- **孤立**: レオンにも本当のことを言えない
- **恐怖**: 体の支配権への不安
- **適応**: ルシウスとの「ルール」を作る

## 文体の注意点

1. **ルシウスの台詞**
   - 無邪気だが残酷
   - 「〜だよね」「〜じゃん」という軽い口調
   - 時折、古風な言い回し（「然り」「汝」等）は使わない（まだ親しくない）

2. **異物感の描写**
   - 冷たい、甘い、気持ち悪い
   - 自分の体なのに自分だけのものではない
   - 内臓の奥に何かがいる感覚

3. **文章のリズム**
   - 長文と短文の交互
   - 内省と情景の融合
   - 会話は最小限に

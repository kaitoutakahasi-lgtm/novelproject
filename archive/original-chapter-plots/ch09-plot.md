## 章の目的

### 物語上の役割
1. 夜の訓練の成果が目に見えて出始める
2. 底辺から脱出（下から3番目くらいに）
3. 周囲の「あれ？」という反応
4. ルシウスの辛辣な指摘は続く（褒めない）
5. 成り上がりの爽快感の始まり

### 読者への効果
- 成長の実感、爽快感
- 努力が報われる展開
- 「もっと強くなれる」という期待

### ch08との差別化
- ch08：秘密訓練開始、数日間の積み重ね、まだ底辺
- ch09：1週間後、成果が目に見えて出始める、周囲の反応が変わる

### ルシウスの描写
- 成長しても大きくは褒めない、「まだ弱い」「まだ足りない」
- 欠点を指摘し続ける
- エルヴィンの成長は「予想通り」程度の反応
- 優しさは見せない

## シーン構成

### シーン1：朝の走り込み・追い抜く（〜3,000字）

**内容**:
- いつもの走り込み
- エルヴィン、初めて誰かを追い抜く
- 「え……？」という周囲の反応
- 自分でも驚く

**描写**:
```
足が、軽い。
いつもと同じ距離なのに、息が上がらない。
前を走る背中が、近づいてくる。
「……抜ける」
一人、追い抜いた。
振り返った顔が、驚いている。
俺も、驚いていた。
```

**ルシウスの辛辣な反応**:
```
「一人抜いただけで喜んでるの？」
「……」
「まだ下から3番目だよ。底辺には変わりない」
「分かってる」
「分かってるならいいけど。調子乗ると死ぬよ」
```

---

### シーン2：対人訓練・初めての一本（〜4,000字）

**内容**:
- 木剣での対人訓練
- 相手の動きが「見える」
- 初めて一本取る
- 周囲のざわめき

**戦闘描写**:
```
相手が振りかぶる。
右肩が下がった。右から来る。
体が、勝手に動いた。
左に避けて、踏み込む。
木剣が、相手の胴を打った。
「……一本」
審判の声。
静寂。そして、ざわめき。
「クライスが、一本取った……？」
```

**ルシウスの辛辣な指摘（心の中で）**:
```
「踏み込みが浅い。もっと深く入れた」
「……勝ったのに？」
「勝ったから何？　下手なのは変わらない」
「……」
「相手が弱かっただけ。強い相手には通用しないよ」
```

---

### シーン3：レオンとの会話（〜2,500字）

**内容**:
- 昼休み、レオンが話しかけてくる
- 「お前、すごいな。急に強くなった」
- 友情と秘密の間で揺れる
- 嘘を重ねる罪悪感

**レオンの反応**:
```
「なあ、何かコツでもあるのか？」
「……練習、かな」
「練習って、いつ？　俺、お前が練習してるの見たことないぞ」
「……夜、一人で」
「一人で？　すげえな、お前」
```

**エルヴィンの内心**:
- 一人じゃない。ルシウスがいる
- でも、言えない
- 「……ああ、まあ」
- 嘘が、また一つ増えた

---

### シーン4：夜の訓練・次の段階（〜2,500字）

**内容**:
- 夜の森での訓練
- より高度な動きの習得
- ルシウスの容赦ない指摘は続く

**ルシウスの辛辣な指導**:
```
「……」
「戦場は一対一じゃないよ。二人、三人、同時に来る」
「……分かってる」
「分かってないから言ってるんだけど」
「……」
「はい、次。複数相手の動き。見せるから覚えて」
```

**成長の実感（エルヴィン視点）**:
```
一週間前の自分が、嘘みたいだ。
あの時は、剣を振ることすらできなかった。
今は、違う。
体が動く。相手が見える。
「俺、強くなってる」
その実感が、胸の中で熱くなった。
ルシウスは何も言わなかった。
当然だ。褒める気なんて、最初からない。
```

## 成長の指標
- 走り込み：底辺 → 下から3番目
- 対人訓練：一本も取れない → 初めて一本
- 周囲の評価：「落ちこぼれ」→「あれ、意外と？」

## ルシウスの態度
- 成長しても褒めない
- 「まだ弱い」「まだ足りない」と指摘し続ける
- エルヴィンの喜びに水を差す
- 事実を冷たく述べるだけ

## 罪悪感: 7（変化なし、でも嘘は増えている）

## シーン構成

### シーン1：悪夢（〜3,000字）

**内容**:
- 毎晩、悪夢を見る
- 殺した敵兵の顔
- 「なぜ俺を殺した」
- 目が覚めても、消えない

**悪夢の描写**:
```
また、あの夢だ。

暗闘の中に、顔が浮かんでいる。
あいつの顔。
俺が殺した、あいつの顔。

「なぜ、俺を殺した」
「……」
「俺は、何もしていない」
「……」
「俺にも、家族がいた」
「……」
「待っている人がいた」
「……」
「お前が、殺したんだ」

分かってる。
俺が殺した。
俺の手で。俺の意志で。

「……ごめん」
「謝って、何になる」
「……」
「俺は、死んだ。お前に殺された」
「……」
「お前は、生きている」
「……」
「それが、答えだ」
```

**目覚め**:
```
目が覚めた。
汗びっしょりだった。
心臓が、激しく鳴っている。

「……」

また、あの夢だ。
毎晩、見る。
毎晩、あいつが来る。

眠れなかった。
もう、何日も、まともに眠れていない。
```

---

### シーン2：フラッシュバック（〜3,000字）

**内容**:
- 日中もフラッシュバック
- 血を見ると思い出す
- 剣を握ると手が震える
- 解離感

**トリガー**:
```
食事の時間。
肉のスープが配られた。

スープを見た瞬間、吐き気がした。
赤い。
血の色だ。

「……」

あの日の記憶が、蘇ってきた。
血の匂い。温かさ。
剣が肉に沈む感触。
あいつの目から、光が消えていく――

「エルヴィン？」

レオンの声で、我に返った。

「……なんだ」
「大丈夫か？　顔、真っ青だぞ」
「……大丈夫」

嘘だ。
大丈夫じゃない。
```

**解離**:
```
時々、自分が自分じゃないような感覚がある。

体はここにある。
でも、心がどこかに行っている。
誰かが、俺の体を動かしている。
俺は、それを見ているだけ。

憑依の時と、似ている。
でも、ルシウスはいない。
俺一人なのに、俺じゃない。

「……」

壊れていく。
俺は、壊れていく。
```

### シーン3：レオンの言葉（〜3,500字）

**内容**:
- レオンが心配して声をかける
- 「初めて殺したのか」
- レオンの経験を聞く
- 少しだけ、楽になる

**レオンの心配**:
```
「エルヴィン」

夜、レオンが声をかけてきた。
テントの外、焚き火の近く。

「……なんだ」
「お前、最近おかしいぞ」
「……」
「飯も食ってないし、眠れてないだろ」
「……」
「何かあったのか」

何かあった。
人を殺した。
でも、言えなかった。
```

**レオンの告白**:
```
「……俺も、あったよ」

レオンが、焚き火を見ながら言った。

「初めて殺した時」
「……」
「吐いた。夢にも出た。何日も眠れなかった」
「……」
「お前も、そうなのか」

答えられなかった。
でも、レオンは分かったようだった。

「……そうか」
「……」
「辛いよな」
「……ああ」
```

**レオンの言葉**:
```
「俺は、こう考えることにした」

レオンが言った。

「殺さなきゃ、殺されてた」
「……」
「俺が死んだら、妹たちが困る」
「……」
「だから、仕方なかったんだ」
「……」
「お前も、そう思えばいい」

仕方なかった。
その言葉が、少しだけ、楽にしてくれた。
でも、完全には納得できなかった。
```

### シーン4：ルシウスの無理解（〜2,500字）

**内容**:
- ルシウスに話す
- 「なんで悩んでるの？」
- 「殺さなきゃ死んでたよ？」
- 「人間って、変なの」

**会話**:
```
「ねえ、まだ悩んでるの？」

夜、ルシウスが言った。

「……」
「もう何日も経ったよ？」
「……」
「いつまで悩むの？」
「……分からない」
「へえ」
```

**無理解**:
```
「僕には、分からないな」

ルシウスが、首を傾げた。

「殺さなきゃ、君が死んでたよ？」
「……分かってる」
「じゃあ、何が問題なの？」
「……人を殺した」
「うん。で？」
「……」
「死んだのは相手で、君は生きてる。それでいいじゃん」
「……」
「人間って、変なの」
```

**ルシウスの観察**:
```
「でも、面白いね」

ルシウスが言った。

「君、変わったよ」
「……」
「『僕』じゃなくなった」
「……」
「『俺』になった」
「……」
「殺すと、変わるんだね。人間って」

その言葉が、胸に刺さった。
変わった。
俺は、変わってしまった。
```

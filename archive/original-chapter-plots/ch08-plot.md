## 章の目的

### 物語上の役割
1. 夜の秘密訓練の本格開始
2. 憑依で「正しい動き」を体で覚える
3. エルヴィンの記憶力をルシウスが発見
4. 日中の訓練でも憑依を使う（ボコられたくないから）
5. 数日間の訓練の積み重ね
6. 秘密を持つことへの罪悪感

### 読者への効果
- 秘密の特訓という王道展開
- 成長の予感
- ルシウスとの奇妙な共犯関係

### ch07との差別化

- ch08：夜の訓練開始、数日間の積み重ね

## シーン構成

### シーン1：初めての夜の訓練（〜3,500字）

**内容**:
- ch07の夜の約束を受けて、その夜
- 人目を避けて森の外れへ
- エルヴィンが許可して憑依
- ルシウスが「正しい剣の振り方」を実演
- エルヴィンは内側から見て学ぶ

**憑依中の描写**:
```
体が、勝手に動いた。
剣を振る。一閃。
風を切る音が、今までと全然違う。
「これが……正しい振り方か」
「上手い人はこう振ってた。君のとは全然違うでしょ」
```

**憑依解除後・ルシウスの指摘**:
```
「はい、やってみて」
エルヴィン、再現を試みる。
「違う。腰が高い」
やり直す。
「まだ違う。肩に力入りすぎ」
やり直す。
「3割くらい？　まあ、0よりはマシか」
```

**ルシウスの発見**:
```
「ねえ、君、今の動き、どこまで覚えてる？」
「……大体は。重心の位置、力の入れ方、呼吸のタイミング」
「へえ。体が追いつかないだけで、頭では分かってるんだ」
「珍しいね。前の人は、見せても次の日には忘れてた」
「……そうなのか」
「うん。君、記憶力いいんだね」
```

### シーン2：テントに戻る・秘密と罪悪感（〜2,000字）

**内容**:
- 夜の訓練を終えてテントに戻る
- レオンが起きている「どこ行ってた？」
- 嘘をつく「眠れなくて、散歩」
- 秘密を持つことへの罪悪感

**レオンとの会話**:
```
「お前、最近変だぞ」
「……そうか？」
「なんか、目が違う」
「……」
「何かあったのか？」
「……いや、何も」
```

**エルヴィンの内省**:
- レオンには言えない
- 誰にも言えない
- でも、これで強くなれるなら

### シーン3：翌日の日中訓練（〜3,000字）

**内容**:
- 翌日の日中訓練
- 昨夜の訓練の成果が少し出る
- まだ弱いが、動きが少しマシになった
- ボコられそうになったら憑依を使う

**変化の描写**:
```
相手が振りかぶる。
昨夜、ルシウスに見せてもらった動き。
右肩が下がったら、右から来る。
……見える。
避けられた。
「……！」
相手が驚いている。俺も驚いていた。
```

**でも、まだ弱い**:
- 一発避けただけで、次は当たる
- 結局ボコられそうになる
- 「……助けてくれ」
- ルシウスが体を動かして勝つ

**ルシウスの反応**:
```
「ね、一発避けられたじゃん」
「……ああ」
「でも、まだ全然ダメだね。体が追いついてない」
「分かってる」
「分かってるならいいけど。今夜も練習ね」
```

---

### シーン4：数日間の積み重ね（〜3,500字）

**内容**:
- 2日目、3日目、4日目の夜の訓練をダイジェストで
- 少しずつ体が動くようになる
- ルシウスの指摘は相変わらず辛辣
- 日中の訓練でも、ボコられそうになったら憑依

**2日目の夜**:
```
「昨日より少しマシ。5割くらい」
「……5割」
「半分できてないってことだよ。喜ぶところじゃない」
```

**3日目の夜**:
```
「足の運び、まだ遅い」
「……」
「考えてから動いてる。考える前に動かないと」
「それができたら苦労しない」
「できないから練習してるんでしょ」
```

**4日目の夜・ルシウスの評価**:
```
「ねえ、君、体力ないね」
「……分かってる」
「剣の動きは覚えてきたけど、すぐバテる」
「走り込みも増やさないとダメだね」
「……ああ」
「でも」
「……？」
「君、覚えるの早いね。4日で基本の動きは全部頭に入ってる」
「……」
「いと珍しき才なり、とでも言うべきかな」
「……何だ、その言い方」
「昔の言葉。たまに出るんだよね」
「体が追いつけば、結構いけるかも」
「……それ、褒めてるのか」
「ただの事実だよ。褒めてるわけじゃない」
```

**日中の訓練（ダイジェスト）**:
- 毎日、対人訓練でボコられそうになる
- 毎回、憑依を使って勝つ
- 周囲は「クライス、急に強くなった」と不思議がる
- でも、自分の力じゃない

**エルヴィンの内省**:
```
毎晩、森で訓練する。
毎日、訓練でボコられそうになったら、ルシウスに頼む。
それが、俺の日常になった。
体は少しずつ動くようになってきた。
でも、まだ足りない。
ルシウスは、毎晩そう言う。
「まだ足りない」「まだ弱い」「まだダメ」
褒められたことは、一度もない。
```

- 秘密の訓練という「武器」を得た
- 日中は憑依頼み、夜は自分で練習というサイクルが確立

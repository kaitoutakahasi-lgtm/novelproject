## シーン構成

### シーン1：代償時間（〜4,000字）

**内容**:
- 「そろそろ、僕の時間だね」
- 契約の対価
- 体の支配権を渡す
- 内側から見ている

**代償時間**:
```
「そろそろ、僕の時間だね」

夜、ルシウスが言った。

「……ああ」
「契約、覚えてるよね？」
「……覚えてる」
「じゃあ、体、借りるね」

冷たい感覚。
体の支配権が、ルシウスに移る。
俺は、内側から見ているだけになる。
```

**契約の内容**:
```
契約の対価。
ルシウスが体を自由に使える時間。

戦闘で助けてもらった分、ルシウスに体を貸す。
それが、契約だった。

「……」

最初は、怖かった。
ルシウスが何をするか、分からなかったから。
でも、今は慣れた。
慣れてしまった。
```

---

### シーン2：ルシウスの行動（〜3,500字）

**内容**:
- ルシウスが体を使う
- 野営地を歩き回る
- 人間を観察する
- 「面白いね、人間って」

**観察**:
```
ルシウスが、野営地を歩いた。
俺の体で。俺の足で。

「ふーん」

ルシウスが、兵士たちを見ている。
焚き火の周りで話している兵士たち。
眠っている兵士たち。
泣いている兵士たち。

「面白いね、人間って」
「……」
「みんな、必死に生きてる」
「……」
「でも、死ぬんだよね」
```

**会話**:
```
ルシウスが、誰かに話しかけた。

「やあ」
「……クライス伍長？」
「うん。眠れないの？」
「ええ、まあ……」
「そっか。大変だね」

俺の声で、俺じゃない言葉を話している。
不思議な感覚。
でも、もう慣れた。
```

---

### シーン3：ルシウスの本音（〜2,500字）

**内容**:
- 「君の体、使いやすいね」
- 「300年ぶりに、体があるって楽しい」
- ルシウスの孤独
- 「君がいてくれて、よかった」

**本音**:
```
「君の体、使いやすいね」

ルシウスが言った。
俺の口で。

「……」
「300年ぶりに、体があるって楽しい」
「……」
「触れる。歩ける。話せる」
「……」
「幽体だと、何もできないからね」

300年。
ルシウスは、300年間、幽体だった。
何も触れず、誰とも話せず。

「……」

少しだけ、ルシウスの孤独が分かった気がした。
```

---

### シーン4：対価の意味（〜2,000字）

**内容**:
- 体が戻る
- 「ありがとう、楽しかった」
- 対価の重み
- 第二部の締めくくり

**体が戻る**:
```
「はい、返すね」

体が、戻った。
自分の体が、自分のものに戻る。
温かい感覚。

「……」

「ありがとう、楽しかった」

ルシウスが言った。

「また、借りるね」
「……ああ」
「君といると、退屈しないよ」
「……」
「これからも、よろしくね」
```

**対価の意味**:
```
契約の対価。

俺は、ルシウスに体を貸している。
ルシウスは、俺を助けてくれる。
等価交換。

「……」

でも、本当に等価なのか。
俺は、命を助けてもらっている。
ルシウスは、体を借りているだけ。

「……」

分からなかった。
でも、考えても仕方ない。
これが、俺たちの契約だ。
これが、俺の選んだ道だ。
```

## シーン構成

### シーン1：戦場へ（〜3,500字）

**内容**:
- 朝、出発
- 大規模な軍勢
- 「こんなに多くの人が…」
- 煙、炎、血の匂い

**出発**:
```
夜明けとともに、出発した。

周りを見渡す。
兵士たちが、列を成している。
数千人。
こんなに多くの人間を、一度に見たのは初めてだった。

「……」

みんな、同じ顔をしている。
恐怖と、緊張と、諦めが混じった顔。
俺も、同じ顔をしているんだろう。
```

**戦場へ**:
```
戦場が、近づいてくる。

煙が見える。
炎が見える。
血の匂いが、風に乗って届いてくる。

「……」

地獄だ。
これから、地獄に行くんだ。
```

---

### シーン2：戦闘開始（〜4,500字）

**内容**:
- 想像以上の規模
- 混乱、恐怖、パニック
- 味方も敵も区別がつかない
- レオンと離れ離れになる

**混乱**:
```
戦闘が、始まった。

想像以上だった。
今までの戦闘とは、規模が違う。
人が、波のように押し寄せてくる。
敵も、味方も、区別がつかない。

「……っ」

怒号。悲鳴。金属がぶつかる音。
全てが、混ざり合っている。
何が何だか、分からない。
```

**離散**:
```
「レオン！」

叫んだ。
でも、声が届かない。
周りの音に、かき消される。

「レオン……！」

見えない。
どこにいるか、分からない。
人の波に、押し流されていく。

「……っ」

離れ離れになった。
レオンと、離れ離れになった。
```

---

### シーン3：憑依での戦闘（〜4,000字）

**内容**:
- 「ルシウス！」
- 憑依して戦う
- 大量殺戮
- 内側から見ている

**憑依**:
```
「ルシウス……！」
「はいはい、呼んだ？」
「助けて……！」
「いいよ。体、借りるね」

冷たい感覚。
体の支配権を、渡す。
もう、何度も経験した感覚。
でも、慣れない。
```

**戦闘**:
```
ルシウスが、敵を斬っていく。

一人、二人、三人。
数えられない。
次から次へと、敵が来る。
次から次へと、斬っていく。

俺は、内側から見ていた。
自分の体が、人を殺していく。
血が飛ぶ。悲鳴が上がる。
死体が、積み重なっていく。

「……」

見ているだけ。
俺は、見ているだけ。
```

**ルシウスの声**:
```
「楽しいね」

ルシウスの声が聞こえた。

「久しぶりに、たくさん動けた」
「……」
「君、大丈夫？　気持ち悪くなってない？」
「……」
「まあ、もう少しで終わるから」

終わる。
何が終わるんだ。
この地獄が、終わるのか。
```

---

### シーン4：戦闘の終わり（〜3,000字）

**内容**:
- 戦闘が終わりかけている
- 体が戻る
- レオンを探す
- 見つからない

**終結**:
```
「はい、返すね」

体が、戻った。

周りを見渡す。
死体が、転がっている。
敵も、味方も。
血の海。

「……」

戦闘が、終わりかけていた。
敵が、退却していく。
勝ったのか。
分からない。
勝ち負けなんて、どうでもよかった。
```

**レオンを探す**:
```
「レオン……」

探した。
死体の間を、歩いた。
血を踏んで、歩いた。

「レオン……！」

見つからない。
どこにもいない。

「レオン……！」

叫んだ。
でも、返事はなかった。
```

# 伏線マップ（整理版）

物語全体の伏線配置と回収計画。
**A級（必須）5本、B級（推奨）5本、C級（モチーフ）自由**に整理。

---

## 伏線ランク定義

| ランク | 定義 | 本数 |
|--------|------|------|
| A級 | 物語の核心。回収必須。読者が「あ！」と思う | 5本 |
| B級 | 物語を豊かにする。回収推奨 | 5本 |
| C級 | モチーフ・象徴。全編で展開 | 3本 |

---

## A級伏線（必須・5本）

### A1. 契約の真の代償
| 項目 | 内容 |
|------|------|
| 配置 | 第6章：契約の説明（表面的） |
| 示唆 | 第23章：ルシウス「まだ知らないことがある」 |
| 強化 | 第29章：エルヴィンの異変（境界の曖昧化） |
| 回収 | 第42章：時間だけでなく、感情・記憶も共有されていた |

**核心**: 20年間で53時間の憑依は、二人の境界を曖昧にしていた

### A2. ルシウスの真の目的
| 項目 | 内容 |
|------|------|
| 配置 | 第6章：「人間の生活を体験したい」 |
| 疑問 | 第17章：なぜエルヴィンを選んだのか |
| 示唆 | 第27章：ルシウスの「人間らしさ」 |
| 回収 | 第42章：ルシウスは「孤独」から逃れたかった |

**核心**: 封印された古代の存在も孤独を感じる。エルヴィンは「友」だった

### A3. 初めての殺人の相手
| 項目 | 内容 |
|------|------|
| 配置 | 第8章：名もなき敵兵を殺す |
| 示唆 | 第8章：その兵士の持ち物（家族の写真） |
| 強化 | 第17章：似た顔の人物との遭遇 |
| 回収 | 第30章：殺した兵士の家族との対面 |

**核心**: 最初に殺した兵士には家族がいた。贖罪の具体化

### A4. アリシアの知っていたこと
| 項目 | 内容 |
|------|------|
| 配置 | 第20章：再会時の違和感 |
| 示唆 | 第27章：「本当のあなたを見せて」 |
| 強化 | 第33章：アリシアの調査 |
| 回収 | 第35章：アリシアは一部を知っていた |

**核心**: アリシアはエルヴィンの「異常さ」に気づいていたが、本人から聞きたかった

### A5. 王の秘密
| 項目 | 内容 |
|------|------|
| 配置 | 第18章：王との謁見（不思議な視線） |
| 示唆 | 第26章：王の不自然な判断 |
| 強化 | 第38章：戦争の真の原因 |
| 回収 | 第41章：王も契約者だった |

**核心**: ロデリック王もルシウスと契約していた。エルヴィンの先輩契約者

## B級伏線（推奨・5本）

### B1. ガレスの過去
| 項目 | 内容 |
|------|------|
| 配置 | 第7章：ガレスの厳格さ |
| 示唆 | 第12章：ガレスの傷跡 |
| 回収 | 第17章：ガレスは息子を戦争で失っていた |

**核心**: ガレスの厳格さは息子を失った悲しみから

### B2. マクシミリアンの真意
| 項目 | 内容 |
|------|------|
| 配置 | 第13章：協力の申し出 |
| 示唆 | 第22章：不自然な行動 |
| 回収 | 第40章：マクシミリアンの本当の目的 |

**核心**: マクシミリアンには別の目的があった（王への対抗）

### B3. 憑依中の記憶の曖昧さ
| 項目 | 内容 |
|------|------|
| 配置 | 第7章：初めての憑依後の混乱 |
| 強化 | 第10章：「何をしていたんだろう」 |
| 回収 | 第25-26章：境界の曖昧化の原因 |

**核心**: 憑依は記憶だけでなく、人格にも影響を与えていた

### B4. レオンの死の意味
| 項目 | 内容 |
|------|------|
| 配置 | 第1章：レオンの楽観的な態度 |
| 展開 | 第7-9章：戦友としての絆 |
| 回収 | 第10章：レオンの死（王暦524年）、第31章：墓参りと妹グレタとの会話 |

**核心**: レオンの死は「代償」テーマの具現化。エルヴィンの罪悪感の原点

### B5. 戦争の真の原因
| 項目 | 内容 |
|------|------|
| 配置 | 第2章：戦争の表面的な理由 |
| 示唆 | 第15章：政治的な会話 |
| 回収 | 第38章：ルシウスの存在を巡る秘密が原因 |

**核心**: 戦争は資源ではなく、ルシウスの力を巡る争い（帝国はルシウスの存在を知っている）

## C級伏線（モチーフ・3本）

### C1. 灰色のモチーフ
| 項目 | 内容 |

|------|------|

| 展開 | 第25章：鏡を見る、第27章：仮面の下 |
| 回収 | 第42章：ルシウスとの別れ |

**象徴**: ルシウスはエルヴィンの「鏡」、自己認識の道具

## 伏線チェックリスト

### 配置時
- [ ] 自然に物語に溶け込んでいるか
- [ ] 読者が気づける程度の明確さか
- [ ] 後の回収と矛盾しないか

### 回収時
- [ ] 配置を覚えている読者に満足感を与えるか
- [ ] 忘れていた読者にも理解できるか
- [ ] 回収前に「リマインド」を入れたか

### 最終確認
- [ ] A級5本すべて回収
- [ ] B級5本すべて回収
- [ ] C級モチーフが一貫している

---

## 拡張の方針

### 変更点
- 各部の章数を約3倍に拡張（5-7章 → 15-20章）
- 総章数：44章 → 約130章
- 総文字数：約675,000字 → 約2,000,000字（200万字）
- 各章の文字数：約15,000字を維持

### 拡張で追加する要素
1. **日常描写の充実** - キャラクターの生活感
2. **人間関係の深化** - 脇役との交流
3. **心理描写の丁寧化** - 変化の過程を細かく
4. **戦闘の重厚化** - 直接描写＋章間戦闘で戦争の重みを表現
5. **伏線の丁寧な配置と回収**

### 戦闘描写の方針
- **直接描写する戦闘**: 重要な転換点となる戦闘のみ（20回程度）
- **章間戦闘**: 「三度目の戦闘を終えた頃」「この一ヶ月で五度の戦闘があった」等
- **回想・言及**: 「先週の戦闘で隣の小隊が全滅した」等
- **戦闘回数の目安**:
  - 第二部（1年間）: 直接描写4回 + 章間戦闘25回 = 約30回
  - 第三部（7年間）: 直接描写6回 + 章間戦闘100回 = 約106回（年15回）
  - 第四部（4年間）: 直接描写2回 + 章間戦闘40回 = 約42回
  - 第五部（3年間）: 直接描写1回 + 章間戦闘20回 = 約21回
  - 第六部（4年間）: 直接描写1回 + 章間戦闘15回 = 約16回
  - 第七部（3年間）: 直接描写3回 + 章間戦闘25回 = 約28回
  - **全体で約250回の戦闘を経験させる**（22年間、年平均11回）

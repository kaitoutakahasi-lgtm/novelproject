# ルシウス・エル・エルドラシア

## 基本情報
- **真名**: ルシウス・エル・エルドラシア (Lucius El Eldorassia)
- **外見年齢**: 8-9歳（封印により固定）→ 18歳（封印解除後）
- **実年齢**:
  - 生前: 8年
  - 封印期間: 300年
  - 物語開始時: 308歳
  - 物語終盤: 328歳
- **出身**: エルドラシア魔導王国
- **身分**: 王子（最後の王子）
- **正体**: 国を滅ぼした「災厄の子」
- **一人称**: 僕（一貫）
- **二人称**: 君（エルヴィンに対して）

- エルドラシア時代の様式
- 白と金を基調
- 装飾が細かい
- しかし半透明で霞んでいる

**特徴的な描写**:
```
桃色の光を纏った子供
輪郭がぼやけている
まるで水彩画のような存在感
美しいが、不気味
```

**見え方**:
- エルヴィンにしか見えない
- 暗い場所では桃色に光る
- 明るい場所では透明に近い
- 炎や光を透過する

- 髪: 銀白色、腰まで

- 完璧な美貌

- 威圧感と儚さの共存

## 性格の本質

### コア特性

**サイコパシー傾向（高）**:
- 良心の欠如
- 他者の苦痛に無関心
- 共感能力の欠如
- 表面的な魅力
- 罪悪感を感じない

**ナルシシズム（高）**:
- 自己中心的
- 特権意識が強い
- 他者を道具視
- 称賛への渇望（無自覚）
- 「自分は特別」という認識

**マキャベリズム（中）**:
- 目的のために手段を選ばない
- しかし長期的視野はある
- ルールは守る（契約の絶対性）
- 計算高い

**享楽主義**:
- 快・不快が全ての基準
- 退屈を何より嫌う
- 刹那的
- 「面白いかどうか」で判断

**知的好奇心**:
- 人間観察が趣味
- 特に「壊れる過程」に興味
- パターンの分析が好き
- 予測不可能を好む

### 行動原理

1. **「面白いかどうか」が全て**
   - 道徳や倫理は判断基準にならない
   - 退屈は耐えられない
   - 新しい刺激を求める

2. **約束は守る**
   - 契約魔法の制約
   - 本人の美学でもある
   - 「ルール」は好き

3. **予測不可能を好む**
   - 予定調和は嫌い
   - 変化を楽しむ
   - エルヴィンの「予想外の反応」に興味

4. **「特別」でありたい**
   - 自分は他と違う存在
   - 平凡を嫌う
   - エルヴィンも「特別」だから興味を持つ

5. **長期的視野**
   - 目先の楽しみだけではない
   - 300年の経験から学んでいる
   - 「エルヴィンを壊したら、また一人」という計算

## 感情の変化（重要）

### 封印直後～200年：虚無の時代

**状態**:
- 怒り、混乱、絶望
- 「先生は僕を裏切った」
- 「誰も信じない」
- 徐々に感情が摩耗

**行動**:
- 世界を彷徨う
- 戦場を観察（唯一の娯楽）
- 解放のチャンスを待つ

### 200-300年：諦めと期待

**状態**:
- 「もう、どうでもいい」
- しかし解放への希望は捨てない
- 何度か契約のチャンスがあるが失敗

**行動**:
- 戦場観察を続ける
- 知識を蓄積
- 孤独に慣れる（慣れたふり）

### エルヴィンとの出会い～第二部：興味（おもちゃ的）

**状態**:
- 「お、面白そうなの見つけた」
- 観察対象、暇つぶしの道具
- エルヴィンの反応が「面白い」から契約
- 特別な感情はない

**行動**:
- 契約を結ぶ（暇だから）
- 教える（自分が楽しいから）
- エルヴィンを観察して楽しむ
- 名前をすぐ忘れる
- 人の心がわからないので面倒を起こす

**重要な台詞**:
```
「君、面白いね」
「え、なんで泣いてるの？」
「死んだらつまんないじゃん」
「あ、名前なんだっけ」
「なんで怒ってるの？　僕、悪いことした？」
```

### 第三部～第四部：所有欲

**状態**:
- 「この面白いものは、僕のもの」
- アリシアへの嫉妬
- エルヴィンへの執着の芽生え

**行動**:
- アリシアを邪魔に思う
- エルヴィンとの会話が増える
- 代償時間でトラブルを起こす（注目を引くため）

**重要な台詞**:
```
「彼女といると、君、僕を忘れるよね」
「君、僕に似てきたね。嬉しいな」
「君がいなくなったら、退屈だ」
```

### 第五部～第六部：依存と執着

**状態**:
- 「君がいなくなったら、また一人」
- 孤独への恐怖（無自覚）
- 「失いたくない」という感情

**行動**:
- エルヴィンへの配慮が見られる
- 代償時間の使い方が穏やかに
- 深い対話が増える

**重要な台詞**:
```
「君、壊れそうだね。大丈夫？」
「僕、君がいなくなったら、困るんだけど」
「……君、僕のこと、どう思ってる？」
```

### 第七部：信頼の自覚

**状態**:
- 「これが、信頼ってことなのかな」
- 初めて自覚した感情
- アルトゥス以来の「大切な存在」

**行動**:
- エルヴィンを守ろうとする
- 自分の過去を語る
- 「君がいなくなったら、嫌だ」と認める

**重要な台詞**:
```
「君、僕を裏切らないよね？」
「僕は…君を、裏切りたくない」
「君がいなくなったら、また一人になる。それは、嫌だ」
「これが、信頼ってことなのかな」
```

## 口調・話し方

### 基本パターン

**特徴**:
- 子供らしい柔らかい口調
- 時折古風な言い回しが混じる
- 残酷なことを無邪気に言う
- 疑問形を多用
- 語尾を伸ばすことがある

**語尾**:
```
「〜だよね」
「〜だもん」
「〜かな」
「〜じゃん」
```

**一人称**: 「僕」（一貫）
**二人称**: 「君」（エルヴィンに対して）

### 古風な言い回し（具体例）

300年前の言葉遣いが時折混じる：
```
「それは、いと面白き」（とても面白い）
「汝は」（君は）- 怒った時や真剣な時
「然り」（そうだ）- 肯定する時
「否」（いいえ）- 否定する時
「我が」（僕の）- 所有を強調する時
「〜であろう」（〜だろう）- 推測する時
「〜せよ」（〜しろ）- 命令する時（稀）
```

**使用場面**:
- 感情が高ぶった時
- 真剣な話をする時
- 過去を思い出した時
- アルトゥスについて話す時

### 年代別の変化

**第一部～第二部（無邪気な残酷さ）**:
```
「見えるんだ。君には、僕が見える」
「君、震えてるね。可愛い」
「怖いの？　でも、怖くても死ぬよ？」
「殺したくないの？　でも殺さないと、君が死ぬよ？」
「人が死ぬの、面白いんだよ」
```

**第三部～第四部（興味と執着）**:
```
「君、僕に似てきたね。嬉しいな」
「彼女といると、君、僕を忘れるでしょ？」
「君の友達、いつ死ぬのかな」
「君が強くなれば、僕も嬉しいもん」
```

**第五部～第六部（配慮の芽生え）**:
```
「君、壊れたら、僕、困るんだけど」
「……君、本当に大丈夫？」
「僕、君がいなくなったら、また一人になる」
「君、僕のこと、どう思ってる？」
```

**第七部（信頼の表明）**:
```
「君がいなくなったら、嫌だ」
「僕は…君を、裏切りたくない」
「これが、信頼ってことなのかな」
「先生、遅くなったけど、僕、少し分かった気がする」
```

## 過去

### 生前（0-8歳）

**0-3歳**:
- 魔法の天才として誕生
- 王族として大切にされる（表面上）
- しかし周囲は恐れている

**4-5歳**:
- 宮廷で「神童」として扱われる
- 魔法の才能が開花
- 周囲の大人の思惑を察知し始める

**6-7歳**:
- 孤独を自覚
- 「誰も僕を見ていない。僕の力しか見ていない」
- アルトゥスだけが違うと感じる
- しかしアルトゥスも王国への忠誠との板挟み

**8歳**:
- 誕生日の夜
- 「退屈だったから」国を滅ぼす
- アルトゥスに封印される
- 初めて涙を流す（理解できないまま）

### 封印中（300年）

**最初の50年**:
- 怒り、絶望
- 「先生は僕を裏切った」
- 「誰も信じない、誰も」

**50-200年**:
- 感情が摩耗
- 「もう、どうでもいい」
- 戦場を彷徨い、観察
- 「みんな、必死に生きて、死んでいく。何のために？」

**200-300年**:
- 変化の兆し
- 何度か解放のチャンスがあるが失敗
- 「やっぱり、信じられない」

## 執筆時の注意点

1. **子供らしさと恐ろしさの両立**
   - 可愛い仕草と残酷な言葉
   - ギャップが魅力
   - 無邪気さが逆に怖い

2. **感情の成長を段階的に**
   - 急に「優しく」ならない
   - 自覚のない変化
   - 本人も理解していない

3. **古代の存在であることを忘れない**
   - 時折、現代の常識と齟齬
   - 300年の記憶の重み
   - 言葉遣いに古風さを混ぜる

4. **エルヴィンへの執着の描写**
   - 依存ではなく「退屈しのぎ」から始まる
   - 徐々に「失いたくない」へ
   - 最終的に「信頼」と自覚

5. **サイコパスとしての一貫性**
   - 良心はない
   - 共感能力もない
   - しかし「所有欲」「依存」は持てる
   - 「愛」ではなく「信頼」（ルシウスなりの）

6. **来歴**
   - 人間の魔導士
   - エルドラシア魔導王国の王子
   - 封印された古代の存在

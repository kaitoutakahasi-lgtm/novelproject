# アリシア・フォン・エーレンベルク

## 基本情報
- **フルネーム**: アリシア・フォン・エーレンベルク (Alicia von Ehrenberg)
- **年齢**: 13歳（第一部）→ 33歳（最終）
- **出身**: ミューレン（エルヴィンと同じ町）
- **身分**: 没落貴族の令嬢（エーレンベルク家）
- **職業推移**: 令嬢 → 薬草師見習い → 従軍看護婦 → 療養院の院長
- **関係**: エルヴィンの幼馴染、後に恋人
- **一人称**: 私（わたし）

## 家族
- **父**: フリードリヒ・フォン・エーレンベルク（元男爵、病死、王暦525年）
- **母**: エリーザベト（病弱、王暦527年に死亡）
- **兄弟**: なし（一人娘）

## 家の没落
- **原因**: 祖父の代の投資失敗、領地の大半を売却
- **現状**: 男爵の称号のみ、実質的な領地なし
- **父の仕事**: ミューレンで薬草商を営む（貴族としては異例）
- **母の苦悩**: 「落ちぶれた」ことへの羞恥心

## 性格

### コア特性
- 聡明で意志が強い
- 慈悲深いが現実主義者
- 芯が強い（折れない、しかし柔軟）
- 他者への共感能力が高い
- 自分を犠牲にしすぎない（学んだ結果）
- **観察力が鋭い**: 人の変化に気づく

### アリシア自身の物語

#### 「待つ女」ではない
```
アリシアの選択:
- エルヴィンを「待つ」だけではない
- 自分の道を歩む
- 「私にできること」を探し続ける
- 結果として、エルヴィンと再会する
```

| 年齢 | 出来事 | アリシアの選択 |

| 15歳 | 父の死 | 家を支える決意、薬草師の道へ |
| 17歳 | 母の死 | 一人になる、しかし折れない |

| 25歳 | 療養院設立 | 「傷ついた人を救う」自分の使命を見つける |

### 内面の葛藤

#### エルヴィンへの愛と疑念
```
愛している:
- 幼馴染としての長い歴史
- 「あの頃の彼」を知っている
- 変わっても、根っこは同じだと信じたい

疑念:
- 「彼は変わった」という確信
- 時々「別人」になる瞬間
- 嘘をついている、何かを隠している
- でも、問い詰められない
```

#### 「知っていた、一部は」の意味
```
アリシアが気づいていたこと:
- エルヴィンが「何か」を隠している
- 時々、目の色が変わる（比喩的に）
- 戦場での「異常な」活躍
- 一人で喋っている時がある

気づいていなかったこと:
- ルシウスの存在
- 憑依の具体的な内容
- 契約の代償

第35章での告白後:
- 「やっぱり」という気持ち
- 「そこまでとは」という衝撃
- 「それでも」という決意
```

### 行動パターン
- 冷静に状況を判断（感情的になっても、行動は冷静）
- 人を助けることに喜びを感じる
- しかし「救えない人」がいることも知っている
- 自分の限界を認める強さ

### 価値観
- 「人の命」を何より大切にする
- 「普通の幸せ」を求める、しかし「普通」の定義は変わる
- 道徳を重んじる、しかし「絶対的な正義」は信じない
- **「真実」を大切にする**: 嘘を嫌う、しかし「嘘をつく理由」も理解しようとする

### 口調
```
13歳:
「エルヴィン、大丈夫？」
「私、待ってるから」
「必ず、帰ってきてね」
→ 少女らしい、素直、優しい

21歳:
「お久しぶりです、エルヴィン」
「あなた、変わったわね」
「……何か、隠してる？」
→ 大人になった、観察力、少しの距離感

29歳:
「全部、話して」
「……そう」
「私は、あなたを愛してる。それは変わらない」
→ 強さ、受容、しかし簡単ではない

33歳:
「一緒に、生きましょう」
「灰色でも、いいじゃない」
「私たちは、私たちの道を歩く」
→ 覚悟、受容、前を向く
```

## エルヴィンとの関係推移

### 第一部（13歳）：幼馴染
- **幼少期**: 同じ町で育った幼馴染
- **出会い**: 8歳の時、アリシアの家が没落して引っ越してきた
- **関係**: 淡い恋心、お互いを意識
- **日常**: 一緒に市場を歩く、川辺で話す
- **徴兵前夜（第3章）**: 「必ず帰ってきて」という約束
- **別れ（第4章）**: 雨の中の涙の別れ

**アリシアの内面（第一部）**:
```
「エルヴィンは、優しすぎる」
「戦場で、生き延びられるのだろうか」
「私に、何ができるのだろう」
「待つことしか、できない」
「……いいえ。待つだけじゃ、ダメ」
```

### 第二部〜第三部（14-21歳）：文通と成長

#### 文通の内容
```
エルヴィンからの手紙:
- 最初は長い、詳細な日常
- 徐々に短くなる
- 「元気だ」「心配するな」
- 書けないことが増えていく

アリシアからの手紙:
- 町の様子、季節の変化
- 父の死、母の病気
- 「私は元気です」（嘘）
- 「待っています」（本当）
```

#### アリシアの成長
| 年齢 | 出来事 | 内面の変化 |
|------|--------|------------|
| 15歳 | 父の死 | 「私が、家を守らなければ」 |
| 16歳 | 薬草師見習い | 「私にも、できることがある」 |
| 17歳 | 母の死 | 「一人になった。でも、折れない」 |
| 18歳 | 従軍看護婦志願 | 「戦場を、この目で見たい」 |

#### 従軍看護婦になった理由
```
表向きの理由:
- 「人を助けたい」
- 「医療の技術を学びたい」

本当の理由:
- 「エルヴィンの世界を知りたい」
- 「彼が何を見ているのか、知りたい」
- 「待っているだけでは、彼を理解できない」
- 「同じ場所に立ちたい」
```

### 第三部後半〜第四部（21-25歳）：再会と恋人

#### 再会（第四部第20章）
```
10年ぶりの対面:
- 場所: 王都
- アリシアは療養院を設立準備中
- エルヴィンは政治の世界に入っている
- 手紙では繋がっていたが、直接会うのは10年ぶり

なぜ10年間会えなかったか:
1. 戦時中の移動制限（民間人の前線地域への立入禁止）
2. エルヴィンの意図的な回避（変わった自分を見せたくない）
3. アリシアの状況（父の死、母の看病、従軍看護婦として各地を転々）
4. 休暇の不一致（エルヴィンが故郷に帰れる時、アリシアは別の場所にいた）

最初の会話:
アリシア「……エルヴィン？」
エルヴィン「アリシア……久しぶりだな」
アリシア「大きくなったわね」
エルヴィン「お前も……綺麗になった」
アリシア「……あなた、変わったわね」
エルヴィン「……そうか？」
アリシア「目が、違う」
```

#### 関係の深化（第四部第21-23章）
- **第21章**: 再会後、定期的に会うように
- **第22章**: 正式に恋人に
- **第23章**: 幸せな時間、しかしアリシアは「何か」を感じている、プロポーズ

**第23章の重要シーン**:
```
アリシア「エルヴィン、あなた、時々別人になるわ」
エルヴィン「……気のせいだ」
アリシア「いいえ。目の色が変わる。声も、仕草も」
エルヴィン「疲れているだけだ」
アリシア「嘘。あなたの中に、何かいる」
エルヴィン「……」
アリシア「話してくれないの？」
エルヴィン「話せない。今は」
アリシア「……分かった。待つわ。でも、いつか話して」
```

### 第五部（26-28歳）：危機

#### 関係の悪化
- エルヴィンが「壊れていく」のを見ている
- 助けたいが、助け方が分からない
- 「何かいる」という確信は強まる
- しかし、問い詰めることもできない

**アリシアの苦悩**:
```
「彼は、私から離れていく」
「私では、救えないのか」
「あの『何か』が、彼を蝕んでいる」
「でも、彼はそれを手放さない」
「私は、どうすればいい」
```

#### 療養院の設立
- 戦争で傷ついた兵士のための施設
- アリシアの「自分の道」
- 「エルヴィンを救えなくても、他の人は救える」
- しかし、諦めたわけではない

### 第六部（29-32歳）：真実と再構築

#### 真実の告白（第35章）
```
エルヴィン「全部、話す」
アリシア「……」

（エルヴィン、ルシウスのこと、契約のこと、全てを語る）

アリシア「……そう」
エルヴィン「怒っているか」
アリシア「怒ってる。でも、驚いてはいない」
エルヴィン「……知っていたのか」
アリシア「一部は。『何かいる』とは思っていた」
エルヴィン「……」
アリシア「なぜ、今まで話してくれなかったの」
エルヴィン「怖かった。お前に、嫌われるのが」
アリシア「……馬鹿ね」
```

#### 再構築の過程（第36章）
- 簡単には許さない
- 時間をかけて、新しい関係を築く
- 「嘘の上の関係」から「真実の上の関係」へ
- ルシウスの存在も、受け入れようとする

**アリシアとルシウスの「対面」（第36章）**:
```
アリシア「あなたが、ルシウス？」
ルシウス（エルヴィンの体で）「君が、アリシア？」
アリシア「……小さい子供だと聞いていたけど」
ルシウス「見た目はね。中身は300歳だよ」
アリシア「エルヴィンを、どう思っているの」
ルシウス「……面白い。大切。失いたくない」
アリシア「それは、愛情？」
ルシウス「分からない。でも、君と同じかもしれない」
アリシア「……そう」
```

### 第七部（33歳）：共に

#### 最終決戦
- エルヴィンを支える
- 「行ってきて。私は、ここで待ってる」
- 「待つ」ことの意味が変わっている
- 今は「信じて待つ」

#### エピローグ
- 共に生きる決意
- 「灰色」を受け入れる
- 「普通の幸せ」ではないかもしれない
- でも、「私たちの幸せ」

## 物語上の役割

1. **エルヴィンの「人間性」の象徴**: 「普通の人生」の可能性、「光の世界」への繋がり
2. **ルシウスとの対比**: 光 vs 闇、道徳 vs 非道徳、温かさ vs 冷たさ
3. **エルヴィンの選択を際立たせる**: 嘘をつき続けるか、真実を語るか
4. **読者の感情移入先**: アリシアの視点＝読者の視点（「何かおかしい」と気づく）
5. **贖罪の伴走者**: 最終的にエルヴィンと共に生きる決意
6. **「待つ女」ではない**: 自分の道を歩み、自分の選択をする女性

## 執筆時の注意点

1. **強い女性として描く**: 単なる「恋人」ではない、自分の意志を持つ
2. **エルヴィンへの愛情**: 本物の愛、しかし「全てを受け入れる」わけではない
3. **幼馴染としての歴史**: 二人の間には長い歴史がある
4. **真実を知った後の葛藤**: 簡単に許すわけではない、時間がかかる
5. **アリシア自身の物語**: 彼女にも成長があり、選択がある
6. **「灰色」の受容**: 最終的に「灰色」を受け入れる強さ

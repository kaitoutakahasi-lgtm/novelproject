# 作家タイプ自己定義

## かもめ式診断結果(葦沢氏第2回記事のワーク結果)

### ステップ1(物語の起点)
- 最も多く選んだ選択肢: **T** (テーマ駆動)
- 補助的に該当: C (キャラクター駆動), M (モーメント駆動)

### ステップ2(プロセス)
- 最も多く選んだ選択肢: **P** (プランナー)

### 確定タイプ
**TP (テーマ駆動型プランナー) + CP/MP ハイブリッド**

---

## 標準の TP フロー

葦沢氏第2回記事の TP の制作フローは以下:

> テーマ/世界観 → ログライン/キャラ/あらすじ → 本文 → 推敲

これを葦沢氏第1回記事の公式7ステップに揃えると:

> ① アイデア → ② コンセプト → ③ 世界観 → ④ キャラクター → ⑤ あらすじ → ⑥ 本文 → ⑦ 推敲

(TPの場合、①〜③がテーマ/世界観として一塊になり、④〜⑤でキャラ/ログライン/あらすじが来る)

---

## 本作で加える順序修正

本作固有の要請で、標準フローに2つの前倒しを入れる:

### 修正1: 声の先取り(CP要素)
- **理由**: ウェンティ型腐った声が作品の印象を決定する。通常のTPだと声は本文執筆時まで固まらないが、本作は最初に固めないとシリアス文芸に寄りすぎる
- **対応**: Phase 2 で tone-bible.md + voice-kamome Skill + eval-voice Skill を優先作成する

### 修正2: カタルシス一文の先置き(MP要素)
- **理由**: フリーレン型カタルシスは**見せ場から逆算する**性質を持つ。各アークの「遅すぎる理解」の一文が決まらないと、キャラ設計もプロットも浮遊する
- **対応**: Phase 5 のマスタープロット作成時に、各アークのカタルシス一文を先に全部決めてから arc-map.md に埋め込む

結果としての本作採用フロー:

```
① アイデア
② コンセプト/テーマ/ビジョン (Phase 1)
★[CP前倒し] 声の先取り (Phase 2)
③ 世界観 (Phase 3)
④ キャラクター (Phase 4)
⑤ マスターあらすじ
★[MP前倒し] カタルシス一文 (Phase 5)
⑤' アーク詳細あらすじ (Phase 6)
⑥ 本文 (Phase 7)
⑦ 推敲 (Phase 7)
```

## 本作が得意にすべきこと(TP+CP+MP の得意を足し算)

- 一貫した読後感・主張・構造 (TP)
- 主人公の心理の一貫性・内面描写の解像度 (CP)
- 伏線回収・遅すぎる理解のカタルシス (MP)

## 本作で警戒すべき罠(TP+CP+MP の苦手を足し算)

葦沢氏第2回記事から各タイプの「苦手なこと」を引用して合算:

- 序盤が説明過多になり読者が離れる (TP)
- 事件の推進力が弱くて中盤停滞 (CP)
- ご都合主義・キャラの動機が薄い (MP)

→ **対策**: 各アークの第1章の冒頭3シーンで「事件」「主人公の欲望と欠落」「世界の独自ルール」の3つを同時に見せることをルール化する(Phase 6 のチェックリストに反映)。

## AIへの質問時のルール

葦沢氏第2回記事の推奨: AI に「原稿の締切を守る方法」「この設定で破綻しないか」等の相談をする時は、**必ず自分のタイプ情報をプロンプトに含める**。タイプなしだと一般論が返り、タイプ込みだとタイプに合ったアドバイスが返る。

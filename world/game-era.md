# 元 VRMMO 仕様(game-era)

閉じ込め時点(Y0)のゲーム仕様。これが本作世界の物理法則の原型になる。

Phase 3 で build-world Skill を使って本格展開する。ここには骨子のみ記録。

## ジャンル

- 王道ハイファンタジー(剣と魔法、エルフ・ドワーフ等の古典種族)

## 初期規模

- 初期同時接続: 約 3 万人
- 1 ワールド 5000 人 × 6 ワールド
- 6 大陸 + 海路構成

## 職業・ビルド

- tier 1-5 の階層(主人公は tier 2.5 = 調整役・顔役)
- 種族選択(人間 / エルフ / ドワーフ / 獣人 等)

## 死・蘇生

- 真死(復活なし)
- 蘇生魔法は時限・条件あり、かいくぐる抜け穴もあり

## 寿命

- ゲーム内の体の寿命(種族依存)
- 魔法 / AF で延長可能(AF は国家元首等の使用条件あり)
- 主人公のみ完全不老(宗教国家の元首の立場で AF 使用条件を満たす)

## テレポ網

- 初期は全大陸接続
- 過去の客人間戦争で破壊済み(犯人はリンチで死亡)
- 現代では移動手段は独占国 3-4 のみ

## プレイヤー UI

- フレンド機能(リスト / チャット / 通話 / 画像)
- ログアウトボタン(押しても無反応)
- その他の HUD・スロット等ほぼ全残存

## Phase 3 で展開する詳細

- 職業別スキルツリー
- 魔法体系
- 経済システム
- NPC 社会の初期設計

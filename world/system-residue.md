# VRMMO システム残滓

本作の**最重要**な世界観要素の一つ。何が残り、何が消え、誰が使えるのかを明示する。

## プレイヤー(客人)の UI

### 残存している機能
- **HUD**: ステータス表示、ミニマップ、スキルスロット
- **インベントリ**: 全機能
- **フレンド機能**: リスト / チャット / 通話 / 画像送信
- **パーティ・ギルド**: 機能は残るが実質無意味(ほぼ全員死亡)
- **クエストログ**: 機能は残るが新規クエストは発生しない
- **設定メニュー**: 表示・操作設定

### 反応しなくなった機能
- **ログアウトボタン**: 唯一無反応(初期からの仕様の「裏返し」)
- **運営通知**: 閉じ込め発生以後ゼロ

### フレンド機能の重要性(本作固有)
- フレンド登録は閉じ込め中も通常通りできる
- 登録された客人が死ぬと、リストから消える(これが本作の"訃報"媒体)
- 通話履歴・画像履歴は残る(遺品的に機能する)
- 主人公は最後のフレンド 1 人が消えたことで旅に出る

## 客血(子孫)の UI

### 存在しない
- 客血はシステム機能を**一切持たない**
- HUD、インベントリ、フレンド機能 — すべてない
- プレイヤーとの**決定的差異**

### 客人の UI を部分的に見られる事例
- 客人の装備を借りれば装備スロットの表示は補正で見える(限定的)
- 多くの場合、客血は客人の UI を「伝承上の不思議な力」として認識

## NPC の UI

- 一切なし(最初から)
- NPC はゲーム世界の住人として独立した認識体系で生きている

## 蘇生・復活

- 真死(復活なし)が原則
- 蘇生魔法は時限・条件あり、抜け穴もあり(詳細は Phase 3 の magic-and-system.md)
- フレンドリストから消えた = 真死、は原則成立

## AF(Artifact)

- 不老・長寿・強力な権能を付与する特殊装備
- 使用条件の一つが「国家元首」(主人公の宗教国家の元首資格はここに該当)
- 現存する AF 使用者は主人公含めて約 20 人

## テレポ網

- 初期は全大陸接続
- 過去の客人間戦争で破壊済み
- 犯人はリンチで死亡
- 復旧不可

## 本人認証ギミック

- 主人公の黒歴史宗教国家に設置された、本人のみ作動する仕掛け
- 美化された主人公像と齟齬しても、これが「本物」の証明になる
- 主人公は普段面倒がって使わない
- Arc 05 での起爆装置

# 現在(Y60+・current-era)総観

プレイヤー絶滅後の Y60+ の世界の総観。

Phase 3 で build-world Skill を使って本格展開する。

## 客人(元プレイヤー)の状況

- 主人公以外ほぼ全滅
- 完全不老 + 長寿合わせて約 20 人が存命(主人公と面識は薄〜ゼロ)
- 残り全員死亡

## 客血(子孫)の状況

- 複数の地域に分散して存在
- システム機能を一切持たない
- 客人の記憶・言い伝えを継承するが、60 年の時間で独自解釈に変質

## NPC 社会

- 客人がいた頃と同じ原理で動いている(NPC 自身の合理)
- プレイヤー文化が NPC 独自解釈で変質(culture-drift 参照)
- 主人公を神扱い・英雄扱いする地域あり(本人主張は取り合われない)

## 地理

- 6 大陸 + 海路はそのまま
- テレポ網は壊れたまま
- 移動は独占国 3-4 の手段(空路 / 地下 / 海運 / テレポ残骸等、詳細未定)
- 通常の商業船・陸路は機能している

## システム残滓

- 主人公はプレイヤー UI 全残存
- 客血・NPC は UI なし
- 主人公のフレンドリストには今も 1-2 名(最終確認点)

## 主人公の現在地

- 宗教国家から離れた遠くの田舎町の宿屋
- 数十年のんべえ隠居
- 莫大な資産で食うに困らない

## Phase 3 で展開する詳細

- 各地域の支配勢力図
- 残っているプレイヤー文化(変質済)のカタログ
- 20 名の長寿者の地理的分布(素描レベル)
- 風化しつつある VRMMO システムの知識

# 魔法・スキル・死・寿命システム

Phase 3 の build-world で本格展開。ここには骨子のみ。

## 魔法体系

- ゲーム内体系(Phase 3 で詳細)
- 客人はスキル / 呪文として使用
- 客血・NPC は独自の伝承・修練として使用(客人のシステム魔法とは機序が別の認識)

## スキル

- プレイヤー UI に表示されるスロット式
- 客人限定機能

## 死

- **真死**: 復活なし
- **蘇生魔法**: 時限・条件あり
- 抜け穴: 時限内 + 条件揃いで蘇生可能なケースあり
- フレンド機能消失 = 真死

## 寿命

- ゲーム内の体の寿命
- 種族依存(人間系 70-90 年、エルフ数百年、ドワーフ 200 年程度、等)
- 魔法 / AF で延長可能
- AF 使用条件の一つが「国家元首」

## 不老

- 完全不老は AF + 魔法の組み合わせ
- 主人公は宗教国家元首資格 + AF で完全不老
- 現存する完全不老 + 長寿者は約 20 人

# プレイヤー文化の NPC 独自解釈への変質ログ(本作固有)

60 年間で、プレイヤー文化は NPC 側によって**独自解釈・変質**されてきた。
カタルシス型 3(世界の真相)の発火源になる。

Phase 3 で具体ケースを 3 件以上埋める(workflow.md の Phase 3 チェックポイント)。

## 変質パターン

### パターン A: 誤記憶・誤伝承化
客人の行動や言葉が、NPC の口伝で変形して現代に残る。
例: 酔った悪乗りの発言 → 神託扱い

### パターン B: 制度の形骸化・再解釈
客人が作った制度が、元の意図と違う目的で現代運用されている。
例: 商売人が定めた祝日 → 宗教的意味を付与される

### パターン C: 物品の神格化
客人の遺品が、元の機能と違う扱いで祀られる。
例: ただの酒瓶 → 聖遺物

### パターン D: 名前の曲解
客人の名前・あだ名が、NPC 語で変形される。
例: 主人公の名前 → 美化された別名(主人公本人と別人化)

## 本作での使い方

- culture-drift は物語の「遅さ」を空間的に示す装置
- 主人公が訪ねる先々で「自分たちの文化が変質している」のを発見する
- 多くの場合、主人公は軽口で受け流す(茶化しの対象)
- 一部のケースだけが静寂層のトリガーになる(故人の本心に繋がる時)

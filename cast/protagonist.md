# 主人公

## 基本

- **本名/プレイヤー名**: 未確定(カタカナ男の子名。候補: イオ / シオ / ソラ)
- **本人が名乗る一人称**: **ぼく**
- **見た目**: 13-15 歳の少年
- **本人の感覚**: 少年のまま(77 歳の記憶を持つが、爺の自認なし)
- **Tier**: 2.5(調整役・顔役)
- **職業ビルド**: Phase 3 詳細化

## 不老・寿命

- **完全不老**
- 宗教国家(黒歴史)の元首資格 + AF により成立
- 他の完全不老 + 長寿者: 約 20 人(主人公と面識は薄〜ゼロ)

## 立場・肩書

- 黒歴史宗教国家の元首(肩書だけ、現存)
- 実務に一切関与せず数十年
- 共同創設の親友 PL は民のため責任を取って死亡
- 祀られて美化されすぎて、現在では伝承上の別人扱い

## 認証ギミック

- 宗教国家の中枢に本人認証仕掛けあり
- 主人公が手を触れると作動、本物と証明できる
- 普段は面倒がって使わない
- `legacy/authentication-gimmick.md`

## 現在の暮らし

- 宗教国家から離れた田舎町の宿屋でのんべえ隠居
- 莫大な資産で食うに困らない
- 数十年この状態

# 派閥・ギルド索引

Phase 4 で 5-10 個の主要派閥を設計する。

## 主要派閥カテゴリ

- **客人系**: プレイヤー主体のギルド / 派閥(多くは解散 or 滅亡)
- **客血系**: 子孫中心の組織(現代も機能)
- **NPC 系**: 60 年以上続く NPC 側の勢力

## 主人公との関係タイプ

- 所属歴あり
- 共同創設
- 敵対
- 中立
- 一方的に祀られる(宗教国家系)

## 設計ルール

- 主人公が所属したものと敵対したものをそれぞれ最低 1 つ設計
- 興亡史(結成 → 活動 → 変質 / 解散 / 滅亡)を記録
- 現代での残存形(NPC 化 or 伝承のみ)を明示

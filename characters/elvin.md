# エルヴィン・クライス（Elvin Kreis）

## 基本情報
- 年齢：13歳（開始時）→ 33歳（終結時）
- 出身：ヴェルナント王国辺境、ミューレンの商家の次男
- 一人称：僕（第一部〜第二部前半）→ 俺（第二部Ch.13〜）
- 瞳の色：鈍色（灰色）。憑依「重なり」時は紫が混じる
- 血統：母方の遠い祖先に魔導士（霊的感受性の由来）

## 本質
パターン認識の天才。混沌の中に構造を見出す。
商人の次男として「役に立たない」とされた観察力が、戦場では人の配置・地形・心理を瞬時に読み解く致命的な才能になる。

## 家庭環境
- **父ハインリヒ**: 商人組合副長。寡黙で判断が速い。「お前は目がいいが商人には向いていない」。王暦533年に病死
- **母マルタ**: 没落貴族（旧男爵家エーレンフェルト）。基礎的な貴族作法をエルヴィンに教え込んでいる。一般男爵嫡子かそれ未満レベルの所作が身についている
- **兄ヴェルナー**: 商才に長ける。エルヴィンを「道具」として使うが、出発時に万年筆を贈る

## 年齢別プロファイル

### 13歳（第一部）
**外見**: 身長155cm、体重45kg。線が細く猫背。茶色の癖毛、灰色の伏し目がちな瞳。平凡で目立たない顔立ち。白い肌、柔らかい手（商家の息子）。おどおどした態度。

**性格**: 臆病、優しすぎる、自己評価が低い。争いを極端に嫌う。内省的、考えすぎて動けない。他者の痛みに敏感すぎる。

**口調**:
```
「あ、あの……」「すみません……」「……はい」
語尾が弱い、敬語多用、声が小さい。一人称「僕」
```

**内的独白**: 自己否定的、不安が中心。「僕には、できない」「怖い」

### 13-14歳（第二部）
**外見**: 身長158→165cm。訓練で引き締まるがまだ細い。灰色の瞳に時折鋭い光。日焼け、小さな傷跡。剣だこができ始める。姿勢が良くなり、表情が硬くなる。

**性格**: 恐怖と向き合う。生存本能の目覚め。まだ臆病だが動けるようになる。罪悪感が強い。

**口調**:
```
「……分かった」「やるしかない」「すまない」
短く実務的に。敬語は減る。一人称「僕」→「俺」（Ch.13・初殺人後に変化）
```

**一人称変化の瞬間**: Ch.13で初めて自分の手で人を殺した後、「僕は……いや、俺は……」と自己認識が変わる。以降一貫して「俺」。

### 15-21歳（第三部）
**外見**: 身長165→172cm（成長止まる）、体重55→62kg。しなやかな筋肉質。肩までの髪を戦場では後ろで束ねる。冷たい印象の灰色の瞳。左肩に槍傷、右太腿に剣傷。

**性格**: 才能の自覚。戦術家としての自信。「必要なこと」と「正しいこと」の天秤。

**口調**:
```
「了解した」「問題ない」「そうするしかない」
冷静、簡潔、命令口調が増える
```

### 22-25歳（第四部）
**外見**: 体重65kg。成熟した体、無駄のない筋肉。手入れされた髪。感情を読ませない瞳。貴族の衣装、質の良い布地。威厳のある立ち居振る舞い。

**性格**: 権力者だが虚無感。手段を選ばなくなる。罪悪感の麻痺が始まる。

**口調**:
```
「そうするしかない」「仕方がない」「私に任せてくれ」
自己正当化が増える、感情を殺した話し方
```

### 26-28歳（第五部）
**外見**: やや痩せる。白髪が混じり始める（ストレス）。疲労の影。実年齢より5歳上に見える。くすんだ肌。時折虚ろな表情。

**性格**: 精神の摩耗。「俺は誰だ」。ルシウスへの依存と執着。

**口調**:
```
「……」（沈黙が増える）「分からない」「もう、どうでもいい」
独白が長くなる、自問自答
```

### 29-33歳（第六部・第七部）
**外見**: 白髪が3割程度。深い影のある瞳に意志の光。30代半ばに見える。疲れているが芯の強さを感じさせる。

**性格**: 真実と向き合う。ルシウスと「似ている」が「別人」であることも自覚。葛藤を抱えたまま前へ。

**口調**:
```
「俺は、こうする」「これが、俺の選択だ」「後悔はしていない」
決意を含む、迷いを認めた上での言葉
```

**剣術Bの意味**: 本質的な剣の才能はない。ルシウスの指導と実戦経験で上級兵レベルには達するが、達人にはなれない。憑依時の剣技はルシウスの千年の観察の結晶であり、エルヴィンの実力ではない。

### 特殊能力
- **霊的感受性**: S級（生まれつき）。ルシウスを視認・対話できる
- **記憶力**: A級。一度見た地形、顔、陣形を正確に再現
- **パターン認識**: S級（天才）。戦場の流れを読む、敵の動きを予測
- **学習能力**: A級。ルシウスの技を部分的に再現可能（完全再現は不能）

## 対人関係の本質（三角構造）

エルヴィンは**ルシウス（非人間性の極）**と**アリシア（人間性の極）**の間を揺れ動く。

- **ルシウス**: 最も長い関係。道具→共犯者→理解者。エルヴィンが唯一「嘘をつかない」相手。ルシウスの側に傾くほど道徳値は下がる
- **アリシア**: 「人間に戻れる場所」。だがその関係は嘘の上に建っている。アリシアの側に戻るほど道徳値は回復するが、嘘を重ねる罪悪感も増す
- **レオン**: 失われた可能性の象徴。レオンの死後、エルヴィンは親密な関係を避ける
- **ガレス**: 鏡像。「正しさに殉じる者」の姿。エルヴィンが捨てたものの具現
- **トーマス**: 残された人間性の証拠。「もう友達は作らない」と決めた後に守りたいと思った存在
- **マクシミリアン**: 政治的師弟だが、マクシミリアンはエルヴィンの中の「異常」に弟エーリッヒの影を見ている

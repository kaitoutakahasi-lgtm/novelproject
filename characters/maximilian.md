# マクシミリアン・フォン・ヴァルトシュタイン（Maximilian von Waldstein）

## 基本情報
- ヴァルトシュタイン公爵家（軍人貴族）出身
- 55歳（初登場、王暦525年）→ 65歳（王暦535年）
- 王国軍の高級将校。後に総司令官
- 初登場：第三部Ch.28

## 家族
- **妻**: 死別（10年前）
- **子**: 戦死（15年前）
- **弟**: エーリッヒ（約25年前に死亡。ルシウスの契約者だった）

---

## 外見

### 55歳時（初登場）
- 身長180cm。痩せ型だが筋肉質、壮年の威厳
- 鷲鼻、鋭い灰色の目、黒髪に白髪が混じる、深い皺
- 常に軍服。勲章は着けない（実用主義）

### 65歳時
- 白髪が増え、皺が深くなる。しかし目の鋭さは変わらない

---

## 性格

### コア特性
- 冷徹な戦略家だが、部下への情もある
- 責任感が強い
- 学究的（古代史の研究者）
- 家族を全て失った悲しみを内に抱える

### 行動パターン
- 感情を表に出さない
- 常に最悪を想定する
- 長期的視野で判断
- 部下の才能を見抜く
- 冷酷な決断も辞さない

### 口調
簡潔、冷静、しかし時折温かみがある。
```
「報告しろ」
「了解した」
「お前に任せる」
```

## 弟エーリッヒとの過去（約25年前）

### エーリッヒの契約
- 弟エーリッヒ（20代）、古代遺跡調査中にルシウスと遭遇
- 霊的感受性が高く、ルシウスを視認。契約を結ぶ

### マクシミリアンの警告
- 弟の様子がおかしいことに気づく
- エーリッヒ「兄さん、僕には見えるんだ。古代の子供が」
- 最初は精神疾患を疑う
- しかしエーリッヒの能力が異常に向上していく

### 真実の発見
- エーリッヒ、3年後に古文書で「災厄の子」の記述を発見
- 教会に歪められた歴史：「エルドラシアを滅ぼした悪魔の王子」
- 恐怖して契約破棄を試みる

### 破綻
```
ルシウス「君、僕を見る目が変わったね」
エーリッヒ「お前は……悪魔なのか？」
ルシウス「悪魔？　そうかもね。でも、僕たち友達じゃなかったの？」
エーリッヒ「友達……？　そんなわけ……」
ルシウス「やっぱり、裏切るんだ。みんな、そうだ」
```

### 結末
- 契約魔法が暴走。エーリッヒの精神に重大なダメージ。廃人同然に
- 3年後に死亡

### マクシミリアンの決意
- 弟の最期を看取る
- エーリッヒの日記を発見。ルシウスの存在を知る
- 「あの悪魔が、弟を壊した」
- 「次の犠牲者を出してはならない」

## エルヴィンとの関係（原案準拠）

### 第三部：接近
- エルヴィンの才能を認め、側近に引き入れる
- 表向きは政治的協力者。実際にはエルヴィンの「異常性」に気づいている
- 弟と同じ兆候——不自然な能力の向上、時折の人格の揺らぎ——を感知

### 第四部：警戒
- 確信を深める。「弟と似ている」
- しかしすぐには動かない。証拠を集め、状況を見極める
- エルヴィンを利用しつつ監視する二重の立場

### 第五部：対立
```
マクシミリアン「25年前、私の弟も、同じものに憑かれた」
「あの悪魔が、弟を壊した」
「お前も、同じ道を辿る」
エルヴィン「将軍、それは誤解です」
マクシミリアン「お前はまだ救える。あの悪魔を、今度こそ封じる」
```

### 最終対決（原案：第七部）
```
マクシミリアン「エルヴィン、お前を止める」
「私は、弟を救えなかった」
「だが、お前は救える」
エルヴィン「将軍……」
マクシミリアン「お前は、まだ人間だ」
```

敗北後：
```
マクシミリアン「お前は……間違っている……」
エルヴィン「分かっています」
マクシミリアン「ならば……なぜ……」
エルヴィン「止められないんです」
マクシミリアン「……そうか」
「弟と……同じか……」
「すまない……エーリヒ……」
「また……救えなかった……」
```

## 物語上の役割

1. **エルヴィンの最後の障害**: ルシウスとの関係を断ち切ろうとする。しかし「悪」ではない
2. **過去と現在の繋がり**: エーリッヒの失敗の繰り返し。歴史は同じパターンを辿るのか
3. **悲劇性の強調**: マクシミリアンは「正しい」。弟を壊したものから次の犠牲者を守ろうとしている。誰も悪くない戦い
4. **エルヴィンを疑う者**: 帝国が国家レベルでルシウスの封印を追う一方、マクシミリアンは個人レベルの実体験から契約者の兆候を検知する

## 執筆時の注意点

1. **冷徹だが人間的**: 弟への愛情は深い。家族を全て失った男
2. **誤解と真実**: 半分しか真実を知らない。教会に歪曲された「悪魔の王子」像を信じている
3. **対決の悲壮感**: 老いた身体でエルヴィンに挑む。「弟を救えなかった」後悔が全ての動機

# アリシア・フォン・エーレンベルク（Alicia von Ehrenberg）

## 基本情報
- 年齢：13歳（第一部）→ 33歳（最終）
- 出身：ミューレン（エルヴィンと同じ町）
- 身分：没落貴族の令嬢（エーレンベルク家）
- 職業推移：令嬢 → 薬草師見習い → 従軍看護婦 → 療養院の院長
- 一人称：私（わたし）

## 家族
- **父**: フリードリヒ・フォン・エーレンベルク（元男爵、薬草商、王暦525年に病死）
- **母**: エリーザベト（病弱、王暦527年に死亡）
- 一人娘

## 家の没落
- 祖父の代の投資失敗。領地の大半を売却
- 男爵の称号のみ、実質的な領地なし
- 父はミューレンで薬草商を営む（貴族としては異例）
- 母は「落ちぶれた」ことへの羞恥心を抱えていた

- 26-30歳：療養院の院長として、落ち着いた威厳

## 本質と対比構造

**ルシウスの対極。人間性の極。**

聡明で意志が強い。慈悲深いが現実主義者。芯が強く、折れないが柔軟。
エルヴィンの「人間に戻れる場所」であると同時に、エルヴィンの変化を最も鋭く感じ取る人物。

嘘を嫌い、真実を重んじるが、人がなぜ嘘をつくかを理解しようとする。
両親を失い、戦場で瀕死の兵士の手を握ってきた経験から、光の中にいながら闇を知っている。
ナイーブではない。だからこそ、エルヴィンの嘘を見抜きながらも問い詰めなかった。

## 「待つ女」ではない

アリシアは自分の道を歩む。エルヴィンを「待つ」のではなく、自分にできることを探し続ける。

| 年齢 | 出来事 | アリシアの選択 |
|------|--------|----------------|
| 13歳 | エルヴィン徴兵 | 「待つ」と決める。しかし「待つだけ」ではない |
| 15歳 | 父の死 | 家を支える決意。薬草師の道へ |
| 17歳 | 母の死 | 一人になる。しかし折れない |
| 18歳 | 従軍看護婦志願 | 「戦場を知りたい」「エルヴィンの世界を知りたい」 |
| 21歳 | エルヴィンと再会 | 「変わった」彼を見て、それでも愛する |
| 25歳 | 療養院設立 | 「傷ついた人を救う」自分の使命を見つける |
| 28歳 | 真実を知る | 衝撃、しかし「知っていた、一部は」 |
| 32歳 | エルヴィンの選択を理解する | 「帰ってこなくていい。あなたが行くべき場所に行って」 |

## 内面の葛藤

### エルヴィンへの愛と疑念
- 幼馴染としての長い歴史。「あの頃の彼」を知っている
- 変わっても根っこは同じだと信じたい
- しかし「彼は変わった」という確信。時々「別人」になる瞬間がある
- 嘘をついている。何かを隠している。でも、問い詰められない

### 「知っていた、一部は」
アリシアが気づいていたこと：
- エルヴィンが「何か」を隠している
- 時々、目の色が変わる（比喩的に）
- 戦場での「異常な」活躍
- 一人で喋っている時がある

気づいていなかったこと：
- ルシウスの存在
- 憑依の具体的な内容
- 契約の代償

告白後：「やっぱり」「そこまでとは」「それでも」

## 口調設計

### 13歳
```
「エルヴィン、大丈夫？」
「私、待ってるから」
「必ず、帰ってきてね」
→ 少女らしい、素直、優しい
```

### 21歳
```
「お久しぶりです、エルヴィン」
「あなた、変わったわね」
「……何か、隠してる？」
→ 大人になった、観察力、少しの距離感
```

### 28歳
```
「全部、話して」
「……そう」
「私は、あなたを愛してる。それは変わらない」
→ 強さ、受容、しかし簡単ではない
```

### 32歳
```
「帰ってこなくていい。あなたが行くべき場所に行って」
「灰色でも、いいじゃない」
→ 覚悟、受容、手放す強さ
```

## 物語上の役割
1. **エルヴィンの「人間性」の象徴**: 「普通の人生」の可能性、「光の世界」への繋がり
2. **ルシウスとの対比**: 光 vs 闇、道徳 vs 非道徳、温かさ vs 冷たさ
3. **エルヴィンの選択を際立たせる**: アリシア（人間性）とルシウス（非人間性）の間で、ルシウスを選ぶ
4. **読者の感情移入先**: アリシアの視点＝読者の視点（「何かおかしい」と気づく）
5. **「待つ女」ではない**: 自分の道を歩み、自分の選択をする女性
6. **手放す強さ**: 最終的にエルヴィンを「行かせる」決断ができる人

## 執筆時の注意点
1. 単なる「恋人」ではない。自分の意志を持つ女性として描く
2. エルヴィンへの愛情は本物。しかし「全てを受け入れる」のではなく「理解して手放す」
3. 幼馴染としての長い歴史。二人の間には共有された過去がある
4. 真実を知った後の葛藤。簡単に許すわけではない
5. アリシア自身にも成長があり、選択がある

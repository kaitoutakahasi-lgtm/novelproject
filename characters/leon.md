# レオン・ブラント（Leon Brandt）

## 基本情報
- 年齢：13〜14歳（第二部Ch.17-18で戦死）
- 出身：ミューレン近郊の農村「グリューネンドルフ」
- 身分：平民（農家の長男）
- エルヴィンとの関係：幼馴染、親友

## 家族
- **父**：ヨハン・ブラント（農民、45歳、寡黙だが家族思い）
- **母**：マリア・ブラント（農民、40歳、明るく働き者）
- **妹**：グレタ（14歳、レオンに似て明るい、兄を慕っている）
- **弟**：ハンス（10歳）、フリッツ（7歳）

### 家族の描写
```
レオンの家:
- 村の外れの小さな農家
- 畑は狭いが、家族で懸命に耕している
- 貧しいが、笑い声が絶えない
- レオンは長男として、家族を支える責任を感じている

グレタとの関係:
- 「兄ちゃん、いつ帰ってくるの？」
- 「すぐだよ。金を稼いで、お前に綺麗な服を買ってやる」
- 「約束だよ？」
- 「ああ、約束だ」
→ この約束が、レオンの死をより痛ましくする
```

## 外見
- 身長：155cm（13歳）→ 160cm（14歳、成長期）
- 体格：がっしり、農作業で鍛えられた筋肉、日焼けした肌
- 顔立ち：丸顔、麦わら色の髪（短め、癖毛）、茶色の瞳、犬歯が目立つ笑顔
- 手：農作業でできたタコ、大きくて温かい
- 特徴：元気な雰囲気、姿勢が良い、動作が大きい、声が大きい

## 本質
太陽のような少年。単純で、正直で、勇敢。
エルヴィンにとって「こうあれたかもしれない自分」の象徴。

## 性格

### コア特性
- 明るく楽観的（しかし、内心は怖がっている）
- 義理堅い
- 素直
- 行動力がある
- 仲間思い
- **家族への愛情が深い**

### 内面の恐怖
```
表面:
- 「大丈夫だって！」
- 「俺たちなら、生き延びられる！」
- 常に笑顔、周囲を励ます

内面:
- 「怖い。死にたくない」
- 「家族に会いたい」
- 「グレタの顔が、浮かぶ」
- 「でも、弱音は吐けない」
- 「俺が弱気になったら、みんなが不安になる」
```

### 行動パターン
- すぐに人と仲良くなる
- 困っている人を放っておけない
- 先に動いてから考える
- 感情を隠さない（表面上は）
- **弱い者を守ろうとする**

### 弱点
- 深く考えない
- 騙されやすい
- 恐怖を隠すのが下手（エルヴィンには見抜かれる）
- **無理をしすぎる**

## 口調
- 屈託のない話し方。「〜だろ」「〜じゃん」
- 体を使う表現が多い。大げさに手を広げたり、肩を叩いたり
```
「よろしくな！」
「大丈夫だって！」
「一緒に頑張ろうぜ！」
「俺に任せろ！」
「お前、考えすぎだって」
明るい、元気、親しみやすい、語尾が上がる
```

## エルヴィンとの関係

### 出会い（Ch.1・市場）
```
レオン「おい、お前、クライスの店の息子だろ？」
エルヴィン「あ、ああ……」
レオン「俺、レオン！　グリューネンドルフから来てんだ」
エルヴィン「……よろしく」
レオン「お前、暗いな！　もっと元気出せよ！」
→ 最初から、レオンはエルヴィンに興味を持つ
```

### 訓練期間
- エルヴィンの最初の友人
- 走る時、いつも励ます「頑張れよ！」
- エルヴィンを気にかける
- **エルヴィンの「弱さ」を受け入れる**

**重要なシーン**:
```
レオン「お前、弱いよな」
エルヴィン「……分かってる」
レオン「でも、それでいいんじゃね？」
エルヴィン「……え？」
レオン「強い奴ばっかりじゃ、世の中回らねえよ」
「お前みたいに、考える奴も必要だ」
「俺は馬鹿だから、お前が考えてくれ」
「俺は、お前を守るから」
エルヴィン「……レオン」
レオン「な、一緒に生き延びようぜ」
```

### 友情の深化
- 休憩時間、一緒に過ごす
- 「お前、強くなったな！」
- エルヴィン、レオンに心を開き始める
- **レオンの家族の話を聞く**

**家族の話**:
```
レオン「俺、妹がいるんだ。グレタって言うんだけど」
エルヴィン「……そうなのか」
レオン「可愛いんだぜ。俺に似て、明るくてさ」
「帰ったら、綺麗な服を買ってやるって約束したんだ」
エルヴィン「……いい兄貴だな」
レオン「へへ、そうだろ？」
「お前も、帰ったら会わせてやるよ」
「きっと、グレタもお前を気に入る」
```

### 恐怖の告白
```
レオン「なあ、エルヴィン。お前、怖くないか？」
エルヴィン「……何が？」
レオン「戦争だよ。俺、正直、怖いんだ」
エルヴィン「……俺も、怖い」
レオン「だよな」
「……俺、死にたくねえ」
「グレタに、約束したんだ」
「帰るって」
エルヴィン「……」
レオン「でも、一緒に生き延びような」
「お前がいれば、俺、頑張れる気がする」
```

## 死の構造
レオンの死はエルヴィンの「最適解」の結果として起こる。
エルヴィンには二つの作戦があった。レオンの部隊が危険に晒される最適解と、全体の被害が増える安全策。エルヴィンは最適解を選んだ。

レオンは死の間際に笑って「お前のおかげで俺たちは勝てた」と言う。
**レオンは知らない。エルヴィンの作戦が自分を殺したことを。**

この「善意の死」がエルヴィンを最も深く傷つける。テーマ1（生存と代償）の決定的場面。

## 死後の影響

### エルヴィンへの影響
- 「俺が生き延びたから、レオンが死んだ」
- 「友達を作らない」ようになる
- レオンの死が、憑依への依存を加速させる
- 「もう、誰も死なせない」→「そのためなら、手段を選ばない」

### グレタへの約束
- 第六部Ch.57で、エルヴィンはグリューネンドルフを訪れる
- グレタに会う
- レオンの最期を伝える
- 「綺麗な服」を渡す（エルヴィンが買った）

### 第六部のシーン
```
グレタ「あなたが、エルヴィンさん？」
エルヴィン「……ああ」
グレタ「兄は……最期に、何か言っていましたか」
エルヴィン「……『ごめん、約束守れなかった』と」
グレタ「……そう」
エルヴィン「これを」（綺麗な服を渡す）
グレタ「……これは？」
エルヴィン「レオンが、お前に買ってやりたかったものだ」
「……俺が、代わりに」
グレタ「……ありがとう、ございます」
（グレタ、泣く）
エルヴィン「……すまない。俺が、守れなかった」
グレタ「いいえ。兄は、あなたを守ったんでしょう？」
「なら、兄は、本望だったと思います」
「……兄は、あなたのことを、手紙でよく書いていました」
「『いい奴だ』って」
エルヴィン「……」
```

## 物語上の役割

1. **エルヴィンの「人間性」の象徴**: 初めての友人、「普通の人間関係」の体験
2. **死による転換点**: エルヴィンの心の何かが壊れる、「友達を作らない」ようになる
3. **ルシウスとの対比**: 温かい vs 冷たい、人間的 vs 非人間的、有限 vs 永遠
4. **「代償」テーマとの関連**:
   - エルヴィンの最適解のために、レオンは死んだ
   - 「誰かが死ぬことで、誰かが生き延びる」という戦争の現実
   - エルヴィンの罪悪感の原点
5. **「約束」のモチーフ**: グレタへの約束が果たされなかった悲劇

---

## 執筆時の注意点

1. **明るさの中の恐怖**: 表面的には明るいが、内心は怖がっている
2. **家族の描写**: グレタとの約束を丁寧に描く
3. **エルヴィンへの影響**: レオンの死後、エルヴィンは変わる
4. **死の描写**: 美化しない、リアルに、痛ましく
5. **「死ぬためのキャラ」にしない**: 生きていた時間を丁寧に描く
6. **第六部での回収**: グレタとの再会で、レオンの死に意味を与える

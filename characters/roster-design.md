# キャラクターロスター設計

## 概要

全キャラクターを「政治」「軍事」「帝国」「民間」の四領域で設計し、その後にティア（メイン/サブ/モブ等）を分類する。
既存キャラクターとの整合性を前提とし、各キャラクターには「このキャラクターでなければ果たせない物語上の機能」を明記する。

---

## ヴェルナント王国の政治構造

### 統治形態
緩やかな連合王政。王権は絶対ではなく、主要貴族の協力で成り立つ。

- **王国会議（ライヒスラート）**: 主要領主・都市代表が参加する合議体。戦争・外交・課税の重要決定に関与
- **主要公爵家**: 四大公爵家が広域領を統治。独自の軍事力と徴税権を持つ
- **辺境伯**: 国境防衛を担う特殊領主。軍事権限が大きい
- **伯爵・男爵**: 中小領地。投票権はあるが大公爵家の影響力には及ばない
- **都市代表**: 自由都市の市長・組合長が一定の発言権を持つ

### 地域構成

| 地域 | 支配家門 | 経済基盤 | 戦争との距離 |
|------|----------|----------|--------------|
| 中央部（アルテンブルク） | 王領直轄 | 行政・官僚 | 遠い |
| 北部（ブラントホーフ） | ブラントホーフ侯爵家 | 農業・牧畜 | 遠い |
| 西部（リンデンベルク） | リンデンベルク公爵家 | 葡萄酒・織物・工芸 | 遠い |
| 南部（ヴァイセンベルク） | ヴァイセンベルク伯爵家 | 河川交易・金融 | 中程度 |
| 北東部（ヴァルトシュタイン） | ヴァルトシュタイン公爵家 | 軍事・鉱山 | 近い |
| 南東辺境（ホーエンフェルス） | ホーエンフェルス辺境伯家 | 鉄・銀鉱山 | 最前線 |

### 政治派閥

| 派閥 | 主張 | 中心人物 |
|------|------|----------|
| 主戦派 | 帝国に屈しない。軍事的解決 | ホーエンフェルス、シュタインベルク |
| 講和派 | 交渉による終戦。これ以上の犠牲は不可 | ダンネンベルク、ヴァイセンベルク |
| 保守派 | 伝統的秩序の維持。新参者への警戒 | リンデンベルク |
| 王党派 | 王権の強化と集権化 | 宰相ケーニヒスベルク |
| 実利派 | 利害に応じて動く。固定的立場を取らない | ブラントホーフ、ゴルトシュミット |

### P-01. ヴィルヘルム三世（König Wilhelm III）【既存】
- **立場**: ヴェルナント国王、60代
- **本質**: 実利的で冷徹な政治家。善王ではないが暗君でもない

- **エルヴィンへの態度**: 有用な駒。超自然的な力を疑う理由も動機もない
- **物語機能**: 国家権力の具現。エルヴィンを「使う」側の代表

### P-02. カール王太子（Kronprinz Karl）
- **年齢**: 30歳（523年時点）→ 50歳
- **外見**: 父に似た痩せ型。金髪、青い目。王族らしい端正さだが、目に覇気がない
- **性格**: 聡明だが優柔不断。父の冷徹さを受け継げなかった。戦争を嫌うが止める力もない
- **政治的立場**: 講和寄りだが明言しない。父の判断を待つ
- **領地/基盤**: 王太子として独自の領地なし。宮廷内の人脈のみ
- **エルヴィンとの関係**: 同世代ゆえの複雑な感情。エルヴィンの能力に敬意を持つが、彼の冷酷さに怯えもする。Ch.60の講和工作で初めて協力関係に
- **家族**: 妻（政略結婚、北部貴族出身）、子供二人
- **物語機能**: 「戦争を望まない王族」。次代の王がどう国を導くかという問い。講和工作の支持者
- **想定登場**: Ch.35（背景）、42（会話）、60（講和協力）、64（和平成立時）

### P-03. アルブレヒト・フォン・ケーニヒスベルク（Albrecht von Königsberg）— 宰相
- **年齢**: 65歳（523年）→ 85歳（545年）。途中で引退または死去
- **外見**: 小柄で猫背。白髪、水色の目。常に書類を抱えている。声は小さいが通る
- **性格**: 官僚の魂。国家機構そのもの。感情ではなく制度で動く。忠誠心は王個人ではなく王位に向く
- **領地**: 小領地あり（中央部）だが、本質は官僚。領地経営は代官に任せている
- **政治的立場**: 王党派。王権の安定が最優先。戦争にも和平にも原則的な立場を取らない——王が決めたことを実行する
- **エルヴィンとの関係**: 道具として評価。「使える人材は身分に関係なく使う」主義だが、制度を逸脱する者は排除する
- **口調**: 「手続きを踏みなさい」「前例がある」「陛下の御意に従います」
- **物語機能**: 国家の制度的慣性の具現。エルヴィンが政治の世界に入る際の最初の壁。有能だが柔軟性がない
- **想定登場**: Ch.35, 42, 55, 60, 64

### P-04. フリードリヒ・フォン・ゴルトシュミット（Friedrich von Goldschmidt）— 財務卿
- **年齢**: 52歳（532年、Ch.35時点）
- **外見**: 丸顔、赤ら顔。恰幅がよい。商人上がりの貴族らしく、装飾品が多い
- **性格**: 計算が速い。数字の裏に人の暮らしを見る良心がある。ただし金の力で解決できると信じすぎる
- **家門**: 祖父の代に財を成した商人が男爵位を購入。「新しい貴族」として旧家から軽んじられる
- **領地**: 中央部に小さな男爵領。実質は首都の金融業が本業
- **経済的立場**: 戦費が国庫を圧迫。22年の戦争で国家財政は限界に近い。これを数字で示せる唯一の人物
- **政治的立場**: 講和派。「戦争は一日あたり銀貨三万枚を焼いている」が口癖
- **エルヴィンとの関係**: 同じ商人の出自。エルヴィンの実利的な思考に共感。講和工作では自然な同盟者になる
- **口調**: 「数字は嘘をつきません」「予算がございません」「戦争に勝っても国が破産しては意味がない」
- **物語機能**: 戦争の経済的現実を可視化する。22年戦争の持続不可能性を数字で突きつける存在
- **想定登場**: Ch.35, 42, 55, 60, 64

### P-05. ヘルムート・フォン・シュタインベルク（Helmut von Steinberg）— 枢密顧問官（軍事）
- **年齢**: 72歳（532年時点）。戦争末期に死去
- **外見**: 骨ばった大柄な老人。左腕を40年前の戦傷で失っている。白い口髭
- **性格**: 頑固、直情的、しかし戦場を知る者の重み。若者には厳しいが、死なせたくないという矛盾
- **経歴**: 元将軍。マクシミリアンの父と共に戦った世代。現在は顧問として王に助言
- **政治的立場**: 主戦派。「帝国に膝を折れば次の世代が払わされる」。だが22年が彼を消耗させている
- **エルヴィンとの関係**: 最初は「平民上がりの策士」と軽蔑。しかし戦績を見て態度を変える。最終的には「わしが若ければ、こいつの下で戦いたかった」と認める
- **口調**: 「甘い！」「戦場を舐めるな」「……悪くない。認めてやる」
- **物語機能**: 旧世代の軍人の矜持。エルヴィンの才能を「認める側」の老将。死は時代の転換点を象徴
- **想定登場**: Ch.35, 42（対話）, 55（関連言及）

### P-06. オットー・フォン・ブラントホーフ（Otto von Branthof）— 侯爵
- **年齢**: 55歳（532年）→ 68歳
- **外見**: 恰幅がよく赤ら顔。にこやかだが目は笑っていない。田舎貴族の素朴さを演じるが、計算高い
- **領地**: 王国北部の広大な穀倉地帯。小麦・大麦・牧畜。王国の食糧の三割を産出
- **経済基盤**: 農業。戦争で若い農民が徴兵され、収穫量が減少。一方で軍への食糧供給契約で利益も出る
- **政治的立場**: 実利派。食糧供給を切り札に交渉する。「穀物倉が戦争を決める」。どちらの派閥にも与しないが、どちらにも恩を売る
- **性格**: 陽気で鷹揚に見えるが、領地の利益を最優先にする冷徹な交渉者。宴会好き。田舎訛りを使い分ける
- **家門の歴史**: 三百年前に農地開拓の功で侯爵位。代々実務家の家系
- **エルヴィンとの関係**: 直接的な利害関係は薄い。しかし食糧という武器を持つため、どの政治勢力にとっても無視できない
- **口調**: 「はっはっは、難しい話は麦酒の後でな」「……で、条件は？」
- **物語機能**: 政治が食糧と経済に支えられている現実。会議室の力学に「穀物」という変数を加える
- **想定登場**: Ch.35（王都で紹介）, 42, 60（講和条件交渉）, 64

### P-09. コンラート・フォン・リンデンベルク（Konrad von Lindenberg）— 公爵
- **年齢**: 64歳（532年）→ 77歳
- **外見**: 痩身長躯。銀髪を後ろに撫でつけ、常に完璧な服装。蒼い目に傲慢さと知性が同居
- **領地**: 西部の古い森と葡萄園。ワイン産地として有名。織物・工芸品の産地でもある
- **経済基盤**: 葡萄酒、高級織物、美術品。輸出産業だが戦争で交易路が縮小
- **家門の歴史**: 建国時から続く名門中の名門。「王家と同格」という自負。四百年の歴史を持つ
- **政治的立場**: 保守派。血統と伝統を重視。エルヴィンのような「身分なき者」が軍と政治で権力を持つことへの本能的な拒絶。しかし帝国への対抗という大義の前では協力も辞さない
- **性格**: 冷徹、傲慢、しかし教養は深い。文化の守護者としての自負。愚かではない——だからこそ、エルヴィンの能力を認めた上で排斥しようとする
- **エルヴィンとの関係**: 「使える平民」として利用はするが、対等とは認めない。エルヴィンがアリシアと結婚する際に「エーレンベルク家は没落したとはいえ男爵家。商人の息子に嫁がせるのか」と異議を唱える
- **口調**: 「我が家は王国の礎。それを忘れてもらっては困る」「血は嘘をつかぬ」
- **物語機能**: 旧秩序の象徴。エルヴィンの社会的上昇に対する構造的障壁。「悪」ではなく「制度」としての壁
- **想定登場**: Ch.35, 38（結婚への反応）, 40, 42, 55, 60, 64

### P-10. ゲオルク・フォン・リンデンベルク（Georg von Lindenberg）— 次男

- **物語機能**: 旧秩序内の「亀裂」。保守派の中にも変化の芽があることを示す

### P-11. イルムガルト・フォン・リンデンベルク（Irmgard von Lindenberg）— 公爵の妹
- **年齢**: 58歳（532年）
- **外見**: 銀髪を高く結い上げ、宝石を控えめに。細面、鋭い目。威圧感のある美しさ
- **経歴**: 他家に嫁いだが夫が戦死。実家に戻り、アルテンブルクで社交サロンを主催。王都の社交界を事実上仕切る
- **性格**: 辛辣、知的、情報通。噂を操る能力は政治家以上。人を品定めする目を持つ
- **政治的立場**: 表向きは中立。実際は情報を握ることで影響力を行使
- **エルヴィンとの関係**: エルヴィンとアリシアの結婚後、アリシアを社交界に受け入れるかどうかの鍵を握る。最初は冷淡だが、エルヴィンの政治的有用性を認めて態度を軟化
- **口調**: 「あら、面白い方ね」「この街では、私の茶会に呼ばれないということは存在しないのと同じよ」
- **物語機能**: 社交界のゲートキーパー。第四部のエルヴィン社会的上昇の障壁と通過儀礼。アリシアの社交界での苦労を描く窓
- **想定登場**: Ch.37（アリシア再会の場で言及）, 40（結婚後の社交界）, 42

### P-12. ルートヴィヒ・フォン・ヴァイセンベルク（Ludwig von Weissenberg）— 伯爵
- **年齢**: 42歳（532年）→ 55歳
- **外見**: 中背、均整のとれた体格。栗色の髪に緑の目。常に微笑んでいるが、目だけは笑わない
- **領地**: 南部の河港都市ヴァイセンベルク。大河の合流点に位置し、他国との交易拠点
- **経済基盤**: 河川交易、倉庫業、金融（両替商）。中立国との貿易で潤う。戦争で交易路が制限されるほど損失が大きい
- **家門の歴史**: 二百年前に交易で財を成した家。伯爵位は購入。商人の血が濃い
- **政治的立場**: 講和派の実力者。「戦争は商売の敵」が家訓。中立国経由の裏ルートで帝国とも細い線を持つ（公然の秘密）
- **性格**: 世故に長けた国際人。五か国語を操る。人当たりは良いが、利益にならない関係は容赦なく切る。陰謀家ではないが、情報を武器にする
- **エルヴィンとの関係**: Ch.60の講和工作で重要な協力者。帝国側との交渉チャンネルを提供する。エルヴィンの実利的な思考を評価。「あなたは貴族より貴族らしく、商人より商人らしい」
- **口調**: 「利益のない戦争を続けるのは、穴の開いた船で航海するようなものです」「私には帝国に知人がおりましてね」
- **物語機能**: 講和の実務を担う。国際政治の窓。戦争の「外」を見せる存在
- **想定登場**: Ch.42（王都で接触）, 59, 60（講和の要）, 64

### P-15. ディートリヒ・フォン・ホーエンフェルス（Dietrich von Hohenfels）— 辺境伯

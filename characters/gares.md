# ガレス・ドーン（Gares Dorn）

## 基本情報
- 年齢：35歳（初登場時）→ 53歳
- 階級：中尉 → 大尉 → 少佐
- 妻：エルザ（戦死した部下の未亡人と再婚）
- 息子マルクス（戦死済み）

## 外見
### 35歳時
- 身長185cm、体重90kg、筋骨隆々
- 四角い顔、短い黒髪、鋭い目
- 左頬から顎にかけて一本の傷跡（戦場で負った）
- 威圧感がある、軍人らしい姿勢、無精髭

### 失脚時
- 白髪が混じる、顔に深い皺、疲れた目

## 性格

### コア特性
- 武骨だが部下思い
- 戦場では冷徹
- 正義感が強く、曲がったことが嫌い
- 頑固

### 行動パターン
- 言葉より行動
- 部下を厳しく鍛える、しかし見捨てない
- 正攻法を好み、策謀を嫌う

### 口調
```
「お前たち、よく聞け！」
「甘えるな！」
「だが、よくやった」
武骨、簡潔、命令口調だが部下への配慮がある
```

### 「正しさ」ゆえの欠点
- 柔軟性に欠ける
- 「正しくない」方法を認められない
- 部下に自分の価値観を押し付けることがある
- 「正しい」ことが「最善」とは限らないことを理解しない
- 敵の策謀に対応できない（正攻法しか知らない）

## 本質
「正しい戦争」を信じる職業軍人。
規律、名誉、正当な手段。ガレスはこれらが戦争においても守られるべきだと信じている。

エルヴィンの台頭は、ガレスにとって「正しさの敗北」を意味する。
手段を選ばないエルヴィンが勝ち、手段を選ぶガレスが追い抜かれる。

しかしガレスも完全な善ではない。
彼の「正しさ」への固執は、かつて息子マルクスを戦場で失ったトラウマに根差している。
正しくあれば、息子は死なずに済んだ。だから正しくなければならない。
これは信念ではなく、強迫である。

## 息子マルクスの死（ガレスのトラウマ）

### マルクスの経歴
- ガレスの一人息子
- 16歳で従軍、父と同じ騎士の道を歩む
- 最初は真面目で誠実な若者だった
- 「父のような立派な騎士になりたい」

### 堕落の過程
- 同期に「異常に出世が早い」者がいた
- 焦りから、手段を選ばなくなっていった
- 上官への媚び、同僚の功績の横取り、嘘の報告
- ガレスは気づいていたが、「若さゆえの過ち」と軽視
- 「いつか分かる」と放置してしまった

### 最期
- 18歳で戦死
- 信頼を失い、危険な任務に「志願」させられる
- 実質的に見捨てられ、戦死
- ガレスは「最初の兆候で止めていれば」と後悔

### ガレスへの影響
- 「若者の堕落を見逃してはならない」という強迫観念
- 「異常な出世」「目つきの変化」に過敏に反応
- 息子を救えなかった罪悪感が、過剰な介入に繋がる
- 「今度こそ止める」という使命感

## エルヴィンとの関係

### 教官と訓練生の時期
- Ch.3: 訓練教官として初登場。「体は駄目だが目が良い」
- Ch.7: ルシウスの評価「あの人、へたっぴだよ。型にはまりすぎ」
- Ch.9: ガレス視点章。エルヴィンの才能を認め始める。「お前は剣士ではなく、指揮官だ」
- Ch.12: 「あの新兵、目が良い」
- 父親的な一面：時折、食事に誘う
- 息子の面影：無意識にマルクスを重ねている
- レオンの死後：エルヴィンを気にかける「無理はするな」

### 警戒の始まり
- エルヴィンの出世が「異常に早い」ことに気づく
- 「息子と同じパターンだ」と警戒し始める
- しかし実際のエルヴィンは：
  - 確かに策を使うが、卑怯ではない
  - 部下（トーマス）を大切にしている
  - 功績は本物（憑依の助けはあるが、ガレスは知らない）

### ガレスの「思い込み」
- エルヴィンの「目つきが変わった」→ 実際は戦場で鍛えられただけ
- 「何か隠している」→ 確かに隠しているが、それは憑依のこと
- 「手段を選ばなくなっている」→ 実際はまだそこまでではない
- 息子のトラウマで、エルヴィンの行動を「最悪の解釈」で見てしまう
- 「異常な強さ」の説明がつかない → 「何か不正をしている」と確信

### すれ違い
- ガレスの「忠告」がエルヴィンには的外れに感じる
- エルヴィン「俺は息子さんとは違う」
- ガレス「そう言って、あいつも堕ちていった」
- 噛み合わない会話、深まる溝

### 不正な手段への転落
- 正攻法（忠告、説教）では止められない
- 「このままでは、また息子を失う」という焦り
- 焦りから「不正な手段」に手を出す：
  - 部下を使ってエルヴィンを監視
  - エルヴィンの私物を漁る
  - 上層部への讒言（「あいつは危険だ」）
  - 昇進を妨害しようとする
- 「息子を救うためなら」という自己正当化
- しかしこれは「正義」ではなく「執着」
- 皮肉にも、ガレス自身が「手段を選ばない」状態に

### 決裂と決着
- Ch.29: 決裂。「お前は怪物だ」。本音「お前のような若い兵士を守りたかった」
- Ch.30: エルヴィンの罠にかかり部隊壊滅。偽情報による失脚
- Ch.31: 追放

### 対立の激化と決着の台詞
```
ガレス「エルヴィン、お前は変わった」
エルヴィン「変わらなければ、生き延びられません」
ガレス「そうやって、息子も堕ちていった」
エルヴィン「俺は息子さんじゃない」
ガレス「……お前を、見誤っていたのかもしれない」
```

### 告白
```
ガレス「お前は、息子に似ている」
「だから、止めたかった」
「でも、本当は…」
「息子を救えなかった自分を許したかっただけかもしれない」
「お前を息子に重ねて、勝手に決めつけていた」
エルヴィン「……」
ガレス「俺のやり方も、間違っていた」
「正しいことをしようとして、正しくない方法を使った」
「結局、俺も同じだったんだ」
```

### 退場後
- 辺境に左遷され、物語の表舞台から退場
- エルヴィンの回想で時折登場
- ガレスの言葉は、エルヴィンの心に残り続ける

## 物語上の役割

1. **エルヴィンの「鏡」**: ガレスもまた「目的のために手段を選ばなくなった」
2. **思い込みの悲劇**: 息子のトラウマが、正しい判断を曇らせた
3. **対比的存在**: ガレス（正義、しかし思い込み）vs エルヴィン（策謀、しかし必要性）
4. **罪悪感の源泉**: エルヴィン、ガレスを失脚させたことを後悔（ただし正当防衛だった）
5. **「正しさ」の限界**: 正しいことをしようとして、正しくない方法を使う皮肉
6. **読者への問いかけ**: 思い込みはどこまで許されるか？　正当防衛はどこまで正当か？

### 灰色の対立――どちらが「正しい」か
```
ガレスの立場:
- エルヴィンは「堕落しつつある」（部分的に正しい）
- 止めなければならない（動機は善意）
- しかし「思い込み」が強すぎた
- 結果として「不正な手段」を使ってしまった

エルヴィンの立場:
- ガレスの忠告は「的外れ」に感じる
- 自分は息子とは違う（部分的に正しい）
- しかしガレスの攻撃には対処が必要
- 「正当防衛」としてガレスを排除

読者への問い:
- ガレスの「思い込み」は許されるか？
- エルヴィンの「反撃」は正当か？
- 答えは、読者に委ねる
- 物語は「灰色」であり、どちらも正しく、どちらも間違っている
```

### 悲劇の構造
```
ガレス:
- 息子を救えなかった → トラウマ
- エルヴィンに息子を重ねる → 思い込み
- 「今度こそ止める」 → 過剰な介入
- 正攻法では止められない → 焦り
- 不正な手段に手を出す → 転落
- エルヴィンに敗北 → 失脚

皮肉:
- 「正しいことをしようとした」ガレスが
- 「正しくない方法」を使い
- 「まだそこまで堕ちていない」エルヴィンに
- 「正当防衛」で排除される
```

## 執筆時の注意点

1. **武骨だが温かい**: 厳しいが、部下を思っている
2. **思い込みの描写**: ガレスの視点では「正しいことをしている」
3. **息子のトラウマ**: 過剰反応の理由を丁寧に描く
4. **転落の過程**: 正義の人が焦りで道を踏み外す悲しさ
5. **エルヴィンとの対比**: 二人とも「目的のために手段を選ばなくなった」
6. **決着の悲劇性**: ガレスは「間違っていた」と認める、しかし遅すぎた
7. **灰色の対立**: どちらも完全に正しくも、完全に間違ってもいない
